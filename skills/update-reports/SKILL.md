# 更新已有公司研究

定位当前项目中含 `reports/` 和 `skills/deep-valuation/` 的仓库根目录，以下路径均相对于该目录。用户点名时按代码或名称匹配主报告；未点名时遍历实际存在的 `reports/<六位代码>-<公司名>/README.md`。首页可能只列出部分公司。点名公司尚无主报告时说明缺项，其余公司继续。

## 确定这次要验证什么

逐家阅读主报告、`evidence/README.md`、`valuation/README.md` 及其引用的现行模型。提取原判断、估值或暂停定价的原因、最敏感的假设、证伪条件和上次待验证的问题。分别识别研究日、财务期间、行情日及上次完成检索的披露截止日。

默认从上次完整检索截止日（含当天）追到本次调用日；首次缺少记录时从原研究日开始，并核查最近一期定期报告及原有证据缺口。按公开披露时间纳入，包括对早期期间的更正。用户指定历史截止日时仅采用当时已公开的信息。按公告编号、原件或披露版本去重，保留实质更正。

## 核实增量及其影响

实际检索交易所公告、公司定期报告、业绩说明会和期后重大事项，再围绕各公司原有疑点定向查行业数据、竞争对手披露及有分歧的研究。例如原判断取决于渠道利润，就核查动销、折扣与回款能否相互印证。为关键事实保留原文链接、披露日、所涉期间和页码或表名。区分已实现数据、管理层指引和研究假设；只能找到转述的事项保留为待核实线索。

把可比实际值与原预测或触发条件对照，解释差异能否持续，以及通过销量、利润率、资本投入、现金分配或股数中的哪一项影响每股价值。分别判断商业质量、盈利预测与价格吸引力。仅有行情变化时，可按注明时点的行情更新价格比较；维持原经营假设。证据支持原判断时，说明哪项检验得到支持、下一项反证是什么。关键依据已失效且影响无法合理估算时，明确暂停相应定价。

## 写回与核对

- 在证据索引维护每家公司的「增量核查截至」及主要检索来源。只在完成该窗口核查后推进日期；部分来源不可用时记录实际覆盖和待补区间，下次补查。无实质新增时只更新必要的核查记录。相同截止日和相同证据重复运行时跳过重复写入。
- 结论变化时直接修订唯一主报告，写清旧判断、新事实、新判断及其成立条件。经营质量变动时按 `skills/value-investing/references/company-quality.md` 核对评级及其对应上限。沿用报告摘要与状态字段，区分本次核查日期与原估值基准日。
- 影响定价时按仓内量化原则及 `skills/valuation-review/SKILL.md` 复核，更新估值附录及输入，运行已有模型或按公式复算。并列新旧结果，区分经营变化、股本或分配变化与计价日变化；如滚动预测终点，单列期限变化的影响。交叉核对主报告、结构化摘要、附录和计算输出。首页字段受到此次修订影响时，按 `skills/update-readme/SKILL.md` 同步对应公司。
- 回复逐家列出核查区间、最重要的新证据、结论变化或维持理由、待验证信号，并链接主报告；覆盖不完整的公司单独标明缺失来源或期间。历史版本交由 Git 保留。
