# 更新公司研究列表

1. 在仓库根 `README.md` 定位唯一的 `## 公司研究`，以下一个同级或更高级标题或文件末尾为界。可编辑内容限于公司表格，以及因本次表格变化而需要修正的单位、估值口径和脚注。若无法唯一定位表格，先说明定位问题。
2. 用户点名公司时，只同步对应公司。要求刷新整表时，遍历 `reports/<六位代码>-<公司名>/README.md`，按完整六位代码与现有行对应，保留前导零和已有行顺序，补入新增的正式主报告。遇到主报告缺失的旧行，先核实是否迁移；无法确认时保留并在回复中指出。
3. 逐项对照主报告的现行结论填写公司链接、买入市值、买入股价、卖出市值、卖出股价和研究日期。按表头匹配字段，沿用亿元、元/股及现有精度。研究日期取报告标明的研究时点，区别于行情日和文件修改日。估值附录可用于核对股本与税费口径。
4. 仅摘录报告已给出的数值。缺项写「报告未给出」；已撤回、未启用或待复核的结论保留报告原状态。勿用现价、远期目标价或情景估值填补缺项，也勿以四舍五入后的股价重算市值。若某行采用不同回报门槛或股本口径，在该行或表下注明适用公司。
5. 对照编辑前的工作区内容复核差异，确认本次修改全部位于目标列表及其说明内，每个更新的代码只出现一行，链接指向对应主报告。列表与报告一致时跳过写入。回复列出实际变动的公司和待核实项。
