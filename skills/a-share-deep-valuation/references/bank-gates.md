# 银行分支 · 深度闸门与模块词典
适用：`industry_branch: bank`（intake 判定）。完整方法论来源见 `（内部文稿未发布）`。制造/消费闸门见 deep-analysis-gates.md；银行票**并行**满足本文件 B1–B6 + 通用 D1–D12（来源/红队/隐含预期等仍适用，单位经济等按本词典改写）。

## 禁令
- 不用单位净利×出货、企业 FCFF/EV-EBITDA 做主路径。
- 不把「当前 ROE / 当前 PB」直接当投资者年化收益（价值奇点）。
- 报表不良率下降 ≠ 资产质量已改善（须逾期/迁徙互证）。
- 拨备覆盖率下降 ≠ 自动利空或自动利好；拨备释放**不得**进基准，且不得与「信用成本下降」双计。
- **不得**因「银行需要资本」用老唐原第 3 条机械封顶 B。

## 模块词典（替换 a–d 制造用语）
| 原 | 银行 |
|---|---|
| 单位经济 | NIM、生息资产收益率、负债成本率、贷款结构（零售/对公/按揭/信用卡）、非息结构 |
| 产能/出货 | 贷款与存款增速（日均优先）、AUM/FPA、份额 |
| 占款/FCF/生产资产 | 拨备勾稽、逾期与不良迁徙、信用成本、拨贷比/覆盖率、核销回收；ROA、成本收入比、活期存款占比、RWA density、CET1 |
| 同行毛利 | 同业 ROA/ROE、NIM、不良与逾期、拨备、CET1、PB |

## 银行硬闸门 B1–B6（全部 pass / pass_with_gap 才进估值）
1. **B1 利润真实性**：报表利润 ↔ 拨备变动 ↔ 逾期/不良 三方勾稽；合意拨备假设写死并只计一次（夏至1987）。
2. **B2 资产质量**：不良 + 关注 + 逾期90天+ + 重组/核销；招行必须零售/对公分列。
3. **B3 息差与负债**：NIM ≥5 年趋势；存款成本与活期占比；是否依赖批发负债。
4. **B4 资本与分红**：CET1 水平与趋势；RWA 增速；分红率；优先股/永续/转债对普通股影响。
5. **B5 护城河两边写**：好（低成本存款、客群、风控、财富）与坏（息差天花板、零售不良、让利、资本消耗）均量化到「好/坏到什么程度」（巴菲特 ROA + 低成本负债；招行管理层口径须验证）。
6. **B6 来源**：年报附注（五级、逾期、分部）、资本充足率附表、业绩会原文；卖方仅交叉验证。

通用 D1–D12 仍勾选：D1 年报（含银行附注重点）、D2 季报、D3 业绩会、D7 熊≥牛、D8 击穿码、D9 红队、D10 银行版三前提、D11 隐含预期、D12 开放问题。

## 老唐三前提（银行改写）
| # | 银行表述 | 评级含义 |
|---|---|---|
| ① | 报表利润经拨备/逾期还原后仍扎实 | 不满足 → 不买入 |
| ② | 可持续 ROE（NIM×信用成本×非息×杠杆稳态可辩护）；非一次性拨备释放 | 不满足 → 最多观察/试仓 |
| ③ | **内生资本能否支撑目标贷款增速并维持分红**（目标 CET1 下）；非「几乎不需资本」 | 资本消耗强且 ROE≤Ke → 偏低档；高 ROE + 内生充足 + 稳定分红 → **可高于 B**，不得机械封顶 |

一票否决：风控失控、严重监管处罚、资本明显不足且依赖摊薄融资续命 → 不进买入候选。

## 招行叙事骨架（老凯李，作分析清单非基准假设）
消费/零售需求 → 零售资产质量 → 息差 → CET1 → 分红率；顺序不可颠倒。宏观（有效需求/让利）只作情景外生变量。

## 招行后补强（2026-10-22，适用于所有 bank）
- **B5 量化**：估值前进 scenarios 前须有 ≥4 家可比同业迷你表（NIM、ROA、不良、CET1、PB），数字须可追溯；否则 B5/D5 只能 pass_with_gap 并保留 G6。
- **老唐③证据最低集**：同时披露高级法与权重法 CET1（若有）；写 g≈ROE×(1−payout) vs 目标贷款增速；分红率与目标 CET1 的可检验约束。证据不足时标「有条件满足」，不得写无条件「满足」。
- **复核必查**：总回报 y 是否进买点；退出 PB 中值方向；ROE 与低 PB 是否双杀；无倍数修复是否为 min；脆弱比定义。
