## 1. 情景（scenarios_risk 用）
- 熊/基/牛均为经营驱动：量 × 单位利润（或收入 × 净利率）± 投资收益 − 税负变化，三年后得 NI3。
- 增长来源：业务、市场、行业数据；永续 g 只用于 DCF 尾部交叉检验。
- 基准 = 中性最可能路径；平台期/零增长属熊市，除非有证据并在 base_neutrality_note 写明。
- 超额净现金 = 净现金 − 经营性占款（应付+合同负债−应收−预付的净额中属于上下游的部分）− 必要营运现金；拿不准取低值并登记 data_gap。
- 概率为主观判断，只用于展示。

## 2. 评级与 hurdle（P2 grade_two_axis + P2b b_quality_tier · 2026-10-26；经验值/待回测）
评级主轴仍是质量 × 确信。展示串规则：
- `quality_grade`∈{A,C} → `grade={quality_grade}·{confidence}`（例：`A·确认`）；`b_tier=null`
- `quality_grade`=B → 必须再标 **B 内档** `b_tier`∈{B+, B, B-}，展示 `grade={b_tier}·{confidence}`（例：`B+·暂定`、`B-·暂定`）
**禁止**再把「开放问题 + 上限 B」压成单一 `B-暂定` 大锅饭；也**禁止**把 B+/B/B- 再折叠回光秃秃的 `B·暂定`。

### 2.1 quality_grade ∈ {A, B, C}
老唐三前提 + 生意类型（特许 vs 周期/资本开支），**按老唐精神**：温和需求/批价周期单独**不得**把清晰特许现金牛挡在 A 外。

**A** 须同时满足：
1. 老唐① 利润为真：满足（OCF/NI 健康、无重大造假/监管否决）。
2. 老唐② 利润可持续：满足，**或**仅「温和周期/批价波动/净利率中枢缓下移」而特许/品牌/牌照护城河仍在（茅台类）；**不得**因行业有一点周期就把特许股打成非 A。
3. 老唐③ 维持竞争所需再投入低：满足，或轻资产高 ROIC 现金牛有条件满足（capex 不吞噬业主盈余）。
4. 生意类型：franchise / 平台 / 受监管公用特许等「优质生意」主叙事；**不是**强周期商品、重资本扩产成长、投放驱动尚未证实的品牌作为主叙事。
5. `four_quality` 企业+生意+管理层均为 `pass`（任一项 `edge` → 最高 B）。

**B→A 升档路径（t310u · 2026-10-27；经验值/待回测）**：B 名可随时按下列**硬标准**申请升 A，**现数先判**（t308u：用 run 内既有 ≥5 年年报数据当轮判定），只经**独立复核**改 `quality_grade`；**永不**因价格、折价、TA、看板重点升 A。
- **A1 利润为真（老唐①·现金转换）**：近 5 年累计 OCF / NI（主轨口径）≥1.0，且无单年 <0.8。
- **A2 可持续（老唐②·护城河耐久）**：近 5 年每年 ROE（非银可用 ROIC）≥15%（银行按 `bank-gates`：ROE ≥12% 且不良/拨备无恶化趋势）；毛利率（银行用 NIM）5 年极差 ≤5pp **或**有一手定价权证据一句（提价/份额稳定/价格战未伤毛利）；周期名须**穿越至少一个下行年**仍达标。
- **A3 轻再投入（老唐③）**：近 5 年每年 (OCF − capex) / NI ≥0.7，且最新年 capex/收入 ≤ 5 年中位数 ×1.5（资本强度未结构性跃升）；触 `franchise_vs_midcycle_reinvestment_bar` / `tob_reinvestment_vs_A` 即 fail。
- **A4 资产负债表**：非银 净现金 或 有息负债/EBITDA ≤1.0；银行 核心一级资本充足率达监管+缓冲且 5 年无下降趋势。
- **A5 管理层与资本配置**：`four_quality.management=pass`（无 edge）；5 年无重大诚信/监管处罚；资本配置序列一句（分红+回购/再投入回报）无「为再投入牺牲股东回报」的系统性证据。
- **A6 生意类型**：满足上文第 4 条（franchise/平台/受监管特许主叙事）。
- **A7 ROE 持久（Tillinghast · r19 P-X5 · 2026-10-27）**：近 **10** 个完整会计年度中，至少 **8** 年 ROE（优先加权 ROE；银行同口径）**>12%**（Tillinghast「10–12%」带上沿；与银行 A2 的 12% 对齐）。口径：年报加权净资产收益率；港股可用 ROE_AVG / 归母÷平均权益。可核对年数 <10 时：缺失年记 data_gap，**不自动 fail**——以已核对年中「>12% 的年数 ≥8」为过闸（即使最差把缺失年全算 fail 仍 ≥8/10 则 pass）。不足 8 年 >12% → A7 fail，不得升 A。**双口径（§59 P-AA5）**：报表加权 ROE 与 §55 调整后 ROE 须**同时**过上述 8/10；调整后第 8 高年份 <13% → `a7_margin_thin`（贴线，全文见 §59）。`predictability_edge` 名仍不得走 A 路径（与 A1–A7 其余条件相同否决）。
- **程序**：A1–A7 全过 → 标 `a_upgrade_review_due` + `hurdle_reval_pending`（A hurdle 18–20% 的适用买点另由 owner 重跑，**本步不改** 收益卖线/FV3/NI3；字段约定见 §2.3）→ 独立复核确认后才改 `quality_grade=A`；任一项因数据缺失无法判 → 写「待验证」并指定**定日**节点（如下一份年报），仅当该节点能翻转结论才作前置（t307u）；开放问题只作 A 档持有期跟踪项，不阻断升档。

**B**：够正式池（前三优过）但达不到 A——典型：②或③明显部分/不满足、周期成长/资本开支型、`management=edge`、品牌投放仍验证中。B 内再分档见 §2.1b。

**C / unrated**：①不满足，或诚信/能力圈外，或只观察不可执行。看板展示可用 `C·暂定` / `C·确认` / `unrated`。

### 2.1b b_tier ∈ {B+, B, B-}（仅 quality_grade=B；P2b · 2026-10-26 t262u）
同一质量档 B 内也分好坏；**不改** A/C 规则，**不改**任何 B20/B22/收益卖线，**不**因 b_tier 发明新买点。仓位仍由确信档 + edge/事件闸驱动；B+·确认可在卡文写更高确信，本轮试仓规则不变。

| b_tier | 含义 | 判定要点 |
|---|---|---|
| **B+**（优势 B） | 正式名；四优企业+生意+管理层均 **pass**（无 edge）；有清晰耐久优势（全球/成本/规模/技术平台龙头），即使中周期或高 capex | 例意图：宁德时代、福耀、迈瑞、美的、亿联（若非 A）等 |
| **B**（中性 B） | 正式过闸但优势不够决断，或前提混杂，或第二曲线未证实——又不是弱品牌故事 | — |
| **B-**（偏弱 B） | 仍正式可留，但 B 内偏弱：管理层/生意 **edge**、投放驱动品牌仍验证中、特许偏弱等 | 例意图：珀莱雅、贝泰妮、欧普康视、其它 edge 名 |

A/C：`b_tier` 必须为 `null`（或不写）。

### 2.2 confidence ∈ {确认, 暂定}
- **暂定**：仍有卡执行的关键 D12/OQ 待验证（已量化也算暂定，直到关闭）。
- **确认**：无卡执行关键开放问题，或触发已关闭。

| 展示 grade | hurdle（三年年化） | 仓位要点 |
|---|---|---|
| A·确认 | 18–20% | 默认 ≤75% 计划仓位（F1–F4）；**满仓 100%（F5）**仅当 脆弱比 ≥0.60 ∧ 执行价 r_bear ≥+5% ∧ 无击穿码（§4）；唯一可达 100% 的档 |

字段：卡与 watchlist 须有 `grade`（展示串）、`quality_grade`、`confidence`；当 `quality_grade=B` 时须有 `b_tier`∈{B+,B,B-}；可选 `grade_reason` 一句。

**本轮/就地改档不改数**：质量档、b_tier 或 hurdle 带变化时，**禁止**当场重算 B20/B22/收益卖线；对质量升为 A（或 hurdle 带变化）的名字设 `hurdle_reval_pending=true`，交下次深估/独立复核刷新买点。质量 edge / 事件闸仍可额外禁止试仓。

**含息总回报买点 · tr_buy（t396u · 用户 2026-10-30 Asia/Shanghai 选定；独立复核 PASS_WITH_CHANGES / 反方 ADOPT_WITH_CHANGES）**：非银行/保险/公用名的适用买点改为 **B20_TR = (基准 FV3 + 3×DPS_min3) / (1+h)^3**（B22 同式用次档 h）。h 不变：B 档 20%/22%，**A 档 18%/20%（A18/A20；茅台为 A18）**——用户所说「20% 含息」指 B 档。`DPS_min3` = FY23–25 三个完整财年**已实施**现金分红每股的**最小值**，按其后送转股复权；不外推增长、不用 TTM×价格；三年呈下降或末年 <0.8×三年最高 → 标 `dps_declining`（仍取 min3，卡上写一句可持续性）。股息不再投资、期末计 → 略保守。银行/保险/公用 §69 已是总回报口径 → **不叠加**；卡未正式名（分众/中兴）不适用。**双计提示**：若基准 FV3 退出价含 `excess_net_cash`，其中将派出的现金与 3×DPS 存在轻度双计（上限≈3×DPS 的一部分）；新深估须令 excess_net_cash 扣除三年计划派息，存量卡标 `div_cash_double_count_minor`。watchlist：`buy_b20`/`buy_b22` 存 TR 买点，旧值归档 `b20_archived_t396u`。**回测**：无增量证据（8 只事后好股、旧版公允价，新旧到价次数相同 8/8）；按用户选择 + 与收益卖 base_revert 含息口径一致而安装，不得写「回测证明」。`data/*_annual.csv` 的 `dividend_cash` 字段（现金流口径、含利息；紫金股本少一位）**不得**作 DPS。零改 FV3/NI3/退出 PE/收益卖线。复测：FY2026 年报披露后（≤2027-05-05）。

## 3. 买点
- FV3 = NI3 × 退出 PE + 超额净现金（÷ 总股本）。
- 退出 PE：本股历史 PE_TTM（剔除亏损期）20/50/80 分位 → 熊/基/牛。优先用**结构可比窗口**：本股经历明确阶段转换（如超高速成长期→规模期，以利润规模与 PE 中枢断裂为证）时，只取转换后的窗口；窗口须 ≥4 年，且前后各缩短 0.5 年时 P50 变动 ≤10%（稳定性检验）。无可比窗口或不足 4 年 → 回退档：资本开支型/周期成长 12/18/25；轻资产高 ROIC 15/22/30。**回退档始终作为下限对照与敏感性列示**；上限 30（老唐）。
### 退出 PE · 合格窗硬清单（2026-10-26 进化试跑；经验值/待回测）
来源：pe-audit-20261026 + 星宇/茅台/晨光中点重跑教训。
1. 窗合格（结构可比 ≥4y，且两端各缩 0.5y 时 P50 变动 ≤10%）时：
   - 若 window_P50 > 回退基：基准退出 PE = min(30, (window_P50 + 回退基)/2)（中点下压）；**禁止**改写为纯回退主路径。
   - 若 window_P50 ≤ 回退基：基准 = window_P50；**禁止**再向回退基或更低下压。
2. 熊 = min(window_P20, 基准)；牛 = min(window_P80, 30)；并保持熊 ≤ 基 ≤ 牛。
3. 拒用合格窗，必须书面给出一手证据之一：利润规模与 PE 中枢同步断裂、亏损/利润塌陷、周期失真（含可核对数字）。禁止以「含高成长溢价」「现价 PE 已低」「年度 P50 波动大」单独拒窗（年度波动 ≠ 稳定性检验）。
4. 决策卡 / valuation_decision 必须标注 Exit PE 路径标签：`窗口` | `中点下压` | `回退` | `触30帽`，拒窗时附 evidence source_id。
5. 「无倍数修复列」= min(主路径买点, 回退路径买点)；回退不更严须注明。

- 买点 = 基准 FV3 / (1+hurdle)^3。
- 老唐参照 = 基准 NI3×(25–30，按利率)×50%。三前提全满足时买点取 min(买点, 老唐)；前提③失败 → 仅参照。
- DCF（FCFE）只作交叉检验；**禁止先用 Ke 折现得 FV₀ 再叠 hurdle**。

### 执行前二级检查（Marks / 三角闸；2026-10-26 经典学习）
到价或拟试仓前，决策卡必须书面回答（任一空 → 不执行、不 promote）：
1. **共识已定价什么？** 用现价反推隐含 NI3/退出 PE/叙事（1 句）；禁止引入卖方目标价。
2. **我与共识差在哪？** 须指向 scenario 或 risk_register 条目（量/价/份额/资本开支纪律/风险折价）。
3. **若共识对了，现价是否仍贵？** 用熊 FV3 或脆弱比回答；不能只答「已低于 B20」。
与买入三角对齐：增值须答「三年回报拆成 盈利增长 / 估值修复 / 股息 各占多少？是否主要靠估值修复？」——**只拆解与标记、不否决**：主要靠估值修复（份额 ≥50%）→ 卡标「主要靠估值修复」并按「估值不修复」情景控仓（硬闸 §109，用户 2026-10-28 裁定；原「是 → 否决/观察」作废）；合格窗内的倍数回归是 §3 估值锚，不得据此拒窗或否决（与合格窗硬清单 3「禁止以现价 PE 已低拒窗」一致）；进取失败条件含「长期增量 ROIC 明显低于资本成本且持续扩产」；折价含熊档+脆弱比+击穿码+`pre_event_hold`。

### 周期/商品类 · NI3 路径标签（Damodaran；2026-10-26 经典学习）
凡模块 b 判定周期性「强/中」或商品价格驱动为主：
- `ni3_path_tag` ∈ {`normalized_midcycle`, `recovery_path`, `peak_fade`}，缺标签 → valuation self_check fail。
- `normalized_midcycle`：利润率/单位利润取跨周期中枢（写窗口年数与来源）；禁止用最近峰年外推基/牛。
- `recovery_path`：近端低于中枢、远端回归；须写回归时点与证伪（价格/利用率/价差）。
- `peak_fade`：现处或刚过峰值 → 基/牛不得高于中枢，熊须显式低于中枢。
- **禁止**用今日板块可比 PE / 卖方退出倍数替换本股历史窗或回退档。

退出 PE 窗峰谷自检（补硬清单）：窗内若含行业景气极端年（利润率近 10 年顶/底分位）且未做结构断裂切割 → 敏感性列示「剔峰/剔谷 P50」，或给出一手「周期失真」拒窗证据；不得以剔峰后更高 P50 单独上修基准突破中点纪律。

### 证伪优先与认知偏差过滤（Munger / Marks；2026-10-26 进化重跑）
1. **Disconfirming line（强制）**：决策卡 / 拟试仓前须写 1 句「什么一手证据出现则基准 NI3 或进取闸失败？」（时点可核）。空 → 不执行、不 promote。用于对抗承诺一致性（写完 B20 后脑门上锁）。
2. **Lollapalooza 升级怀疑**：当「到价或近买 + TA 高/见底 + 产业叙事热闹（利用率回升/政策暖风）」同时满足 → 二级检查必须多答一句「市价作为社会证明是否已把修复写完？」；仍禁止用叙事抬 B20。

### 买卖点严格锁 · 降价才买（Buffett 2008 / Marks 1992&1997；2026-10-26 进化 r5）
1. **strict_cycle_lock（周期/窗口票）**：当模块 b 强/中且已用 `normalized_midcycle`（或窗口 P50≤回退基而守窗），且现价相对 B20 溢价 ≥100% 或已 `return_below_line` → **禁止**为「贴近现价/减少刺眼折价」放松 NI3 中枢、退出 PE、hurdle 或收益卖线倍数。用户或复核肯定「严格」时，视为确认锁而非修改请求。唯一改数路径=一手证伪（产量/成本/合同）触发情景重估。
2. **marked_down 适用域**：Buffett「打折买优质」仅当收盘价 ≤ 有效 B20（或贴近带且见底候选）且执行路径开放（正式池 promote 或规则允许试仓）。**现价 > 收益卖线不得称为 marked down**，不得用「质量好/股息高/相对同行便宜」打开试仓。
4. **商品近峰禁令（Conoco 课）**：动力煤/锂盐/设备订单等价格或利用率近阶段高位时，基准 NI3 不得年化峰利；安监/保供/长协制度只进 risk。

### 优质挖掘 · 难受才可能优质 / look-through（Marks Dare to Be Great II / Buffett Owner's Manual；2026-10-26 进化 r6）
1. **quality_screen_note（强制，模块 c / why_quality）**：须同时写 (a) 可核超额回报或单位成本优势的一手证据（对齐 economic_goodwill_tag）；(b) 一句「共识舒适点是什么 / 我们的难受或不一致点是什么」。Marks：多数伟大投资始于不适；舒适、人人点赞的叙事通常没有议价。缺任一项 → **禁止**将 economic_goodwill_tag 标为 `franchise_pricing` / `durable_low_cost` / `regulated_franchise`（最多 `tangible_heavy` 或下调）。
2. **禁止伪优质标签**：市占第一、主题热、专精特新/小巨人认定、工信部质量管理能力高等级（经验级→卓越级）名单、品牌知名度口号 ≠ 自动经济商誉。政策与认定只进 external-views / risk，**禁止**上修 NI3/B20 或自动 promote。
3. **look_through_progress**：优质筛选看每股经济进展（可分配现金/内在价值路径），禁止用「市值做大、股价强、营收规模」替代（Owner's Manual：按 per-share 进展而非规模；股价短期波动只在提供加仓机会时有意义）。
4. **dare_to_look_wrong 域（窄）**：仅当收盘≤有效 B20 **且**执行路径已开放（正式池 promote 或规则明确允许试仓）时，才允许「买得早、暂时看起来错」的耐心叙事。**禁止**用「敢与众不同 / 逆向」为 `return_below_line`、候补到价或三角闸未齐强行试仓辩护。

### 增长必须挣来 · NI3 分解（Damodaran Growth and Value, 2008；2026-10-26 进化 r6）
1. **growth_decomposition（强制，scenario_model / valuation_decision）**：基准 NI3 相对锚定年（最近完整年或中周期单位利润×量）的增量，须拆成：
   - `g_sustainable`：再投资率 × 增量 ROIC/ROE（capex−折旧+ΔWC 等可核）；
   - `g_efficiency`：存量资产回报改善（毛利率/费用率修复等）——**必须写耗尽时点**；时点之后不得继续外推效率增长。
2. **硬禁令**：禁止把历史 EPS/归母 CAGR、卖方一致预期增速、或宏观「规上工业企业利润同比」直接写入基/牛 NI3。宏观利润只作压力测试背景。
3. **价值毁灭检查**：若持续高再投资且增量 ROIC 明显低于资本成本 → 进取闸倾向失败；该增长**不得**抬 B20（增长可毁价值）。
4. **与周期标签衔接**：模块 b 强/中时，分解结果不得推翻 `ni3_path_tag` / `strict_cycle_lock`；效率修复若来自周期价差回升，优先归入 recovery/peak 路径而非永续 g。
5. Damodaran Prop4：历史高增长对未来预测力弱；高增长后更常接低增长——敏感性须列「效率耗尽后」情景。

### 绝对优先 · 最不贵陷阱（Montier Absolute vs Relative / Tweedy；2026-10-26 进化 r7）
1. **absolute_mos_gate（强制）**：相对便宜（同行/同链更低 PE·更高 ROE·更大折价）**永远不能**打开执行。可执行仍只看：收盘≤有效 B20（或贴近带且见底）**且**执行路径开放（promote/规则允许）。相对笔记只进 `relative_mispricing_note` / falsifier。
2. **least_bad_trap（链内最不贵）**：当同链或可比组在**绝对**意义上均无 margin of safety（多数溢价于本股 B20，或已 `return_below_line`/`return_below_line`）时，挑选「链内相对最便宜」**不是** fat pitch；动作=`观察`；禁止把「相对套利」写成试仓理由。Montier：相对估值是价差仓位——两腿都贵时不要被迫满仓选最不坏。
3. **Tweedy 屏线索 ≠ 抬 Exit PE**：行业内相对低 PE / 股价较前期大跌，只可作为「值得深挖低估」的线索（What Has Worked）；**禁止**据此上修本股 Exit PE 窗、回退档或 B20。大跌后廉价 TTM PE 常叠在盈利低谷——必须用 `ni3_path_tag` 中枢/恢复路径，禁止用谷底EPS抬倍数。
4. **会计可比压测（证监会造假专项对齐）**：若相对便宜依赖难核收入确认/关联交易/总额法嫌疑 → 标 `peer_not_comparable` 或 `accounting_stress`，停止相对结论；造假/退市制度只进 risk，**禁止**当作「壳便宜可套利」抬点。

### Fat pitch 耐心 · return_below_line · 行动偏见（Montier Seven Laws / 李录 Columbia 2010；2026-10-26 进化 r7）
1. **fat_pitch_patience**：机会集在绝对上无 MOS（正式/候补多数 >B20 或已 near/above sell）时，默认=`等待/观察`（等价于持有现金耐心）；**禁止**因「闲着」「相对还有更便宜」而降低 hurdle、放松周期锁或打开候补试仓。Montier Law3：nothing to do → do nothing。
3. **downside_first（李录）**：拟试仓/到价卡须先写下行（永久损失/熊 NI3），再写上行；「先看涨后看跌」→ self_check fail。100% 所有者视角：到价且未 promote 时仍是**不交易纸片**——候补主因不得改回「技术底」。
5. **不理解不做（Law7 对齐 competence）**：说不清商业模式与现金从哪来 → `competence_tag` 不得 `in_circle`；相对故事不能替代理解。

### 护城河来源标签 · ROIC–WACC 持续性（Dorsey Little Book / Mauboussin Measuring the Moat；2026-10-26 进化 r8）
1. **moat_source_tag（强制，模块 c；可多选主次）** ∈ {`intangible_pricing`, `switching_costs`, `network_effects`, `cost_advantage`, `efficient_scale_or_size`, `none_or_eroding`}，写入 enterprise_analysis，决策卡投影。须与 `economic_goodwill_tag` 同向：
   - `franchise_pricing` → 主源通常 `intangible_pricing`（须可核溢价/重复购买，非知名度）
   - `durable_low_cost` → `cost_advantage`（或稀缺资源+规模）
   - `regulated_franchise` → `intangible_pricing`/`efficient_scale_or_size`（牌照且超额回报未被管制抹平）
   - `tangible_heavy` / `spurious_or_eroded` → 倾向 `none_or_eroding` 或仅弱成本优势
2. **伪护城河禁令（Dorsey Mistaken Moats）**：好产品、热赛道、高市占、强执行/明星管理层 **单独** ≠ 护城河。品牌若不能带来定价权或更高复购 → 不得标 `intangible_pricing`。
3. **ROIC–WACC 量级+久期（Mauboussin）**：优质筛选须同时看 (a) 正利差是否存在；(b) 能再投资多大规模；(c) 利差能维持多久。高 ROIC 但无再投资跑道或利差正在均值回归 → 不得用「优质复合」上修基/牛 NI3。股价常已预支未来价值创造——拟试仓前用二级检查写清「现价隐含多少未来利差/久期」。
4. **行业≠命运**：行业整体毁价值仍可有创造价值的公司，反之亦然；禁止「赛道好→自动优质」。段永平：好赛道不会系统性掉进低毛利；低毛利多为差商业模式——对齐 competence 与 moat 证据，不抬 B20。
5. **与 I1 关系**：本条把 quality_screen_note 的「超额回报证据」具体化为护城河来源枚举；缺 `moat_source_tag` → 不得标 franchise/durable/regulated。

### 特殊情形套利闸 · 整组高估相对尺（Greenblatt Columbia Special Situations / Schloss OID；2026-10-26 进化 r8）
1. **special_situation_note（可选）**：分拆/重组/要约/折价子公司/净现金壳等只进深挖优先级与 falsifier；**禁止**用收购价值、收购倍数或「市值≈现金」故事直接抬 B20/Exit PE。现金须按资本配置纪律折价（管理层是否会毁掉现金）。
2. **relative_overvalued_trap（强制加固 J1）**：Greenblatt——相对估值的核心风险是整组都贵时拿贵的比更贵；「EV/EBIT 略低」≠ 便宜。Schloss——没便宜货时放松到「相对价值」须仍承认绝对尺子；**禁止**把相对放松写成可执行套利。落地= `least_bad_trap` + `absolute_mos_gate`。
3. **催化剂纪律**：特殊情形「有催化剂」是加分，不是免 MOS 通行证；无绝对安全边际时催化剂只缩短等待，不打开试仓。看见华尔街已定价的催化剂往往已晚（Greenblatt/Pzena 课）。
4. **ROIC 优先于 ROE 线索**：筛优质/错价时主看 ROIC（或 EBIT/(NWC+净设备)）与 EBIT/EV 作交叉，ROE 杠杆扭曲不得单独支撑「便宜好生意」。交叉结论不得替换本股 Exit PE 窗/回退档。

### 现价隐含价值创造 · 估准交叉（Mauboussin / Greenblatt / 段永平浙大2025；2026-10-26 进化 r8）
1. **price_implied_vc_note（强制，拟试仓/到价卡；对齐二级检查#1）**：用现价反推市场已为「稳态价值 + 未来价值创造」付了多少（一句话）；若隐含永续高 ROIC–WACC 利差或超长久期，而我们的 base 并无对等 moat_source 证据 → 倾向观察/不执行，**禁止**为贴近现价上修 NI3。
2. **earnings_yield_crosscheck（可选敏感性）**：并列 EBIT/EV 或逆向 PE 现实性检查；仅作「贵/便宜」直觉校准，**不得**替换 Exit PE 路径或 hurdle。
3. **不懂不碰（段永平）**：商业模式/文化/现金从哪来写不清 → `competence_tag` 不得 `in_circle`；禁止用信息差、主题热、短期赔率包装能力圈。好公司可以长期持有的前提是「真懂」——候补/高于收益卖线不得借「长期」话术执行。
4. **慢与踩雷**：投资做得好的人节奏慢、不怕错过；本系统等价落地=`fat_pitch_patience`，不新增空仓命令，不改 B20。
5. **宏观/固投/规范条件**：统计局固投、工增、工信部行业规范征求意见等只进 risk/压力测试背景，**禁止**上修基准 NI3/B20（对齐 I2/E1）。

### Fisher 优质闸 · 管理层诚信与稀释（Common Stocks 15 Points / When to Sell；2026-10-26 进化 r9）
1. **fisher_quality_gate（强制加固 I1/K1）**：在已有 `moat_source_tag` 之外，优质筛选须额外过 Fisher 硬闸：
   - **诚信/披露（Points 14–15）**：管理层好消息畅谈、坏消息封口，或出现诚信硬伤 → 不得标 `franchise_pricing`/`in_circle`；`quality_screen_note` 难受点必须写明；倾向 `competence_tag=outside` 或至少 `edge`+额外证伪。
   - **稀释（Point 13）**：可预见股权融资将大体抵消现有股东增长收益 → **禁止**用「高增故事」上修基/牛 NI3 或 Exit PE；写入 risk/falsifier。
   - **利润率（Points 5–6）**：worthwhile 且有维持/改善路径的证据不足时，不得仅凭品牌/市占标 `intangible_pricing`。
2. **增长跑道 ≠ 护城河**：Points 1–2（市场潜力/产品线延展）只说明可投资规模，**不能**替代 `moat_source_tag`；无结构性优势时高增默认均值回归（对齐 Mauboussin/Greenwald）。
3. **Scuttlebutt 定义**：一手披露、竞品/客户/渠道可核交叉、业绩说明会问答可计入；**卖方研报目标价/评级、市值管理话术、协会 TAM 叙事不计**为 scuttlebutt。
4. **与卖出纪律交叉（Fisher Ch.6）**：仅当（a）买错、（b）公司不再满足买入标准、（c）显著更优标的经同等研究验证 才构成「基本面卖出」；**单纯 PE 变高、宏观恐惧、涨多了要落袋**不是本系统抬/降 B20 的理由。持仓侧仍服从既有收益卖线/`return_below_line`/`return_below_line` 与击穿码。
5. **与 K1 关系**：本条把 quality_screen 的「难受点」落到可核管理层/稀释/利润率闸；缺 fisher 相关难受点叙述时，franchise 标签应降级复核。

### Greenwald 可靠度分层 · EPV 交叉（AV→EPV→Franchise；2026-10-26 进化 r9）
1. **epv_reliability_note（强制，拟试仓/到价卡）**：用一句话按可靠度分层写清：资产/重置成本线索 → 无增长盈利能力（现状可持续 EBIT/FCF 资本化直觉）→ 特许增长是否额外值钱。对齐 Greenwald：信息按可靠度组织，远端子增长是最不可靠一层。
2. **无特许则增长不值钱**：若 `moat_source_tag=none_or_eroding` 或 EPV 直觉 ≤ 有形资产重置（无超额回报）→ **禁止**用收入/利润高增叙事上修 Exit PE 中点、回退档或 B20；增长只进 bear/bull 敏感性，不进基准抬点。
3. **DCF/终值陷阱**：把「好信息（近端）+坏信息（远端终值）」混加会让坏信息主导；本系统 Exit PE×NI3 已是折中——**禁止**再叠卖方长期 CAGR、主题终局份额或宏观利润总额来抬中枢。
4. **与 K3 咬合**：`price_implied_vc_note` 写「市场已付多少未来创造」；`epv_reliability_note` 写「我们自己按可靠度分层认多少」。两者同时偏贵且 moat 弱 → 观察/不执行。
5. **搜素偏好提醒（Greenwald search）**：便宜/丑陋/冷门是深挖线索，不是执行通行证；仍须过 absolute_mos_gate。

### 买卖点纪律加固 · 满价/剥夺感/激励扭曲（Klarman FAJ2010 / Munger Misjudgment / Fisher Ch.6 / Smith Fundsmith；2026-10-26 进化 r9）
1. **full_price_discipline（Klarman；t319u/t320u）**：有安全边际时，可从现金/他袖**置换入**；价格已反映价值、上行/下行比翻转后应倾向**置换出**该袖（→现金或更优到价名）、且禁止从现金新建入该袖——落地=既有收益卖线与 `return_below_line`/`return_below_line`，以及 **`置换：公允附近溢价仓→现金/更优`**（B 档近 FV0，朝档位/组合上限修剪，非强制清袖、非改收益卖线）。**禁止**在 `return_below_line` 下因「优质可长期」从现金打开试仓；亦**禁止**在远低于收益卖线且 thesis **与质量闸均未坏**时，仅因「涨多了/回本」发明额外清仓规则替代击穿码/收益卖线——但 §40–§41 的不合格/公允置换带不在此禁。
2. **cash_default_patience**：无绝对 MOS 时保持现金/等待是过程正确（Klarman never fully invested if nothing great；Smith「Do nothing」；Montier/J2）。不新增强制空仓比例，不改 B20。
4. **commitment_bias_exit（Munger consistency）**：公开/书面结论有锁脑倾向；击穿码或核心 falsifier 触发后须立刻改动作标签，**禁止**为维持旧叙事在 return_below_line/thesis 破裂后继续「观察待涨」。
5. **incentive_caused_bias（Munger + IR）**：管理层激励、市值管理、券商佣金、政策喊话会导致偏乐观表述；业绩说明会指引与「全球前十/市值管理」叙事**只进 risk/证伪清单**，**禁止**抬 B20/NI3（迈瑞 2026 业绩说明会正例：分红/增持/目标 ≠ 买点）。
6. **social_proof_ban**：同业都贵、指数成分、被动资金流入不是估准或买点依据（Munger social proof；Smith 指数动量批评）。

### 两层体系 + 四优（t220u/t222u/t225u/t227u · 2026-10-26）

**层定义**
- **候补（够格待研）**：`candidates.json` active。须过 **优质生意 + 优质领导层**。深估可未完成/未复核，或事件闸未清。不上早报、不试仓、不发明买点；**亦不上关注列表 Page**。
- **正式（研究完成盯盘）**：`watchlist.json` / 关注列表。须过 **优质企业 + 优质生意 + 优质领导层**，且 **深估 + 独立复核完成**（有 B20/B22/收益卖线）。早报只扫本池。价格未过 → 只观察；`return_below_line`/`return_below_line` 可留正式但降频、早报默认静默。
- **试仓执行**：仅正式池内，且 **优质价格** pass（收盘≤有效 B20，或贴近带且见底）。价格是执行闸，不是「能不能进正式」的闸。事件闸可压过价格到价（`pre_event_hold`）。

**收录硬规则（t227u）**：关注列表 / `watchlist.json` **只保存已深研**；未深研够格名可留候补 pipeline，永不进关注列表或早报。

**四优闸**
1. **four_quality_gate**：企业 / 生意 / 领导层 / 价格 各 `pass|fail|pending|edge`。升正式盯盘要求前三项过（+研究完成）；试仓要求四项全过。
2. **便宜救不了平庸**：价格再低也不能弥补生意/管理层/企业质量不足；「到价」只是价格一维。

### 到价/贴近带强制分批计划（t304u · 2026-10-27）
1. **强制触发**：正式池 `premium_vs_B20_pct≤0`（到价）或贴近带 (0%,5%] → 决策卡「分批计划」节 + digest/早报动作旁注 **不得空缺**。
