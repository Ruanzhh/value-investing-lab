# 评级 A1–A7 / b_tier / hurdle 原文（自 legacy L11–74 原样迁入，V§4/V§5 引用）

## 2. 评级与 hurdle（P2 grade_two_axis + P2b b_quality_tier · 2026-10-26；经验值/待回测）
评级主轴仍是质量 × 确信。展示串规则：
- `quality_grade`∈{A,C} → `grade={quality_grade}·{confidence}`（例：`A·确认`）；`b_tier=null`
- `quality_grade`=B → 必须再标 **B 内档** `b_tier`∈{B+, B, B-}，展示 `grade={b_tier}·{confidence}`（例：`B+·暂定`、`B-·暂定`）
**禁止**再把「开放问题 + 上限 B」压成单一 `B-暂定` 大锅饭；也**禁止**把 B+/B/B- 再折叠回光秃秃的 `B·暂定`。

### 2.1 quality_grade ∈ {A, B, C}
老唐三前提 + 生意类型（特许 vs 周期/资本开支），**按老唐精神**：温和需求/批价周期单独**不得**把清晰特许现金牛挡在 A 外。

**A** 须同时满足：
1. 老唐① 利润为真：满足（OCF/NI 健康、无重大造假/监管否决）。
2. 老唐② 利润可持续：满足，**或**仅「温和周期/批价波动/净利率中枢缓下移」而特许/品牌/牌照护城河仍在（茅台类）；**不得**因行业有一点周期就把特许股打成非 A。
3. 老唐③ 维持竞争所需再投入低：满足，或轻资产高 ROIC 现金牛有条件满足（capex 不吞噬业主盈余）。
4. 生意类型：franchise / 平台 / 受监管公用特许等「优质生意」主叙事；**不是**强周期商品、重资本扩产成长、投放驱动尚未证实的品牌作为主叙事。
5. `four_quality` 企业+生意+管理层均为 `pass`（任一项 `edge` → 最高 B）。

**B→A 升档路径（t310u · 2026-10-27；经验值/待回测）**：B 名可随时按下列**硬标准**申请升 A，**现数先判**（t308u：用 run 内既有 ≥5 年年报数据当轮判定），只经**独立复核**改 `quality_grade`；**永不**因价格、折价、TA、看板重点升 A。
- **A1 利润为真（老唐①·现金转换）**：近 5 年累计 OCF / NI（主轨口径）≥1.0，且无单年 <0.8。
- **A2 可持续（老唐②·护城河耐久）**：近 5 年每年 ROE（非银可用 ROIC）≥15%（银行按 `bank-gates`：ROE ≥12% 且不良/拨备无恶化趋势）；毛利率（银行用 NIM）5 年极差 ≤5pp **或**有一手定价权证据一句（提价/份额稳定/价格战未伤毛利）；周期名须**穿越至少一个下行年**仍达标。
- **A3 轻再投入（老唐③）**：近 5 年每年 (OCF − capex) / NI ≥0.7，且最新年 capex/收入 ≤ 5 年中位数 ×1.5（资本强度未结构性跃升）；触 `franchise_vs_midcycle_reinvestment_bar` / `tob_reinvestment_vs_A` 即 fail。
- **A4 资产负债表**：非银 净现金 或 有息负债/EBITDA ≤1.0；银行 核心一级资本充足率达监管+缓冲且 5 年无下降趋势。
- **A5 管理层与资本配置**：`four_quality.management=pass`（无 edge）；5 年无重大诚信/监管处罚；资本配置序列一句（分红+回购/再投入回报）无「为再投入牺牲股东回报」的系统性证据。
- **A6 生意类型**：满足上文第 4 条（franchise/平台/受监管特许主叙事）。
- **A7 ROE 持久（Tillinghast · r19 P-X5 · 2026-10-27）**：近 **10** 个完整会计年度中，至少 **8** 年 ROE（优先加权 ROE；银行同口径）**>12%**（Tillinghast「10–12%」带上沿；与银行 A2 的 12% 对齐）。口径：年报加权净资产收益率；港股可用 ROE_AVG / 归母÷平均权益。可核对年数 <10 时：缺失年记 data_gap，**不自动 fail**——以已核对年中「>12% 的年数 ≥8」为过闸（即使最差把缺失年全算 fail 仍 ≥8/10 则 pass）。不足 8 年 >12% → A7 fail，不得升 A。**双口径（§59 P-AA5）**：报表加权 ROE 与 §55 调整后 ROE 须**同时**过上述 8/10；调整后第 8 高年份 <13% → `a7_margin_thin`（贴线，全文见 §59）。`predictability_edge` 名仍不得走 A 路径（与 A1–A7 其余条件相同否决）。
- **程序**：A1–A7 全过 → 标 `a_upgrade_review_due` + `hurdle_reval_pending`（A hurdle 18–20% 的适用买点另由 owner 重跑，**本步不改** 收益卖线/FV3/NI3；字段约定见 §2.3）→ 独立复核确认后才改 `quality_grade=A`；任一项因数据缺失无法判 → 写「待验证」并指定**定日**节点（如下一份年报），仅当该节点能翻转结论才作前置（t307u）；开放问题只作 A 档持有期跟踪项，不阻断升档。

**B**：够正式池（前三优过）但达不到 A——典型：②或③明显部分/不满足、周期成长/资本开支型、`management=edge`、品牌投放仍验证中。B 内再分档见 §2.1b。

**C / unrated**：①不满足，或诚信/能力圈外，或只观察不可执行。看板展示可用 `C·暂定` / `C·确认` / `unrated`。

### 2.1b b_tier ∈ {B+, B, B-}（仅 quality_grade=B；P2b · 2026-10-26 t262u）
同一质量档 B 内也分好坏；**不改** A/C 规则，**不改**任何 B20/B22/收益卖线，**不**因 b_tier 发明新买点。仓位仍由确信档 + edge/事件闸驱动；B+·确认可在卡文写更高确信，本轮试仓规则不变。

| b_tier | 含义 | 判定要点 |
|---|---|---|
| **B+**（优势 B） | 正式名；四优企业+生意+管理层均 **pass**（无 edge）；有清晰耐久优势（全球/成本/规模/技术平台龙头），即使中周期或高 capex | 例意图：宁德时代、福耀、迈瑞、美的、亿联（若非 A）等 |
| **B**（中性 B） | 正式过闸但优势不够决断，或前提混杂，或第二曲线未证实——又不是弱品牌故事 | — |
| **B-**（偏弱 B） | 仍正式可留，但 B 内偏弱：管理层/生意 **edge**、投放驱动品牌仍验证中、特许偏弱等 | 例意图：珀莱雅、贝泰妮、欧普康视、其它 edge 名 |

A/C：`b_tier` 必须为 `null`（或不写）。

### 2.2 confidence ∈ {确认, 暂定}
- **暂定**：仍有卡执行的关键 D12/OQ 待验证（已量化也算暂定，直到关闭）。
- **确认**：无卡执行关键开放问题，或触发已关闭。

### 2.3 展示、字段、仓位、hurdle
| 展示 grade | hurdle（三年年化） | 仓位要点 |
|---|---|---|
| A·确认 | 18–20% | 默认 ≤75% 计划仓位（F1–F4）；**满仓 100%（F5）**仅当 脆弱比 ≥0.60 ∧ 执行价 r_bear ≥+5% ∧ 无击穿码（§4）；唯一可达 100% 的档 |
| A·暂定 | 18–20% | **仓位上限=试仓**（确信未齐） |
| B+·确认 / B·确认 / B-·确认 | 20–22% | 到价可试仓起；**edge/事件闸仍可禁试仓**；默认 ≤50% 计划仓位（F1–F3）；**超半档 ≤75%（F4）**仅当 脆弱比 ≥0.70 ∧ 执行价 r_bear ≥+10% ∧ 四优无 edge ∧ 无事件闸/击穿码（§4）；**永不 100%** |
| B+·暂定 / B·暂定 / B-·暂定 | 20–22% | **仓位上限=试仓**；edge/事件闸另加不试仓 |
| C / unrated | 25% 或只观察 | 观察为主 |

字段：卡与 watchlist 须有 `grade`（展示串）、`quality_grade`、`confidence`；当 `quality_grade=B` 时须有 `b_tier`∈{B+,B,B-}；可选 `grade_reason` 一句。

**本轮/就地改档不改数**：质量档、b_tier 或 hurdle 带变化时，**禁止**当场重算 B20/B22/收益卖线；对质量升为 A（或 hurdle 带变化）的名字设 `hurdle_reval_pending=true`，交下次深估/独立复核刷新买点。质量 edge / 事件闸仍可额外禁止试仓。

**A 档 hurdle 带（t339u · 用户 2026-10-28 Asia/Shanghai 批准）**：A·确认 / A·暂定 的三年年化 hurdle = **18%/20%**（主/次；标签 **A18/A20**）。B 档仍 **20%/22%**（B20/B22）。适用买点 = 锁定基准 FV3 / (1+h)^3（银行总回报 = FV3 / (1+(h−y))^3）。watchlist 字段约定：A 名的 `buy_b20`/`buy_b22` 存适用主/次买点（A18/A20）；B 名仍存 B20/B22。**不改** FV3、NI3、退出 PE/PB、收益卖线。本授权仅改 A 档回报门槛带，不是 NI 主买点公式重写。

**含息总回报买点 · tr_buy（t396u · 用户 2026-10-30 Asia/Shanghai 选定；独立复核 PASS_WITH_CHANGES / 反方 ADOPT_WITH_CHANGES）**：非银行/保险/公用名的适用买点改为 **B20_TR = (基准 FV3 + 3×DPS_min3) / (1+h)^3**（B22 同式用次档 h）。h 不变：B 档 20%/22%，**A 档 18%/20%（A18/A20；茅台为 A18）**——用户所说「20% 含息」指 B 档。`DPS_min3` = FY23–25 三个完整财年**已实施**现金分红每股的**最小值**，按其后送转股复权；不外推增长、不用 TTM×价格；三年呈下降或末年 <0.8×三年最高 → 标 `dps_declining`（仍取 min3，卡上写一句可持续性）。股息不再投资、期末计 → 略保守。银行/保险/公用 §69 已是总回报口径 → **不叠加**；卡未正式名（分众/中兴）不适用。**双计提示**：若基准 FV3 退出价含 `excess_net_cash`，其中将派出的现金与 3×DPS 存在轻度双计（上限≈3×DPS 的一部分）；新深估须令 excess_net_cash 扣除三年计划派息，存量卡标 `div_cash_double_count_minor`。watchlist：`buy_b20`/`buy_b22` 存 TR 买点，旧值归档 `b20_archived_t396u`。**回测**：无增量证据（8 只事后好股、旧版公允价，新旧到价次数相同 8/8）；按用户选择 + 与收益卖 base_revert 含息口径一致而安装，不得写「回测证明」。`data/*_annual.csv` 的 `dividend_cash` 字段（现金流口径、含利息；紫金股本少一位）**不得**作 DPS。零改 FV3/NI3/退出 PE/收益卖线。复测：FY2026 年报披露后（≤2027-05-05）。

旧标签：`B-暂定`（无中点）读作「曾 = 质量 B + 确信暂定」；`B·暂定` 在 P2b 后若缺 `b_tier` → 清洗须补 B+/B/B-，禁止长期停留光秃 `B·暂定`。
