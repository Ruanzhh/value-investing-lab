# 决策卡模板（简约 · 默认）

> 只写下面人读层。完整模式机器附录见 [`card-template-full-appendix.md`](card-template-full-appendix.md)。不改合理买入点公式或数值。

## 人读层（必写）

```
# <名称>（<代码>）· <日期> · 现价 <p>

【结论】这是个人研究卡。买点状态：<已正式启用 / 未启用（只作研究）>。
【约三年后合理价】基准 <y> 元（写清主口径；有第二种算法可一行并列取更稳妥侧）
【合理买入点】<金额或「未启用」>；未启用时用一句话写原因
【是否到价】现价相对合理买入点：到价 / 未到价；买点未启用则写「无正式到价判定」
【动作】观察 | 仅研究对照 | 可按分批计划执行（仅买点已启用且规则允许）
【最大风险】一句话
```

聊天与报告摘要只摘这一段。**不要**对人报熊/基/牛三档合理价，只报基准线。文末加：个人研究，非投资建议。
