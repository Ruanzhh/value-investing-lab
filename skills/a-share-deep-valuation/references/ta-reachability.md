# 技术可达性与执行用法
原则：技术面只用于（1）择时分批，（2）判断估值买点是否摸得到，（3）贴近买点的试探执行与到价暂缓。**永不把买点（B20/B22）抬到估值区间之上**；不改 FV、退出倍数、仓位收益门槛。

## 计算
- 数据：前复权日线/周线；交叉核对 ≥2 个行情源的收盘价。
- 距离：各买点、仓位档边界相对现价的跌幅。
- 支撑阶梯：前低、成交密集区、周线 MA120/250、跳空缺口，由近到远列出；标注**第一关键支撑**。
- 周线趋势：近 12 周 HH/HL vs LH/LL；是否跌破周线年线。
- 情绪：日 RSI(14)、换手、单日放量。
- 历史类比（样本少，仅参考）：类似超跌后 60 日再创新低的幅度分布。

## 可达性等级（经验值）
- 高：买点在第一/二级支撑内，距离 ≤15%。
- 中：距离 15–35%，或需跌破一层主要支撑。
- 低：距离 >35%，或需跌破多年周线支撑。

## 首批触发上调（低可达）
仅当可达性=低，且候选触发价 ≤ 熊市 FV3 按 hurdle 折现后的上沿附近（仍处仓位规则允许区），才可把**首批**触发价上调到最近的强支撑；第二、三批不调。上调后的价格仍须 ≤ 估值买点。

## 「技术见底」操作定义
同时满足才算「技术见底候选」（仅服务贴近带与分批，不作独立买入理由）：
1. **位置**：现价 ≤ 近 60 日低点 × 1.03，或站在已标注第一支撑区上沿 ±2% 内；且
2. **超卖或止跌其一**：日 RSI(14) ≤ 30，**或** 近 5 日内出现长下影/放量止跌日（成交量 ≥ 20 日均量 × 1.5 且收盘回升）；且
3. **未破关键支撑**：未有效跌破决策卡「第一关键支撑」（有效=收盘价连续 2 日在其下，或单日跌破且次日无法收回）。

## 贴近买点执行带（已确认参数）
- **带宽**：现价相对 **B20** 的溢价 ∈ (0%, **5%]**（以主买点 B20 为准；B22 不单独开带）。
- **准入**：仓位规则允许的试仓/半首批/满额首批上限内；满足「技术见底候选」；**收盘价**落入带宽，或盘中最低价触及 B20 但收盘仍在带宽内。
- **执行**：最多动用 **试仓上限的 100%（整笔试仓）**。收盘价 ≤ B20 后转入下方分批加仓。
- **表述**（决策卡/早报统一）：`贴近带触发（溢价 x%）；整笔试仓（达试仓上限）；收盘≤B20 后按分批规则考虑加仓`。
- **禁止**：写成「边界触发已确认买入」；禁止因见底把有效买点改成现价；禁止抬高 B20/B22。
- **退出贴近带**：收盘价重新高于 B20×1.05 → 取消未执行的试仓计划；已建仓按原卖点/击穿码管理（不另设止损规则）。

## 执行硬闸投影（权威收口 · cleanup-20261026）
与 `valuation-rules-v3.md` V§10（及 legacy `valuation-rules-v25.md`「执行硬闸」）对齐；冲突时服从 v3 LIVE。技术面**永不抬 B20/B22/卖点**。

### 池与文案
- **候补 / promote=false**：即使收盘≤B20 → 不执行；`action` 与 `required_fields.到价与试仓` 必须 `到价·候补不执行`（主因=未晋升/三角闸/事件闸）。**禁止**主写「无技术底不试仓」（技术底仅作另栏）。分批第一笔闸门同此。
- **正式且可执行**：到价首笔按下方分批；技术见底**不是**到价首笔前置。贴近带 (0,5%] 仍须见底候选才整笔试仓。
- **above_sell_watch / near_sell_watch**：现价>卖点 → `above_sell_watch`；`sell×0.95 ≤ 现价 ≤ 卖点` → `near_sell_watch`；watchlist / card.json / ta.action 三处同挂，正式 `sell` 不得为空。持仓侧动作写 `置换：<该股>→停泊现金(511990)/具名可执行更优名`（估值天花板），非持仓侧不从现金/他袖置换入；降频；TA 不改卖点、不择时「等回归」。
- **proximity_deprival_trap**：贴近带未见底 → 禁止「就差一点点」绕门控。
- **strict_cycle_lock / marked_down**：刺眼低买点禁为贴现价放松；现价>卖点不得称 marked down。
- **相对便宜 / chain_relative_ban / A-H 价差（ah_canon）**：永不打开执行、不抬贴近带上沿、不作择时。
- **FCF 并行观察互斥 / 距离只认 NI（§111/§112）**：已 `NI_only` 或 gate≠pass → 禁止并列「FCF到价·并行观察」；距买点/卖点分类只认 NI 轨数字。

- **premium 字段**：距离/溢价展示只用 `premium_vs_B20_pct`；禁止 gap_* 符号分裂进早报。
- **正式事件闸**：到价但事件未清 → `到价·正式·事件闸不试仓`。
- **质量 edge（r11）**：四优 edge≠pass → 到价亦 `到价·正式·质量edge不试仓`。
- **overhang_note（r11）**：减持/询价转让/解禁只进事件闸与分批暂缓，不动 B20。

### 到价后分批与暂缓
当收盘价 ≤ B20（或已按贴近带整笔试仓）且执行路径开放（正式池）：
1. **第一笔**：试仓或半首批——收盘确认到价，或贴近带整笔试仓；文案写 `置换：<具名资金袖>→本股`（资金袖集合见估值规则 §42）。
2. **第二笔**：价格回到卡上「第一支撑」或再跌 ≥5%（取先到者），且未触发击穿码。
3. **第三笔**：仅当可达性≠低且第二笔后逻辑仍在；否则不做。

**暂缓（不取消买点）**：到价当日或次日「放量跌破第一关键支撑且收盘不收回」→ 未执行下一笔暂缓，等连续 2 日收回或再创新低后重评。早报写 `到价但技术暂缓加仓`。

### 正式仓升级计划的 TA 输入（t306u · 2026-10-27）
同一支撑阶梯向下延伸供「正式仓升级计划」F1/F2/F3：F1=确认生效且收盘≤B20；F2=第二支撑区或自 F1 再跌≥5%（且≤B22）；F3=第三支撑区或周线首个 HL（结束 LH/LL），仍须≤B20 且可达性≠低。F4/F5（t310u，仅超半档/A·确认）触发价=min(B20, 熊FV3/(1+门槛)^3)，由估值熊 FV3 推出，TA 只决定其暂缓与否，不定价位。暂缓沿用「放量破当时关键支撑不收回」。**TA 只定升级后的分笔节奏，不触发暂定→确认、不解封试仓、不抬 B20/B22**；升级前置只认定日硬条件 + 复核（t307u），手头数据可判者当轮判（t308u），TA 不是前置也不是跟踪项替代。

### 决策卡 / 早报必填技术字段
1. 可达性（高/中/低）+ 距 B20 跌幅  
2. 第一关键支撑与是否失守  
3. 是否落入贴近带（是/否 + 溢价%）  
4. 若到价或贴近带（t304u，权威细则见估值规则硬闸 §33 所指专节）：**完整分批计划**（T1/T2/T3 触发与规模、暂缓、仓位封顶；闸未清写「闸清后执行」）/ 是否暂缓；**并列正式仓升级计划**（定日硬前置+日期 · 跟踪项信号 · 最早解封日 · F1/F2/F3 · 暂缓/中止，t306u/t307u）；候补到价须含 `到价·候补不执行`
