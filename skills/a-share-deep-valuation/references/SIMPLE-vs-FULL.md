# 简约路径 vs 完整模式

| | **简约（默认）** | **完整模式（可选）** |
|---|---|---|
| 怎么走 | 六步白话（`SIMPLE-FLOW.md`） | 状态机逐步提交 + 细则规则全文 |
| 深分析 | 看懂生意要点 | 长检查清单全过 |
| 估值 | 合理价区间 + 合理买入点草稿；仍用同一套公式数值 | 同左，并跑齐交叉校验与校验脚本 |
| 结论卡 | 必须有人读层 | 人读层 + 机器附录字段 |
| 研究结论 | **一定要能出** | 同左 |
| 「买点已正式启用」 | 材料与规则够才说 | 全套门控通过才说 |
| 银行正式合理买入点 | 建议升完整模式 | 银行专规 |
| 公式与门槛常数 | **不改** | **不改** |

一句话：简约路径少术语、少关卡堆叠；完整模式留给「要正式启用买点」或用户点名全套。
