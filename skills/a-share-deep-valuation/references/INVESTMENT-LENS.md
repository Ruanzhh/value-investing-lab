# 投资透镜（分析 / 筛选 / 估值 / 置换）

把用户拍板过的价值投资框架，压进默认研究路径。**不改** `valuation-rules-v3.md` 里的门槛常数与公式数值；本文件只管怎么想、怎么筛、怎么对照。

---

## 1. 分析企业

优质企业通常同时具备：

1. **被需要** — 真实需求，不是概念故事  
2. **很难被替代** — 护城河可讲清机制、可被证伪  
3. **价格不受管制** — 有定价权与盈利空间  

看竞争格局时，用波特五力过一遍（进入壁垒、供应商议价、买方议价、替代品、行业内竞争）。写结论时要落到这家公司具体哪一项强/弱，禁止空喊「竞争不激烈」。

高净资产收益率若长期高于平均，背后通常是难用钱买到的资产，而不是报表上的有形资产堆出来的：

- 法律或管制限制别人同业供给  
- 专利、技术或工艺  
- 品牌对用户心智的先占  
- 客户转换成本高 / 离开很麻烦  
- 成本优势（地理、规模、工艺等）  
- 网络效应：多一个用户对新老客户都更有价值  
- 狭小市场：多一个竞争者大家一起没饭吃  
- 能干的管理层（只能作补充，不能单独当护城河）  
- 中国式关系（若依赖，必须写清脆弱点与证伪信号）

相对有形资产，以上「难用金钱直接买来」的才更有投资价值。详细写法见 `BUSINESS-DEPTH.md`。

## 2. 筛选企业（三性硬关 · 现金转化在此过关）

- 若只能先看一个指标：优先看**净资产收益率**是否长期高于平均，并立刻追问「靠上面哪一类资产撑着」。  
- **利润为真**：排除利润主要来自应收账款、变卖资产或资产重估。须对照经营现金流与应收/存货：利润长期显著高于经营现金且占款膨胀 → 不过关。  
- **利润可持续**：情景与周期位置要对上；高峰年利润不得当基准。  
- **维持当前盈利不需大量资本（含现金转化）**：在【看懂生意】就必须写清结论——过 / 打折 / 不过。至少核对：① 近 3～5 年经营现金流相对净利润；② 折旧摊销能否大致覆盖维持性资本开支；③ 营运资本是否长期吸血。过关意味着：在正常年份，净利润可近似业主盈余，进入估值后**只走利润（PE）轨**。打折则利润打几折再用；不过关 → 不得估正式合理价/闸价，最多出研究备忘。  
- 现金转化必须在本关钉死，不得拖到估值步骤再用第二条定价线补救。  
- 看不懂的生意不硬估正式买点；材料薄可以出基准合理价，但写明「买点未正式启用」。

## 3. 企业估值

默认仍走简约六步与规则里的约三年**基准**合理价、买入闸价；对人只报基准线，不分熊/基/牛三档。心智上再加三条前提（与规则并行，不替代数值）：

1. 利润为真  
2. 利润可持续  
3. 维持当前盈利不需要投入大量资本（现金转化已在筛选关过关）  

**定价只有利润轨**：约三年基准净利润 × 退出市盈率 → 合理价 → 按要求回报折回闸价。经营现金与资本开支只服务于筛选三性；无风险收益倒数等只作交叉对照，不形成第二条合理价。  

**退出市盈率**：主报在约 **20～30** 内视生意判断取值并写理由；历史中位数等只作参照，不得直接主报。细则见 `SIMPLE-FLOW.md` §4。  

经验对照（**只作交叉提醒，不改闸价公式**）：若三年后约 15～25 倍市盈率卖出能大约翻倍，位置才值得认真研究；高杠杆企业更严。正式闸价折回公式仍以 `valuation-rules-v3.md` 为准；简约默认下退出倍数选取以本条 + `SIMPLE-FLOW` 为准。

估值的本质是**比较**：不必假装有唯一精确值；熟悉且相对其他机会明显更好，才进入候选。

## 4. 股票置换

- 资金总是换成某种资产：存款、债券、股票等。  
- 不必追求极精确估值；当某只股票的预期投资收益率**明显**不如类现金或其他已持有机会时，考虑卖出置换。  
- 常用粗对照：市盈率的倒数 ≈ 股权盈利收益率，与无风险/类现金收益比较（粗筛，不是完整模型）。  
- 换仓标准：机会比其他可选机会「稍微好那么一些」且前提仍成立；没有固定公式替代研究。  
- 技术走势不抬买点；不执行交易，输出仅个人研究。

## 底线

投资是为了将来更有能力消费而放弃今天的消费。不做无必要的险；做有价值的事，长期做，等待时间的回报。
