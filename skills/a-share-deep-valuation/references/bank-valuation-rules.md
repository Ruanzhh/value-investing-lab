# 银行分支 · 估值规则（叠在 v2.5 之上）
与 `valuation-rules-v25.md` 共用：hurdle 分档（银行为**总回报**）、买点 = FV3/(1+(h−y))³、仓位按熊市**总**三年回报、脆弱性、概率只展示、保守只计一次、禁止 Ke-then-hurdle。本文件只替换**情景驱动与 FV3 构造**，并定义股息抵扣 y 与退出 PB 中值方向。

## 情景驱动（替换出货×单位利润）
变量：NIM、贷款增速、信用成本、非息增速、费用率、分红率、拨备政策。
- 基准 = 中性经营预测；**不**默认拨备释放、**不**假设政策突然大幅回升息差。
- 拨备释放仅可进牛市，且不得与信用成本下降双计。
- 产出：三年末可持续 ROE、BPS（普通股）、常态化净利润、CET1。

## FV3 主路径（股权模型）
1. **BPS 路径**：BPS₃ = BPS₀ × Π(1 + ROE_t × (1−payout_t))（与 CET1/RWA 约束一致；`g ≈ ROE×(1−payout)`）。
2. **退出 PB**：本股历史 **PB_MRQ** 20/50/80 分位（结构可比窗口规则同 v2.5，≥4 年 + 稳定性检验）。回退档（经验值/待回测，按质量）：
   - 优质（长期 ROA≳1%、CET1 充裕）：0.80 / 1.00 / 1.20
   - 普通：0.60 / 0.80 / 1.00
   - 回退档作**下限对照**；**仅当**窗口 P50 偏乐观（高于 fallback_base）时，基准退出 PB 可取 window_P50 与 fallback_base 中值下压；若窗口 P50 ≤ 回退，直接用窗口 P50，禁止中值上修。
3. **FV3** = BPS₃ × 退出 PB（普通股口径；扣减其他权益工具后的普通股 BPS）。
4. **交叉检验（必做其一）**：
   - 超额收益/理论 PB ≈ (ROE−g)/(Ke−g)（Ke 仅交叉，**不**再叠 hurdle）；
   - 或 DDM（稳态 payout = 1−g/ROE，分红受 CET1 约束）。
5. **禁止**：FCFF；把 ROE/当前 PB 写成已实现 IRR。

## 买点 / 仓位 / 卖点
- 买点 = 基准 FV3 / (1+(hurdle−y))³（y=前瞻可持续股息率；hurdle 为总回报）；另列纯价格买点 FV3/(1+h)³。老唐参照：若银行版三前提均满足，可与「三年后权益×折扣」取低——银行常用折扣需单独标注；否则仅参照。
- 仓位 / 脆弱性 / 卖点：同 v2.5，但仓位用熊市**总**三年回报（卖点：PE>50 或市值>三年后公允上限×150%；银行实务中 PE50 极少触及，以 PB/公允上限为主）。
- 决策卡须并列「无倍数修复」= min(主路径, 回退 PB 路径) 买点。

## 自检（银行）
1. 无 Ke-then-hurdle；无 ROE/PB 口号当 hurdle。
2. 真实 ROE（合意拨备）与报表 ROE 缺口已披露。
3. 未同时：下调 ROE + 过低回退 PB 双杀；未拨备释放+低信用成本双甜。
4. 基准公允≈市价时须说明。
5. 老唐③用内生资本证据，而非「银行要资本→B」。

## 复核清单增量
真实利润勾稽、ROE/PB 误用、拨备双计、资本–分红勾稽、零售分列（招行）。

## 银行 hurdle = 总回报（2026-10-22 补丁）
- **Hurdle 口径**：总回报（价格路径 + 股息），不是纯价格升值。
- **股息抵扣**：买点 = FV3 / (1+(h−y))³，其中 y 为**前瞻可持续股息率**（与基准 payout、BPS/ROE 路径一致），须书面论证；可与 trailing DPS/现价并列展示，但买点公式不用 trailing 抬高买点。
- **决策卡**：须并列「总回报买点」与「纯价格买点（y=0）」两列；仓位按熊市**总**三年回报（价格年化 + y）。
- **DDM 交叉**：股权模型主路径外，须做轻量 DDM/Gordon 或等价含息交叉（Ke 仅交叉，不叠 hurdle）。

## 退出 PB 中值规则（澄清）
- 回退档作下限对照。
- **仅当窗口 P50 偏乐观（高于优质回退 base）**时，基准退出 PB 可取 window_P50 与 fallback_base 的中值（下压）。
- **若窗口 P50 ≤ 回退 base**（窗口更严），基准直接用窗口 P50，**禁止**向回退中值上修。
- 「无倍数修复」并列列 = **min(主路径买点, 回退 PB 路径买点)**；若回退不更严须注明。
