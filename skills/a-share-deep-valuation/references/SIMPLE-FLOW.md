对人说话只用白话。算数时仍遵守 `valuation-rules-v3.md` 里的门槛与公式**数值**，但不要把那些章节代号念给用户听。

对照完整模式：`SIMPLE-vs-FULL.md`。用语对照（需要时才翻）：`user-facing-glossary.md`。  
投资透镜（分析 / 筛选 / 估值 / 置换）：[`INVESTMENT-LENS.md`](INVESTMENT-LENS.md)。

## 核心思想

1. 不编造：缺材料就写缺什么、影响什么。
2. 基准情景 = 最可能的中性经营路径。
3. 先估「大约三年后合理股价」，再谈买不买得便宜。
4. 买入要留安全边际（按要求回报折回来的买入闸价）；材料不够就说「买点未正式启用」，但仍可出研究结论。
5. 同一风险只打折一次。
6. 技术走势不能把买点抬高；定稿前尽量独立挑刺。
7. **看懂生意是估值前提**：单位经济与周期位置没写清楚，不得进入「合理价与闸价」。
8. **筛选三前提**：利润为真 · 利润可持续 · 维持当前盈利不需大量资本（详见 INVESTMENT-LENS）。
9. **估值本质是比较**：相对类现金与其他机会是否明显更好；不追求假装精确到唯一价格。

## 六步

进度只报这些标题：【收材料】【看懂生意】【经营情景】【合理价与闸价】【独立挑刺】【结论卡】  
产物目录：`<代码>_simple_<YYYYMMDD>/`

### 1. 收材料
最少：现价与日期、总股本、最近年报 + 最新季报要点、缺项清单。  
材料薄：继续估基准线并写清不确定；不编分部利润或一致预期。缺项只阻止「买点正式启用」。

### 2. 看懂生意（深度必做）
按 [`BUSINESS-DEPTH.md`](BUSINESS-DEPTH.md) 先过两层三性：生意质量（被需要 / 难替代 / 价格不受管制）+ **筛选三性（利润为真 / 可持续 / 维持盈利不需大量资本·含现金转化）**，再写清七块；波特五力与护城河类型写进竞争一节。  
筛选三性必须写出「过 / 打折 / 不过」；现金转化不过关 → **不得进入**「合理价与闸价」。  
电池等适用行业再加分部/原材料传导/海外爬坡等要点。  
产出 `business_understanding.md`；材料薄就标明未知，**禁止**用空话「龙头/高壁垒」过关。  
不要为了过关去堆英文字段名或字母检查代号。

### 3. 经营情景
**默认只做基准情景**：最可能的中性经营路径；一句话假设 + 约三年主利润指标。  
周期类生意：基准用中位/正常化利润，不用高峰年利润当基准。  
底稿里如需自检悲观/乐观，可内部留一笔，**不要**对人报熊/基/牛三档。

### 4. 合理价与闸价（只走利润轨）
最少：约三年**基准**合理价（一条主线 = 基准净利润 × 退出市盈率）；买入闸价草稿；是否具备正式启用条件；现价对照。  
定价**只有这一条主线**。自由现金流只在步骤 2 的筛选三性里判定能否用净利近似业主盈余、以及是否对利润打折；**不**再单独估一条现金流合理价。  
粗对照（股权盈利收益率、无风险收益倒数等）与主路径差很大时：退回步骤 2 重判现金转化 / 利润是否打折。  
材料或交叉不够：仍给基准合理价与草稿闸价，并写明「买点未正式启用」及原因——**不得**写成可执行到价。  
**对人输出禁止**「熊/基/牛」三档合理价；只报基准线。  

**退出市盈率（主报硬规则 · 2026-11-06）**  
- 主报退出倍数在约 **20～30** 内，按生意质量、周期位置、定价权/难替代**判断取值**，并在驱动树写清理由。  
- 历史同年市盈率中位数、修剪窗、卖方倍数等**只作参照与交叉**，**不得**直接当作主报退出倍数。  
- 增长扩张期的高成交倍数不得抬主报；去库/利润压力期的低倍数不得机械当稳态锚。  
- 弱护城河、强周期、区域龙头偏带下沿（约 20–25）；强定价权、稳定轻资本可偏上沿（约 25–30），仍须书面理由。  
- 带外（<20 或 >30）须写例外理由并交挑刺/用户；不得默默用历史中位越带。  

交叉提醒（不改闸价公式）：三年后约 15～25 倍市盈率卖出能否大约翻倍；高杠杆更严。粗对照股权盈利收益率（市盈率倒数）与类现金收益，只作筛选提示。

### 5. 独立挑刺
最少：指出最可能的乐观假设、是否重复扣险、基准是否偏松；改完再定稿。  
顺带检查：利润是否像假钱、维持盈利是否吞大量资本、护城河是否经不起五力冲击。

### 6. 结论卡
只写人读层（见 `card-template.md`）：结论、约三年**基准**合理价、买入闸价与是否启用、到价否、动作、最大风险。  
动作语义可含「相对其他机会是否值得置换/持有/观望」，但仍不执行交易。  
个人研究，非投资建议。
