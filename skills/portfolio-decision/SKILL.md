# 组合决策

依据 [价值投资理念](../value-investing/SKILL.md)，将已有研究转化为具体用户的资金安排。计算时读取 [计算口径](references/calculation-principles.md)；研究缺失或关键判断失效时，转交 [深估过程](../deep-valuation/SKILL.md) 补足，不凭主页买入价直接分配资金。

## 每次调用的固定提示

每次开始新的组合分析，在首次回复中原样展示以下文案，随后继续；同一次任务的后续回复不重复。默认不询问可承受损失、预计用款时间，也不要求逐项确认。用户已明确透露前提冲突时，指出冲突并调整分析，不继续按不成立的前提给出配置。

> **使用前提与风险提示**
>
> 本分析默认：你提供的可投资资金已扣除生活支出、应急储备及已知用款需求，能够长期持有，且不使用借款或融资杠杆。
>
> 分析默认采用三年测算期和18%目标年化收益要求。三年不是到期卖出承诺，18%也不是收益保证。已有研究可能过时，估值依赖假设；即使达到合理买入价，也可能出现较大亏损或永久本金损失。
>
> 建议仅覆盖你提供的持仓与资金，请自行核对遗漏资产、资金用途和实际交易限制。若上述前提不成立，请先说明，以便调整分析。

## 四条决策规则

1. **买入**：研究仍有效，最新价格对应的预期年化达到默认18%；不额外机械打折。
2. **仓位**：合格机会原则上等权；单家公司主动配置不超过20%，同类风险不超过40%。被动超限时复核，不自动卖出；不为凑等权强制换仓。这两个比例是管理上限，不是模型推导的最优仓位。
3. **现金**：没有合格机会就保留现金，不设固定现金比例，不为满仓降低标准。
4. **持有与调整**：不因涨跌或预期收益低于18%自动卖出；原判断失效，或替代机会扣除成本并考虑不确定性后仍明显更优时，再减持或换仓。

## 输入与产出

- 只补问影响计算的缺失信息：持仓代码、股份类别与数量，可投资现金及币种、可交易市场；行情与研究由 Agent 核验。
- 给出一份明确方案：各标的动作、金额或数量、调整后权重和理由，以及剩余现金、主要下行风险与信息缺口。“维持持仓”或“暂不操作”也是完整结果。
- 私人持仓、资金及方案不写入公开仓库、报告或 Issue；需保存时使用用户指定的私人位置。本技能不授予下单或发送私人信息的权限。
