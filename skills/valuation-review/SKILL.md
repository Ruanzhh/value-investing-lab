# 估值审查

依据 [价值投资理念](../value-investing/SKILL.md) 与 [量化原则](../value-investing/references/quantitative-principles.md) 审查，不另设估值规则；需要重新研究时沿用 [深估过程](../deep-valuation/SKILL.md)。

模型可以自洽而假设缺乏依据。先找最可能改变结论的推导，从原始证据重建，再与报告核对，避免沿着原结论补理由。自查不称独立审阅。

## 审查重点

1. **证据是否支持判断**：明确复核时点，区分原报告当时可知事实与后续新信息，核对重要公告；分清事实、管理层解释与预测。主动阅读有不同解释的机构研究和个人分析，追溯关键论据；注明原件、公开正文、摘要或仅搜索摘录，同源转载不算独立印证。不以篇数、耗时或章节齐全证明充分。
2. **分歧是否落实到经营**：将看多、看空观点拆成量价、利润率、费用、再投入与持续时间的差异，核实季节性、周期及所谓一次性因素。份额、装机、收入增长不自动等于每股价值增长；检查护城河、管理层激励及资本配置能否支持利润和现金回报。评级、目标价与历史估值底部不代替推导，也不直接平均不同口径的估值。
3. **股东究竟能拿到什么**：贯通经营利润、归母利润、可分配现金及每股价值，检查少数权益、收购计量、研发资本化、维持与增长投入、营运资本及现金义务。期后收购、分红、回购和发行同时更新现金、收益归属与股数，避免只计好处、遗漏成本或重复计价。
4. **模型是否经得起反证**：实际复算关键路径，核对日期、币种、税费、联合概率、倍数依据及现金分配，检查正文与模型一致。对最敏感且证据最弱的假设做反推和不利测试，检验正常经营但估值压缩、盈利受损及兑现延迟；公式正确不能证明经济假设成立，发现问题也不意味着价值必然下调。

## 形成结论

复核报告的[公司质量评级](../value-investing/references/company-quality.md)及仓位上限是否匹配，检查四项判断能否由研究时点的材料支持。区分经营质量变化与估值变化，指出决定档位的反证。旧报告缺评级时注明缺项；受托更新报告时补评并同步开篇评级行。

- 完成能够执行的取证和复算后，按对投资判断的影响报告实质问题：**原判断 → 证据或反证 → 对参数与结论的影响**。量化重要影响；暂不能量化时说明缺什么及为何重要，不以待办代替审查。
- 明确结论可保留、需修订或依据不足暂不能定价；无重大问题也说明审查范围和残余不确定性，不为凑问题而挑错。
- 用户要求修订时，完成模型重算并同步报告与附录，解释相对原估值改了什么、为什么；仅要求审查时交付意见。材料组织沿用 [产出结构](../deep-valuation/references/output-structure.md)，不另造重复报告或验收清单。
- 关键反证已处理、剩余缺口的影响已说明时收束；无法公开核实就保留条件或暂停定价，不用更多同源材料掩盖未知。
