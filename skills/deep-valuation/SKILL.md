# 深估过程

围绕影响投资结论的关键未知推进研究。先读 [价值投资理念](../value-investing/SKILL.md)，量化时读取其 [量化原则](../value-investing/references/quantitative-principles.md)，此处不另设估值规则。

## 研究主线

1. **理解生意**：明确标的、市场与研究时点，了解盈利机制、竞争位置和财务轮廓，找出最影响投资判断的未知问题。
2. **深挖问题**：按对结论的影响排序，优先核对公告、财报等原始证据，结合竞争者和历史变化检验解释。围绕问题取证，不以材料数量代替理解；无法核实的内容保留为缺口。
3. **量化判断**：把经营理解转化为盈利、现金、价值与回报。用敏感性找出决定结果的参数，再检查其依据；不从现价倒推使其显得便宜的假设。
4. **反向挑战**：寻找最强反方解释，核对关键事实、假设与计算。反证指向哪里，就回到对应问题修正；尚未解决的分歧如实保留，自查不称作独立审阅。
5. **形成报告**：以概率加权主预测明确结论，围绕最重要的判断与争议组织正文，将情景、权重依据及必要证据和计算放入附录，遵循 [产出结构](references/output-structure.md)。

## 推进与停止

- 上述主线允许往返。每次补查针对一个可能改变结论的问题，不因局部修改重跑全部研究。
- 关键问题已有足够证据、重要反证得到处理，新增研究不再实质改变判断时，可以收束；不以章节填满或达到固定轮次为完成标准。
- 公开信息无法解决关键问题时，说明其影响，形成条件性结论或暂不估值；超出能力圈或发现不可接受的问题时，可以结束该标的研究。

## 产出原则

主报告应能独立阅读：结论清楚，推导完整，事实与假设分明，关键证据可追溯、数字可复算，重要反证、未解问题和判断更新条件充分表达。标题、顺序和篇幅由公司的关键问题决定，不套固定章节，也不强求买入点。
