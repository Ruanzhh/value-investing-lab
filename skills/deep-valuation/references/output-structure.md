# 产出结构

目录和入口固定，正文结构自由：

```text
reports/<代码>-<中文公司名>/
├── README.md          唯一主报告
├── evidence/
│   ├── README.md      来源索引、证据入口与缺口
│   └── raw/           原始材料（取得原件时创建）
└── valuation/
    └── README.md      假设、计算依据与适用范围
```

- **主报告**：注明研究日期和币种；集中呈现研究判断与单一概率加权主预测，就近链接支撑它们的证据和计算。讨论具体股价时注明其时点，详细底稿不重复铺入正文。
- **证据附录**：索引注明材料来源、期间、性质和缺口。专题证据及实质性审阅异议按需分文件；原始材料与研究解释分开，没有原件时不以摘要冒充。
- **估值附录**：保留实际采用的假设、输入、公式、敏感性及必要计算文件。结果应能沿输入和公式复算；只有实际提供可运行文件时才称程序可复现。
- 三个 `README.md` 为固定入口，其余文件按需命名。缺少原件或无法估值时在对应入口说明，不创建空白材料占位。
- 每家公司只维护一篇主报告，不并列结论卡、阅读版或多份报告。附录仅保留支持结论或帮助复核的材料，不收录执行日志、评审请求及重复副本；旧版本由 Git 历史保存。
- 更新已有研究时，明确哪些事实、假设及结论发生变化，保留未解决的实质异议。新增内容不自动证明旧数据已重新核验。

## 主报告的大体内容

建议按“判断 → 生意与事实 → 未来推导 → 价格 → 挑战与更新”的阅读顺序展开。以下是需要覆盖的内容，不是固定章节；可以合并、调整顺序，并围绕公司的核心争议命名标题。

| 内容 | 读者应能理解什么 |
|------|--------------------|
| 核心判断 | 怎样评价这门生意及当前价格，主要理由和最大不确定性是什么。开篇用简短文字给出判断，并按下述规范摘要呈现关键结果。 |
| 生意与经营事实 | 企业怎样赚钱、优势为何能够持续或正在削弱；关键经营与财务变化如何支持或挑战判断。只保留有助于理解结论的公司背景。 |
| 未来推导 | 从经营驱动如何推导未来盈利、资本投入和股东现金；哪些是事实，哪些是假设，最敏感的因素是什么。 |
| 估值与买入条件 | 三年后概率加权盈利与股权价值主预测如何得到，现金转化和再投入能否支持；现价回报与买入条件采用何种口径，关键下行风险是什么。完整情景及权重放附录，不让读者自行挑选主结论。当前价值可另估；无法量化时说明缺口。 |
| 反方与判断更新 | 最有力的反对意见是什么，哪些问题尚未解决，什么证据会推翻判断或要求重新估值。 |

## 主报告中的规范摘要

主报告开头包含且仅包含一个以下格式的摘要块，仅存放研究信息与估值结论，供读者阅读和后续脚本提取。实际报告直接使用 Markdown 表格，不包代码围栏；保留标记、字段名与顺序，替换示例值。正文其余部分自由组织。

```markdown
<!-- research-summary:v2 -->
| 字段 | 内容 |
| --- | --- |
| 公司 | 中文公司名 |
| 证券代码 | 原始代码，保留前导零 |
| 市场 | 交易所及股份类别 |
| 币种 | CNY |
| 研究日期 | YYYY-MM-DD |
| 预测到期日 | YYYY-MM-DD |
| 期末预期股权价值（亿元） | 未给出 |
| 研究结论 | 一句话概括当前判断 |
| 核心风险 | 一句话说明最重要风险 |
| 未给出说明 | 指明缺失字段及原因，无缺失时写“不适用” |
<!-- /research-summary -->
```

- 日期用 `YYYY-MM-DD`，币种用 ISO 代码。股权价值以该币种的亿为单位（如币种 USD 则为亿美元），填写纯数值，不带单位或千分位。字段内不插入换行、链接或竖线，详细来源放正文或附录。
- 预测到期日是价值预测对应的实际日期；期末预期股权价值是该日归属母公司普通股股东的整体价值的概率加权期望值，包含届时尚未分配且未重复计价的非经营净资产，不含此前已分出的现金。它不是今天的合理价值、买入上限或企业价值（EV）。研究结论聚焦生意与价值，不写随行情变化的“已到买点”等状态。
- v2替换v1的当前价值字段；迁移时从实际预测读取到期日与期望值，不给旧数改名冒充新口径。后续脚本必须结合期间分配及股数变化计算回报或买入金额，不能将期末价值与当前市值直接当作同日估值比较。股本、股份类别、稀释及汇率须匹配，不能用流通市值代替总市值，也不能将EV当成股权价值。
- 缺失或无法可靠量化时统一填“未给出”，并在末行解释；不得用零代替缺失，也不得为填表补造或沿用已撤回的估值。示例中的币种须与实际研究一致。
- 摘要与正文结论同步，`valuation/` 保留输入、假设和计算依据，不另建单家公司摘要文件。**本技能不创建或更新跨公司总览，也不负责汇总脚本；总览由后续独立脚本从主报告提取。**
- 摘要不保存参考股价、实时市值、建议买入价或预期年化。后续脚本读取行情及估值附录中的联合情景、概率、期末价值、股数变化、期间现金分配、日期和税费汇率口径，换算为同一股东持有口径；预期年化统一先加权现金流、再求IRR，首次出现注明此定义，不并列展示情景IRR均值。买入上限依 [量化原则](../../value-investing/references/quantitative-principles.md) 按默认18%目标年化反推，用户另行指定时覆盖；正文说明目标、对应价格及等价市值，附录说明投资者计价币种、名义税后假设及不利结果，不另叠加折扣。缺少必要依据时不生成对应指标。
- 不能把估值与市值的差额直接年化。行情刷新不等于经营预测刷新，剩余期限须按实际日期处理，不能将旧预测自动延长为新的完整持有期。

## 可读性

- 正文用连贯段落解释“判断、依据及其含义”，不要写成资料摘要或研究步骤清单。标题表达具体问题或观点，篇幅集中在重要且有争议的推导。
- 正文只突出一个概率加权主预测，交代决定判断的依据和风险；情景表、权重推导与敏感性集中于估值附录，不以多个并列答案代替结论。
- 数字注明期间、单位和口径；表格用于关键数据对比，正文解释它们为何重要。估值在正文保留关键假设和推导，完整计算放附录，不能只报结果再让读者自行查底稿。
- 关键依据就近链接，术语首次出现时简要解释；避免重复结论、堆砌指标，以及把内部流程和文件名当作论证。
