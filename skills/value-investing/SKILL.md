# 价值投资理念

买股票就是买企业。在能力圈内理解企业如何创造股东价值，以有安全边际的价格投资，追求税费后的实际购买力增长，依据事实持续修正判断。

## 投资

- **能力圈**：理解盈利机制、客户选择和竞争优势，区分事实、假设与未知。信心来自可检验的理解，不能用股价表现或个人确信证明判断正确。
- **生意与人**：关注需求、盈利持续性、资本需求，以及管理层诚信、激励和企业文化；判断定价权与资本效率能否抵御通胀。
- **每股价值**：增长只有在新增投入创造足够回报时才有价值；再投资、收购、分红和回购都应以每股价值衡量。
- **永久损失**：区分股价波动与价值损毁，避免杠杆和资金期限迫使自己退出。

## 估值

- 价值来自企业未来可供股东取得的现金；核查会计利润与维持、增长投入的关系。增长投入减少近期现金，是否创造价值取决于投入回报。
- 根据经营机制判断盈利、资本需求和持续时间，以概率加权的期望值形成明确主预测；概率依据与不确定性保留在附录，不能用情景罗列代替判断。
- 区分今天的价值、未来价值和市场价格；具体方法见 [量化原则](references/quantitative-principles.md)。

## 买入与持有

- 好公司也可能买贵，低估值也可能是陷阱。价格须有价值支撑，回报不能完全依赖乐观预期或估值扩张。
- 安全边际是预测出错后仍能接受的余量，以买入折扣或收益率余量表达，并用不利情景检验；两种表达不重复叠加，也不能靠折价弥补根本看不懂。
- 比较机会成本，选择回报值得承担风险、资金允许等待的机会；没有合适机会可以不买。
- 长期持有以逻辑成立为前提。主动寻找反证，在竞争、管理、财务、价格或替代机会实质变化时重新判断。
