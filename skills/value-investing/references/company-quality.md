# 公司质量评级

在研究时点，判断哪些企业特征足以支持股东集中持有。围绕以下四个维度分别给出判断，链接有日期的事实，交代最有力的反例或尚未核实之处。

| 维度 | 怎样判别 |
| --- | --- |
| 护城河 | 解释客户为什么留下、竞争者复制需要付出什么代价。用提价后的留存、竞争加剧时的份额与资本回报等现象检验，并排查景气或补贴带来的暂时优势。 |
| 利润质量 | 将多年归母盈利与股东可得现金对照，追查一次性收益、回款、必要资本开支及少数股东归属。对扩张期现金流偏低的公司，区分维持投入与有望取得回报的增长投入。 |
| 公司文化 | 从组织的制度和反复发生的选择取证。尤其看销售压力、产品事故或行业下行时，公司怎样对待客户、质量和内部纠错。价值观宣言只能作为待验证的主张。 |
| 管理层 | 将当时可查的承诺与后续兑现逐项对照，结合资本配置的每股结果、薪酬激励、关联交易及失误后的披露和纠正，判断能力与诚信。 |

## 综合定级

按下表选择证据能够支持的最高档。用文字解释决定档位的长处和短板，尤其说明最弱一项会怎样影响长期股东回报。四项之间有因果关联，同一事实可从不同角度解释，避免重复加分。市价、目标回报和已有持仓均不参与定级。

| 公司质量评级 | 单家公司仓位上限 | 判定依据 |
| --- | ---: | --- |
| A | 30% | 护城河的持续性和利润的现金含量有跨期证据，文化与管理层在有代价的取舍中体现长期股东利益。已核对重要反证，四项均有充分依据支持集中持有。 |
| B | 20% | 有可验证的竞争优势和盈利基础，文化及管理层行为总体支持股东利益；优势持续时间、现金转化或组织与管理记录仍有一项重要限制，报告能说明其影响范围。 |
| C | 10% | 仍有可核实的长期持有理由，但竞争优势、利润兑现或治理记录只能支持有限仓位。写明主要短板及其影响。 |
| D | 0% | **不建议购买。** 有实质证据表明投资理由已经失效，或关键事实无法核实到足以支持任何新增仓位。例如核心利润或现金披露失去可信基础、管理层严重损害普通股东利益，或竞争优势持续流失且难以解释未来股东现金从何而来。 |

评级给出主动配置上限，实际配置可为零。评 D 时，写明哪项事实或关键缺口足以否决购买，以及什么证据出现后可以重新评估。估值过高只影响当期买入判断；即使模型价格很低，D 级也排除新建仓和加仓。缺少评级的旧报告须按四个维度补评。

首次评级写出最可能导致改档的可观察事实。复评时保留前档、说明新证据以及它为何足以改变或维持原判断；单纯股价变化只更新预期回报。
