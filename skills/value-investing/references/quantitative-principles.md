# 量化原则

主线为：预测三年正常化盈利 → 核查现金与再投入 → 形成概率加权主预测 → 测算持有回报与买入上限 → 检验容错能力。显式预测期与持有测算期均默认三年；不是企业寿命或必须卖出的日期。默认目标年化18%，用于反推合理买入价；用户另有明确要求时覆盖。不预设统一PE或额外买入折扣，不为使现价合格而调整参数。

## 盈利、现金与增长投入

- 从正常化归母净利润出发，用销量、价格、利润率及资本需求解释增长，区分事实、假设与未知，不外推一次性收益或周期高点。基准取最有依据的正常判断，不因安全边际机械压低经营参数；有依据的不利结果进入联合情景及概率判断。
- 核查利润真实性、持续性和现金转化，拆分维持投入、增长投入与营运资金变化。维持投入不能机械等于折旧；利润真实不等于可以全额分配，维持盈利投入少也不代表增长免费。
- 普通非金融企业的股权自由现金流可概括为：净利润＋非现金费用净调整－资本开支－非现金经营营运资金增加＋净债务融资。统一股东归属口径，并检查债务可持续性。
- **增长投入按回报判断**：高回报再投资会减少近期自由现金流，但可能创造价值；不能仅凭扩张期自由现金流低就否定盈利质量或机械降低倍数。反过来，不能既预测增长，又忽略实现增长所需的资金、融资与稀释。
- 可分配现金不等于实际分红。留存、回购、收购及融资落实到期末资产、盈利与股数；回购不算持续持股者收到的现金。处理受限资金、必要经营现金、相关义务、少数股东权益及资本配置损失。

## 主估值：三年后盈利与合理倍数

正常化盈利可估、现金转化和资本需求可解释时，优先采用：

```text
期末经营股权价值区间 = 第三年正常化归母经营净利润 × 合理PE区间
期末整体股权价值 = 期末经营股权价值 + 尚未计价的非经营净资产
```

- **口径匹配**：这里的归母经营净利润是扣除融资成本、所得税及少数股东损益后的归母盈利，并剔除单独估值资产的收益；不是EBIT或NOPAT。PE不能直接乘企业自由现金流，净利润已承担债务利息时不再机械扣全部债务。非经营资产及其收益只能计价一次。
- **倍数必须解释**：依据盈利持续性、现金转化、增长及再投资回报、资本结构和机会成本给出区间，说明上下端对应的经营条件及下调原因。历史与同行估值仅作交叉参照；25–30倍、利率倒数和“好公司”标签均不能单独构成依据。
- **联合情景**：先说明各情景覆盖的经营与估值状态，再赋概率；既检查盈利与倍数同时下降，也检查盈利正常但倍数压缩等重要组合，不机械绑定高利润与高PE。情景避免重叠，影响主结论的遗漏应补入或明确列为预测缺口；不同方法的口径分歧先解决，不能直接平均。
- **单一主预测**：正文给概率加权的期望盈利与期末股权价值，情景细节留附录。先算每条联合路径，再按总和为100%的概率加权，不能用平均利润乘平均PE。期望值不称为“最可能值”；证据不足时给明确标注的暂定主观估计，确实无法判断则说明，不能只列情景交由读者选择。
- **概率可挑战**：记录权重与情景代表值的依据、证据更新条件及敏感性；不机械取区间中点或上沿，也不把语言模型的自报信心当作校准概率。主观概率不冒充统计频率，不规定跨公司的默认权重，不为了期望价格调整概率。
- **方法服从生意**：周期企业用正常化盈利，银行与保险考虑监管资本下的分配能力，资产处置考虑可实现净值与时间。第三年仍在扩张不自动排除PE；盈利无法正常化、再投入或现金归属无法解释时，不强套倍数，可采用更适用的方法或暂不定价。

## 持有回报与买入上限

先按概率加权期间每股现金分配和期末每股价值，再结合买入支出计算预期年化；期末价格有估值依据，但市场未必按时认可。

```text
买入价及买入费用 = Σ[t=1…H](税后每股现金分配_t / (1+r)^t)
                    + 扣除卖出费用的期末每股价格 / (1+r)^H
```

- **合理买入价**：按用户指定的默认目标年化 `r=18%`，以概率加权现金流反推含税费的买入价格上限，并换算同口径等价市值；用户明确另设目标时覆盖并注明。18%是投资收益要求，不是盈利预测、当前合理估值的默认折现率或实际预期收益；给定市场价格时仍须计算真实对应的模型年化。
- **收益基准**：18%指投资者计价币种下、扣除所假设税费后的名义年化，不扣通胀。计价币种未指定时暂用报告币种并注明；附录列明税费、汇率及未建模项目，未知税率不能默认为已确认免税。不同币种或税前税后结果不能直接比较。
- **统一回报口径**：本框架的“预期年化”统一指期望现金流对应的IRR：先按同一股东口径加权各期分配与期末每股价值，再计算年化；买入上限也按此口径反推。它不等于各情景IRR的概率加权均值，后者仅按需留在附录，不作为并列主指标。未加权的单一路径回报不称为概率加权预期收益。
- 改变目标回报时固定同一组经营预测、期末倍数与分红；改动这些因素应另列估值情景。日期按实际时间、税费按明确口径计算；币种及名义/实际回报一致。
- 计算统一到同一持续持股者的每股口径，再乘当前同口径普通股股数得到买入市值上限。处理留存、分配及稀释，不把分红与已分出的期末现金重复计价，不把整体价值增长当作每股增长。

## 安全边际：用偏差检验容错

- 在现价或选定买入上限下，列示基准与不利情景年化、累计盈亏，检查盈利与倍数同时下降以及价值兑现延迟。经营变量按因果联动，不机械压低所有参数；情景不是价值下限或最大损失保证。
- 反推达到目标回报或盈亏平衡所需的关键利润、倍数等条件，说明允许预测错到什么程度。盈亏平衡是参照，不默认要求不利情景零亏损。
- 按默认18%或用户另定的目标回报检验买入条件；另有损失容忍时逐项检验，不满足则降低买入上限或放弃。未给出损失容忍时披露结果，不自设亏损偏好或宣称风险可接受。重大偿债、治理或能力圈问题不能靠高目标回报解决。
- 安全边际可表达为价格折扣或收益余量，不额外机械打折。同一风险已进入盈利、资产或倍数假设时，不再无解释地扣一笔误差准备；不同风险分别说明。收益率高不自动意味着永久损失风险低。

## 辅助估值与结果表达

现金流折现只在有必要且现金流路径可解释时辅助检查倍数，不要求每家公司运行。若结论主要依赖缺乏依据的长期增长、资本回报或折现率，不以增加预测阶段制造精度；列示敏感性，不用复杂模型推翻证据更充分的经营判断。使用DCF时保持增长与再投入匹配、现金流与折现率口径一致，避免终值、留存现金、非经营资产和债务重复计价。

三年后价值、当前合理价值与买入上限分别命名。主分析提供概率加权的未来价值主预测和回报关系，不强制倒算当前点估值；目标回报折现得到的是对应投资要求的买入上限，不能冒充独立的当前合理价值。若另估当前价值，说明该时点的盈利、倍数或现金流依据；不得把未来盈利乘PE直接写成今天的价值。

附录保留预测日期、盈利及倍数区间依据、现金转化与再投入、期末股数、期间分配、税费、目标回报来源及不利结果。反向检查现价隐含的经营要求；关键依据不足时保留条件性结论或暂不定价。
