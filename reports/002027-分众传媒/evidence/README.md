## 三种利润不能混用

2025归母29.4633、扣非27.1939，均受到数禾21.5234亿元长期股权投资减值影响。年末所持数禾账面29.4384降至可收回7.9150；2025全年权益法投资收益为0.5567，不能只加回第四季度亏损、却保留前三季度收益，得到偏高的广告经营利润。税务调节又有未确认递延税资产，不可机械把减值乘75%加回。[S2](raw/2025-annual.pdf)

2026前三季归母44.7566，扣非35.8802。非经常性损益8.8764，其中数禾退出有资本公积转回5.6469、相关递延税负债转回1.4076。处置合同价7.9150已经对应旧资产的变现：已收5.9758在账上，待收1.9392在其他应收款；资本公积转回不是又收到5.6469现金。2025同期权益法收益4.3037，2026已几乎为零，直接用扣非同比-10.41%代表广告主业跌幅会夸大下降。[S4](raw/2026-q3.pdf)

估值因而采用收入、广告成本、费用、融资成本、信用损失、经营相关补助、所得税及少数股东逐项重建；现金和投资资产的收益从PE盈利中剔除。正常化是研究估计，不是公司另披露的财务指标，详见[估值附录](../valuation/README.md)。

## 新潮不是买到一份现成高利润

新潮2024/2025收入19.8829/17.2664，归母0.4190/0.5406；2025所得税为收益0.1008、少数亏损0.0597，净利润并非纯经营现金。2026Q1归母0.1877不能简单乘四当全年。2026-03末应收净额5.5055，对应原值9.5058、坏账准备4.0003，约42.1%的准备率说明历史客户信用问题；这是存量累计准备，不是当年坏账率。[S6](raw/xinchao-2026-q1-audit.pdf)

两笔交易合计83亿元，其中股份77.647751、现金5.35225；完成后新增15.34540509亿股，总股本159.76740235亿股，相比现在增加10.625%。按旧股东口径，若旧业务正常利润50亿元，仅维持EPS就需新增归母利润约5.31亿元，远高于新潮2025的0.54亿元；这还未要求收购获得超额回报。[S3 p175](raw/2026-h1.pdf)、[S5](raw/2026-09-acquisition-summary.pdf)

备考以100%收购为前提，现金对价列其他应付款，并未实际支付。不能既采用其备考现金余额又漏扣现金对价。商誉46.70亿元是备考总额，不是新增损失；新增点位合约等摊销、整合支出和潜在商誉减值须分别处理。模型没有把商誉列为额外可变现资产，也不以已经下调的盈利再扣同一笔商誉损失。[S7](raw/2026-09-proforma.pdf)

## 核查覆盖与剩余缺口

截至2026-11-19，本次检索覆盖巨潮、交易所披露链接、公司公告公开索引、公司IR资料、市监总局、公司历史问询、机构及个人分析；新事项窗口重点覆盖2026-09-24至研究日。已见最新定期报告为10月28日三季报，在这些来源中未检得之后的交割或新增分红公告。官网/搜索索引可能滞后，**不据此断言绝无未检得披露，也不把附条件批准写成完成交割**。首次完整核查截止日记录为2026-11-19，后续须补查迟入库公告。

影响最大的公开缺口是逐城真实成交价、刊挂率、客户续投与点位重合的精细数据；新潮交割日资产、整合预算和最终购买价分摊；海外增资后盈利归属、全部资金上划条件；长期基金逐项目可变现价值；2027年后的现金分红计划。它们分别进入收入/利润率、联合情景、净资产回收与现金分配假设，不能以“市场份额高”替代。核心研究仍可做条件性定价，但不支持精确到分的确定价值。
