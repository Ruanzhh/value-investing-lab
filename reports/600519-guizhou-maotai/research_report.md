## 3. 公司地位

### 市占率走势

公司**不披露**名为「市占率」的官方序列（公开信息已尽，查过年报分产品 / 行业章节）。可跟踪的替代指标：

- **价值集中**：见上节 2022→2024 营业收入 / 行业销售额由约 18.7% 升至约 21.5%；2025 行业销售额年报不再转引，无法续写该代理。  
- **茅台酒（利润锚）**：2025 收入 **1,465.00 亿**（+0.39%），销量 **4.675 万吨**（+0.73%），毛利率 93.53%（−0.53 个百分点）。2024 销量 4.641 万吨、收入 1,459.28 亿。出处：AR2025 / AR2024 产品档次表。  
- **系列酒**：2025 收入 **222.75 亿**（**−9.76%**），销量 3.835 万吨（+3.88%），毛利率 76.11%——量增价跌，是本轮拖累项。  
- **总量**：酒类销量 8.510 万吨（+2.13%），收入却 −1.08%（酒类主营 1,687.75 亿），结构比销量更能解释盈利。

### 客户结构与集中度

- **前五名客户**销售额 170.46 亿，占年度销售总额 **10.10%**（其中关联方 63.58 亿、占 3.77%）——集中度低，不依赖单一大客户。出处：AR2025。  
- **经销商**：2025 年末国内 2,353 家、国外 126 家；2026 年三季报末国内 2,285、国外 124（变动主要为系列酒经销商）。  
- **渠道权重**：2025 直销收入 845.43 亿（+12.96%）vs 批发代理 842.32 亿（−12.05%），直销约占酒类收入 **50.1%**；2026 年前三季直销 737.74 亿 / 批发 571.20 亿，直销约占 **56.4%**。直销 = 自营 +「i 茅台」等；批发 = 社会经销商、商超、电商。  
- **i 茅台**：2025 年平台酒类不含税收入 130.31 亿（−34.92%），毛利率 94.47%；2026 年前三季 58.56 亿。线上从高位回落，不改变「直销权重抬升」的大方向。  
- **区域**：2025 国外收入 48.50 亿，占酒类主营约 **2.87%**（`business_understanding.md` 写作约 2.9%）；2026 年前三季国外 16.41 亿。海外不是利润主引擎。  
- **预收 / 合同负债**：2023 年末约 141 亿 → 2025 年末约 80 亿 → 2026 年三季度末 **20.84 亿**。预收叙事弱化，属周期换档，不是应收占款恶化（Q3 应收 3.65 亿，相对收入仍很小）。

## 4. 生意模式与护城河

### 生意质量三性（分析透镜）

| 性 | 判定 | 一句 |
|----|------|------|
| 被需要 | **过（有条件）** | 终端与礼赠发起人付钱；场景为礼赠、家宴 / 自饮、商务、收藏 / 囤货。社交「硬通货」属性仍在，但非生理刚需。场景定量占比公开信息已尽 |
| 很难被替代 | **过** | 赤水河产区 + 酱香工艺 + **五年以上陈酿** → 供给无法当年扩产；飞天高端心智先占 |
| 价格不受管制 | **过（边界收窄）** | 合同价自主（非公用事业限价）；近批发约 1680–1710 vs 合同 1369，缓冲约 310–340 仍正，但提价弹性有限 |

总判：三项有证据，可估基准合理价与研究用闸价；需求结构定量与社会库存仍未知，**不宣称已深刻理解到可正式启用买点**。

### 筛选三性（含现金转化硬关）

| 性 | 结论 | 依据 |
|---|---|---|
| 利润为真 | **过** | 应收相对收入极小（Q3'26 应收 3.65 亿）；非变卖 / 重估堆利。OCF 波动须剥离财务公司吸收存款 / 拆出，不把口径扰动当假利润 |
| 利润可持续 | **过** | 情景对齐「筑底换档」；**不用** 2021–24 高峰增速；净利率中枢低于历史约 52% 的记忆锚 |
| 维持盈利不需大量资本（现金转化） | **过** | 见下；正常年净利润可近似业主盈余 → **估值只走 PE 轨，不再开现金流定价轨** |

- **净利率**：近五年归母 / 营业总收入约 47.9%–49.6%，2025 回落至约 47.9%。基准假设沿 48% 略升向 49–50%，**不回**约 52% 的历史记忆锚。

## 7. 估值与敏感度（仅 PE 轨）

公式（`valuation.md` / `valuation_calc.json`）：

```
FV3 = (960 × 26 + 1496.05) / 12.50081601 ≈ 2116.3 → 对外约 2116
A20 = (FV3 + n × 27.624) / (1.20)^n
    n = 1151/365.25 ≈ 3.1513
    ≈ (2116.3 + 87.05) / 1.7763 ≈ 1240.43 → 对外约 1240
```

| 项 | 主报 |
|---|---|
| 基准合理价 | **约 2116 元** |
| 研究用闸价 A20 | **约 1240 元**（用户 2026-11-06 拍板） |
| 对照 A18 | ≈ 1308（h=18%；不主报） |
| A20 / FV3 | ≈ **0.586**（落在约 0.55–0.62 交叉带） |
| 现价 vs 闸价 | 1452 > 1240 → **未到价** |
| 买点 | **未正式启用** |

**退出 PE = 26 的理由（判断带取整，非历史中位照抄）**：

- **质量**：飞天心智 + 产区 / 陈酿难替代 + 轻资本高 ROE + 现金转化过关 → 可偏带上沿半区（约 **25–30**）。  
- **周期**：筑底换档、批价缓冲约 310–340、提价期权弱（**非增长扩张期**）→ **不取** 28–30 上沿；去库 / 利润压力期的低倍数也**不**机械锚在 20–22。  
- **取值**：约 26，锁定 **26**——强护城河与周期压力之间的中上沿稳态假设；三年后卖出倍数仍落在「优质消费品合理稳态」，而非扩张叙事。  
- **带内**：是（20～30）。2026-11-06 按新标准复核后**无需改主报** FV3 / A20。  
- **参照（不进主报推导）**：结构窗 2021+ 同年 PE 中位约 30.31（含扩张期溢价，不得抬主报）；轻资产回退中枢约 22；旧算法中点下压曾得 26，与本次判断重合故保留取位。

**敏感性（不改主报）**：NI3 或退出 PE 变动 10%，FV3 约变动 9.44%。证伪情形下若试 NI3 = 900 / 850，只作为下修档示意，本轮基准仍为 960。超额现金对 FV3 不敏感（±10% → ±0.56%），故不下挖。

**交叉对照（附录性质，不是第二条合理价，不改闸价）**：

1. 三年后若按 15 / 20 / 25 倍（含超额现金）对照现价，倍数约 **0.88 / 1.14 / 1.40**——在 15–25× 带内难「约翻倍」。  
2. FY2025 股权盈利收益率粗约 **4.5%**，高于短端类现金，但差值不算明显厚。  
3. 现价隐含 NI3（按基准退出 PE 减超额）约 **637** 亿 ≪ 960，市场更悲观。只展示。  
4. 相对 2026-11-05 旧闸约 1227：仅 PE 轨后曾到 A20≈1247；本轮再因退出PE判断取整 26，闸价约 **1240**（相对旧1227约+13、相对1247约−7）；主因先取消两轨取低、再废止窗算法三位小数。未触发 >15% 退回关卡。

禁止所有者盈余折现轨、禁止 FCFE 第二合理价、禁止两轨取低。

**买点未正式启用的原因**：走的是简约路径，交叉提醒未齐（尤其是「15–25× 卖出约翻倍」这条偏弱）；材料上公开信息已尽，闸价仍给出研究用数字、不标草稿，也**不**因为批价无一手序列或未披露场景 / 库存硬数而把研究闸价撤回。启用与否另待完整关卡 / 用户原话，本研报不授权启用。

## 8. 风险与证伪信号

可观测指标 + 触发线（触发后只许下调 NI3 / 维持未启用，不在退出 PE 上重复扣同一风险）：

1. **飞天批价 / 渠道缓冲**：批发价连续两季明显低于合同价 1369，或渠道利润为负。参照：2025-12 低点约 1485；当前缓冲约 310–340（散瓶 ~1680 / 原箱 ~1710，2026-11-04）。这是结论卡「最大风险」。  
2. **茅台酒销量**：连续两年负增长，或公司下调年度营收指引。  
3. **直销结构**：直销占比趋势回落且吨价同步下降（证伪「量 × 直销结构」主引擎）。  
4. **系列酒**：再出现双位数收入失血，或毛利率再大幅下台阶并侵蚀品牌（2025 已是 −9.8% / 毛利率 −3.76 个百分点）。  
5. **净利率**：归母净利率跌破约 45% 且非一次性（费用率趋势抬升或吨利被批价侵蚀）。  
6. **现金转化口径**：若剥离财务公司扰动后，经营现金仍持续显著低于净利，或应收 + 存货周转同步恶化（当前判定仍为「过」；Q3 应收 3.65 亿需下季跟踪是否持续抬升）。  
7. **合同负债 / 预收**：已从约 141 亿降至 20.84 亿，属于换档事实；若再伴随批价倒挂与销量下滑，则确认需求比「结构切换」更差。  
8. **社会库存 / 场景**：一旦出现可复核的社会流通库存万吨或场景占比硬数，立即回填驱动树（目前公开信息已尽，不空挖）。

例程盯梢：收盘价 vs 闸价约 1240；飞天批价与 i 茅台挂牌；季度营收 / 归母及茅台酒 vs 系列酒；直销 / 批发比；合同负债；经销商数量与库存月数表述；基酒产量 / 设计产能（年报）；分红与回购进度；财务公司存款结构对 OCF 的口径影响。
