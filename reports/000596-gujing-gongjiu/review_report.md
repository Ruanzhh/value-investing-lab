## 问题清单

### Q1 · 退出 PE 28.145 是否偏松（区域龙头 / 去库周期）
- **严重度：** 中
- **证据：**
  - `calc` 同年 PE 窗 2016–2025：15.91 / 16.43 / 20.2 / 27.02 / 27.04 / 29.25 / 32.15 / 45.23 / 57.36 / 74.85 → 中位 **28.145**，修剪差≤10% 成立（与树 1.4 一致）。
  - 剔估值扩张年 2020–21（74.9 / 57.4）后剩余中位 **≈27.03**，合理价仅下移约 **3.7%**（≈185），闸价≈112——中位数对极端年稳健，**「剔扩张年」几乎不改主路径**。
  - 近窗 2023–25 中位 **20.2** 偏低，属去库/利润压力期成交价，不宜直接当退出中枢（易把周期底倍数当稳态）。
  - 经验粗带 15–25×（透镜交叉提醒，非改公式）：基退出 28.1 略高于上沿；无风险 25× 对照 FV≈172、差 **1.12\<1.25**。
- **判定：** **可修**（论证加强，不强制改数）
- **回流节点：** **1.4 / 根**
- **可修动作：** 结论卡旁注写清：① 全窗中位稳健、剔 2020–21 影响\<5%；② 2023–25 低倍数不作退出锚；③ 若行业中枢系统性下移至≤25，回流 1.4 重算。主路径可维持 28.145。

### Q2 · FY2029 NI 34.2（营收 180×净利率 19%）是否基准偏乐观
- **严重度：** 高
- **证据：**
  - 营收 180\<2025 的 188，顶线未用高峰——方向不松。
  - 净利率 19%≈2025 的 18.8%，但子树 1.2.1：9M26 销售费用率≈**33.9%**，上轮去库后费用多年粘在 **≈30%**；基准隐含「收入回 180 时费用回落至 28–30%」才能稳住 ~19% 净利，属**推断**（置信度中）。
  - 对一致预期 FY28 均值 35.1 打 10% 乐观折扣≈31.6，再外推至 FY29=34.2，增速约 +8%，轻度偏快但未离谱。
  - 敏感：净利率 −10%→NI≈30.8、闸价≈**105.7**（已贴近现价 105.2）；若改用 18%→NI=32.4、FV≈**183**、闸≈**110.6**。
- **判定：** **可修**
- **回流节点：** **1.2 / 1.3**
- **可修动作：** 不强制改 34.2；须在卡/树上钉死证伪：若 2027–28 销售费用率中枢仍 **≥31%** 或吨价继续下移，则净利率改用 **17–18%** 回流重算。若父级要偏保守一档，建议一次性改 NI3=**32.4**（180×18%）。

### Q3 · 闸价相对旧 89.3 跳 +30%——是否仅取消两轨取低、有无重复放松

  - 未发现情景端与倍数端同时加码放松（情景未改 + 倍数未抬）。闸价变动\>15% 已触发本轮独立挑刺（合规）。

### Q4 · 现金转化判「过」是否站得住（2025 OCF/NI=0.55）
- **严重度：** 中
- **证据：**
  - 序列：2021–25 = 2.29 / 0.99 / 0.98 / 0.86 / **0.55**；前四年正常年转化良好。
  - 透镜口径：过关看**正常年份**净利可否近似业主盈余；白酒预收款模式下去库年合同负债回吐压 OCF 是周期现象，非「假利润」主证。
  - 辅证：9M26 Capex\<年化 D&A；营运资本非长期吸血（筛选表）。
  - 反证：`k_cross_proxy` 2025=0.323 很弱；若 2026 全年 OCF/NI 仍显著\<0.7，则「例外一年」叙事削弱，应改判 **打折**。
  - RI 差 1.33\>1.25 时，SIMPLE-FLOW 要求回流重判现金转化——本轮解释落在「倍数口径」而非现金流造假，可接受，但买点仍不得启用（EXT.4）。
- **判定：** **可修**（维持「过」，加监控触发）
- **回流节点：** **筛选·现金转化 / 1.8**
- **可修动作：** 卡上写「过（周期修正）」；触发：2026 全年或 2027Q1 滚动 OCF/NI\<0.7 → 改 **打折**（建议利润打 0.9）并暂停正式研究闸价升级。

### Q5 · 是否重复扣险；富余现金 ≈10 元/股是否虚高
- **严重度：** 低（重复扣险） / 中（合同负债与净现金口径）
- **证据：**
  - 树 1.2 明示费用上移与吨价下移**只在净利率扣一次**；结论卡「最大风险」为叙事警示，**无第二次数值打折** → 未见重复扣险。
  - 富余现金 53.11 亿已扣合同负债、有息、应付票据/账款/其他应付款；对合理价敏感度仅 **±0.5%**，即使腰斩也只动闸价约 1–3 元量级。
  - 风险点：去库后若春节合同负债回升，按同一公式净现金会降，但同时货币资金回升，稳态净额未必等幅；树假设「保持到 FY3」偏简化，置信度应标中而非暗示高精。
- **判定：** 重复扣险 **通过**；富余现金口径 **可修**（表述）
- **回流节点：** **1.2（扣险一次） / 1.5（现金）**
- **可修动作：** 1.5 置信度若写「高」改为「中」或加一句「合同负债季节性可使净现金±波动，对闸价影响\<2%」；不必改 53.11 主数。
