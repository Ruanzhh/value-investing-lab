| **触发后处理** | 优先下调基准 FY2029 扣非（方向：195 → 试 175–185）；合理买入点同步下移或维持未启用。**不**因好转上调 |
| **本轮状态** | 未触发；惠而浦利润率塌缩为警示代理；独立挑刺：验尸「收入可利润崩」覆盖不足 → **结论卡风险说明**，不空挖 |

### 2. 卡萨帝利润贡献
| | |
|--|--|
| **缺口** | 无卡萨帝并表收入精确定义下的利润 / 利润率 |
| **公开代理** | ①交流/年报/渠道会卡萨帝收入或**零售额**增速（2026.1–10 零售额约 **+24%**，转引）；②中怡康万元以上冰洗份额；③「整体市场规模」叙述（口径存疑）；④集团综合毛利率与冰洗分部利润率；⑤行业/券商：**近端未见卡萨帝利润点值**（旧申港 2019「假设」至 2023 税后净利 37.4 亿已过期，**勿当现锚**） |
| **触发条件** | （a）卡萨帝收入增速连续两期 **低于** 国内冰洗行业零售额增速 **5pct 以上**；或（b）万元以上冰箱/洗衣机份额较 2025 高点累计回撤 **≥5pct**；或（c）公司停止披露卡萨帝增速且冰洗毛利率同步下台阶 |
| **触发后处理** | 削弱「高端溢价」叙事；基准情景中结构抬升假设下调；合理价/合理买入点只许下调或维持未启用 |
| **本轮状态** | 未触发；零售额增速旁证偏正，利润仍未知；**公开信息已尽** |
