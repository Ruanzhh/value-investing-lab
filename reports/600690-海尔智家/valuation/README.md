## 7. 估值与敏感度（仅 PE 轨）

公式（本附录 / 本附录）：

```
NI_adj = 195 × 0.92 = 179.4
FV3    = 179.4 × 22 / 92.99 = 42.4433 → 约 42.4
B20    = (42.4433 + 3.1513 × 0.80131) / 1.20^3.1513
       = 44.9685 / 1.7763 ≈ 25.315 → 约 25.3
```

| 项 | 主报 |
|----|------|
| 基准合理价 | **约 42.4 元** |
| 研究闸价 B20 | **约 25.3 元** |
| B20/FV3 | ≈ **0.60**（约 0.55–0.62 带内） |
| 买点 | **未正式启用** |

**退出 PE=22 理由（非历史中位照抄）**：生意质量半通过 + 白电消化周期 → 弱护城河偏 20–25 下沿内侧；取 22 略高于地板因冰洗份额/卡萨帝/GE 仍有可证伪相对优势；不取 25+。历史中位~15、旧档 12.5、现价约 11× **仅参照，不得主报**。

**敏感性（不改主报）**：退出 PE=20 → FV3≈38.6、B20≈23.1。折扣若回到 0.95 → 约 43.8/26.1（已否决：黄灯下不得宽于实测）。

**交叉对照（附录，非第二条合理价）**：现价对 2025 扣非 PE≈10.7、股权盈利收益率≈9.3%；压力期成交不得当稳态锚。相对挑刺时闸价 26.1，本轮折扣回流 −3.0%（&lt;15%）。

禁止所有者盈余折现轨、禁止两轨取低。
