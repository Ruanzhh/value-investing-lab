## 退出倍数专节（主报硬规则 · 用户拍板回流）

**主报退出市盈率 = 22**（约 20～30 带内偏下）。

**判断理由（质量 / 周期 / 定价权，非历史中位数）：**
1. **生意质量偏弱**：被需要=过；难替代=打折（IVD 局部）；国内价格不受管制=不过 → 护城河整体偏弱，按规则落在弱护城河带约 **20–25** 的偏下，不宜取中上沿（25–30）。
2. **周期位置非过热**：国内弱复苏未确认，更像底部偏中位修复前夜；海外主引擎但增速放缓 → **不得**用增长扩张期高成交倍数抬主报；也**不得**把去库/利润压力期的低倍数机械当稳态锚。
3. **同一风险只扣一次**：国内价格管制已主扣在净利率 24.5%，退出倍数**不再**叠到地板 20；轻资本与现金转化过关支持略高于地板。
4. **合取**：质量偏弱 + 周期修复前夜 + 管制不双扣 → 主报 **22**。相对上一版数值不变，但理由已从「抬到贴近历史低位」改为质量/周期判断。

**参照交叉（不得主报）：** 自身年末低位约 26–28x 曾被讨论，落在带中上沿；本轮质量/周期不支持以该历史数字抬主报。

## PE 轨公式（唯一定价主线）
```
FV_ops = NI3 × exit_pe / shares
       = 105.05 × 22 / 12.11799431 ≈ 190.7 元

       = 190.7 + 15.68 ≈ 206.4 元
B20    = (FV3 + n × DPS_min3) / (1.20)^n
```
