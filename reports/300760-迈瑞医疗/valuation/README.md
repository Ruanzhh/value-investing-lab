# 估值依据与复算

金额亿元、股数亿股、价格元。研究2026-11-17，预测2029-11-17；输入见[inputs.json](inputs.json)，运行`python3 calculate.py`生成[results.json](results.json)。脚本只依赖标准库，从自身位置读取输入，不依赖调用目录。预测是研究假设，并非审计后的预算。

## 经营利润的起点及三年路径

2025归母81.36亿元，2026前三季度71.84亿元。按2025年第四季度归母约5.66亿元衔接，机械TTM约77.49亿元，但第四季度有费用、税及汇率季节性，因此不能把TTM或前三季度乘4/3当正常利润。对2026第四季度归母作16—24亿元假设，全年归母约88—96亿元；扣除非经营现金税后利息约3—4亿元，近期归母经营利润锚约84—93亿元。未来正常路径首年106.92亿元包含复苏，绝非“当前已经实现”。这个恢复幅度是预测的重要风险来源。

正常化利润保留融资利息、税、少数股东损益、正常研发和经常性损耗；单独计价现金产生的收益从经营利润剔除，另计现金利息。没有把全部汇兑损失加回：汇率影响既有交易性损益，也有收入折算及竞争力变化。没有把所有收购摊销加回利润；现金桥再考虑非现金费用，避免同时提高盈利和现金两次计价。

前三期指截至2027、2028、2029年11月17日的年度经营周期，财报年度数据只作预测锚，不将截至2029年12月底的全年盈利假装为到期日已经实现的财报。期间分红简化到各周年末支付；公司实际多次分红，时间安排确定后必须替换日期重算。

正常路径整体约10%增长：国际增速由人民币口径11%左右向14%左右改善，国内恢复约5%；由本地化和IVD/耗材提升驱动。对产品结构的交叉约束是IVD约10%—12%、新兴业务约15%—20%、成熟设备约0%—5%，组合能支持高个位数至约10%增长；二者是同一收入的两种观察，不能相加。下行路径中国价格和需求压力持续、海外放缓至高个位数；上行路径需要海外及新业务共同加速、费用率摊薄，并非只靠汇率反弹。

45%+20%的正常经营权重源于海外增长、装机与回款证据；拆出20%覆盖经营正常而资本成本/市场认可恶化。25%的不利权重源于国内仍下滑、同行和政策反证；仅10%上行源于新业务有进展但单机产出和收购回报尚缺验证。这些不是统计频率，无法证明每一个百分点。若从正常路径向不利路径移动10个百分点，期末价值减少约169.11亿元，18%上限约下降9元；正式更新应修改概率后重跑，不凭文字“更乐观”调整价格。极端制裁、重大欺诈和产品系统性失败未单列概率，不利情景不是损失底线。

## 倍数的经济含义

合理PE衡量盈利的现金回报、增长所需再投资以及风险。用稳定期关系`PE≈(1-g/ROE增量)×(1+g)/(k-g)`作量纲检查，而非另加一套DCF：增长5%、增量回报20%、股权机会成本9%得到约19.7倍；增长6%、增量回报25%、机会成本9.5%约23.0倍。因此正常区间20—24倍，选择22倍依赖现金转化维持和中期增长可延续。相关长期参数都是假设，尤其未证明收购回报达到20%—25%。

正常利润但资本成本升至约11%，相同5%长期增长可使倍数约13—16倍，压缩路径取16倍。下行情景增长放缓、低投入回报对应13—17倍，取15倍。上行需长期约7%增长、25%增量回报及约10%机会成本，公式约25.7倍，取25—29倍区间代表27倍，要求较严格。18%是买入收益要求，不是上述企业机会成本或当前价值折现率。

倍数下调与盈利下调分别覆盖未来持续性和当期盈利水平，未额外扣模糊风险准备。同行资料用来检验竞争/需求，不用业务混合且财务口径不同的同行市盈率机械取均值。

## 现金归属和投入桥

初始超额现金115.28亿元为暂定归母可计价估计：2026年9月现金及等价物193.05＋交易性金融资产4.98－11月已分出股息15.75－必要经营现金40－少数股东现金归属估计15－额外义务及不可调拨储备12。最后三项未有逐项公开明细，其中经营现金不是负债，而是不重复计价的经营资产；不从利润倍数之外再扣应付账款等营运负债。

40亿元经营现金约相当于全年化经营现金支出的一个半月，覆盖全球库存采购与工资；15亿元少数股东归属、12亿元额外义务储备是工作估计，不声称财报已披露。12亿元覆盖长期员工义务、租赁偿还及受限调拨等未在经营现金预算充分解释的部分，不能再在每年现金桥重复扣相同义务。该项可能偏保守或偏宽松，因此期初超额现金另检查85—145亿元，买入上限影响约±1.5—1.6元。上市公司全部少数股东权益48.89亿元不能直接等同于其现金，也不能全部机械扣出。

上述现金桥只用于条件性估值；9月底至11月17日除已知股息外的现金变动没有完整报表，暂不推算。存在新增大额资本支出或收购时必须更新。不同于必要经营现金，剩余非经营现金按2%税后收益估计，收益不进入经营PE。

财报未把维持资本开支与增长资本开支分开。2025年长期资产购建20.38亿元，固定资产折旧7.21亿元、无形资产摊销8.51亿元。考虑研发、厂房、信息系统和产品注册，未来维持投入工作区间8—12亿元，增长及资本化开发投入10—16亿元；维持投入不机械等于折旧，研发费用化部分仍在利润中。增长现金需求还包含增量营运资本，不能只看购建支出。

正常首期现金桥可用：经营归母利润106.92＋归母非现金净调整约16－维持/增长购建约22－营运资金及其他现金净占用约10.04＝90.88亿元，即85%现金转化。后续用85%概括资本开支、海外营运资本随规模增加后的净效应；不利路径75%体现库存积压、回款恶化及固定投入刚性。16、22、10.04均为研究估计，10.04是模型一致性隐含值，不是独立测得的经营证据。公布新增明细时应替代比例法；不能用这条等式证明85%一定成立。

每期`FCFE=经营归母利润×现金转化率+超额现金税后利息`，`现金分红=(经营归母利润+现金利息)×分红率`，`期末超额现金=期初超额现金+FCFE－分红`。正常分红65%，不利60%；与已披露分红习惯接近，但不是承诺。现金转化均高于分红率，主模型不需要新增债务或融资；现金并非全额可分。没有计入尚未明确的特别股息、回购或新增收购收益；回购未来要同时减少现金和股数。

各期桥在results.json完整保存。期末股权价值=`第三期经营归母利润×路径PE+期末超额现金`。利润已扣融资成本，不机械重复减所有债务；少数股东利润已排除，不再将全部少数股东净资产从结果扣一次。预测依赖当前股数不变，如发行需重算。

## 税费、机会成本与敏感性

投资者税务身份未知，统一假设现金分红税10%，不声称用户实际适用；中国内地个人长期持有可能适用不同税率，应按身份与持股期限重算。买入费用0.03%、卖出总费用0.08%是建模假设，不是券商实时报价；未计最低佣金、冲击成本、资本利得税、融资、个人汇兑与通胀。以人民币名义税费后收益比较，不与税前/外币收益混用。用户若有资本利得税需重新建模。

目标要求变化时固定所有经营参数、倍数和分红：12%对应171.63元，15%对应158.86元，18%对应147.35元，20%对应140.30元。这里是在比较回报要求，不是四个合理价值。现金及短期低风险资产可作为等待机会的替代，但没有核验用户实际可投产品收益，不编造机会成本报价。

所有路径PE一起变动1倍，18%上限约变动6.27元，证明结果主要依赖长期持续性和估值，而不是初始现金的小幅误差。将所有路径第三年利润降低10%而固定此前分红/现金，仅终值一项约使上限下降12.6元；完整经营受损还会减少分红与留存，应重跑联合路径，不能把局部敏感性当完整风险。

假设在首期前发行现有股本10%的新股，发行价120/160/200元，发行成本2%，净募集资金留至期末，不计利息及投资增益；原有总分红不变，由扩股后全体股东分享，期末股数为13.329793741亿股。对应买入上限140.45/142.62/144.78元，参考价IRR7.54%/8.11%/8.67%。这是压力假设，不能写成拟发行方案。若募资投入主业，应将现金变成投入并单独预测回报，不能既加募集现金又加免费增长。

未估独立的“今天合理价”。147.35元是回报约束下的条件性研究数字，特别是现金归属、港股条款和终端试剂产出尚未解决，价格跌破也必须重新核查这些条件。

## 卖出价补算

2026-11-17按新增4%持有年化规则补算，计价日仍为2026-11-17，到期日仍为2029-11-17。经营参数、联合概率、倍数、分配日期、股数及原税费假设保持不变；不是更新到今天的三年预测。

```text
未来净现金流现值 = Σ(税后每股分红_t / 1.04^实际年数_t)
                  + 期末每股价值 × (1－期末卖出费率) / 1.04^实际年数_T
卖出价 = 未来净现金流现值 / (1－当前卖出费率)
等价卖出市值 = 卖出价 × 原模型计价股数
```

未来净现金流现值为213.306421元/股，当前卖出费率沿用原模型的0.08%假设，得到A股卖出价 **213.48元**、等价市值 **2,586.92亿元**。以12.11799431亿股换算等价市值，沿用原报告不新增股份的条件假设。结果保存在[results.json](results.json)的`reasonable_sell`对象，费率及4%参数见[inputs.json](inputs.json)。买入价仍为147.35元，计算不追加安全折扣。

卖出价的4%以立即卖出的净所得为持有成本；不把现在卖出费用错算成买入费用，也不直接取4%买入上限。已分出的现金不重复进入期末价值。原模型未覆盖的个人资本利得税、股息补税及实际佣金仍未建模，不能将示例税费当个人成交净额。当前报价达到卖出价时仍须复核经营判断；复用旧研究需按原到期日和剩余现金流重算，不能将这张研究日价格表直接当作实时阈值。
