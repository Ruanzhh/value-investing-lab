## 7. 估值与敏感度（仅 PE 轨）

### 7.1 主路径

```
NI3     = 350 × 1.07³ × 0.245 = 105.05 亿
FV_ops  = 105.05 × 22 / 12.11799431 ≈ 190.7 元
FV3     = 190.7 + 15.68 ≈ 206.4 元
B20     = (206.4 + 3.154 × 4.38) / 1.20^3.154
        = (206.4 + 13.81) / 1.77721 ≈ 123.9 元
```

| 项 | 主报 |
|---|---|
| 基准合理价 | **206.4 元** |
| 研究闸价 B20 | **123.9 元** |
| 现价相对闸价 | 高出约 **49%** |
| 买点 | **未正式启用** |

**退出市盈率取 22 的理由（质量 / 周期 / 定价权，非历史中位数）**：

1. **生意质量偏弱**：被需要过关，难替代打折，国内价格不受管制不过关 → 护城河整体偏弱，落在弱护城河带约 20–25 的偏下，不宜取 25–30 中上沿。
2. **周期非过热**：国内弱复苏未确认，更像底部偏中位的修复前夜；海外是主引擎但增速在放缓 → 不得用增长扩张期高成交倍数抬主报，也不得把去库 / 利润压力期的低倍数机械当稳态锚。
3. **同一风险只扣一次**：国内价格管制已主扣在净利率 24.5%，退出倍数不再叠到地板 20；轻资本与现金转化过关支持略高于地板。
4. **合取**：质量偏弱 + 周期修复前夜 + 管制不双扣 → 主报 **22**。

自身年末市盈率低位约 26–28 倍（2024 年末约 26.5、2025 年末约 28.4）只作交叉，**禁止**「抬到贴近历史低位」叙事。

明确：**无自由现金流定价轨**。旧卡自由现金流口径合理价 196.9 元 / 闸价 118.5 元仅作规则切换对照，不进入本轮标题数字、不取低。

### 7.2 敏感度（不改主报）

对各输入单独变动 10%（其他不变）对 FV3 的近似影响，摘自 [calc_out.json](calc_out.json)：

| 输入 ±10% | 对 FV3 的影响 |
|---|---|
| 收入（经 NI3 传导） | 约 ±9.24% |
| NI3 | 约 ±9.24% |
| 退出市盈率 | 约 ±9.24% |
| 超额净现金 | 约 ±0.76% |
| 股本 +10% | 约 −8.4% |

示意（四舍五入，不改主报）：退出 20 倍 → 经营价值约 173.4、合理价约 189.0、闸价约 114；退出 24.2 倍（22 的 +10%）→ 合理价约 225.5。国内若长期零增长、收入复合落到约 5%、净利率仍 24.5%，则 NI3 更接近约 96、合理价再下一截——内部压力测试已覆盖，不在基准重复扣。

相对上一版 PE 单轨 206.4 / 123.9：**变动为 0**。相对更早自由现金流取低闸价 118.5 仍 +5.4 元（约 +4.6%，<15%），那是此前规则切换的遗留对照，不是本轮新加。

### 7.3 交叉对照（附录，不是第二条合理价）

- 一致预期（同花顺近半年约 28 家，截至 2026-11-03）：2026 / 27 / 28 净利均值约 85 / 98 / 111 亿；外推 2029 约 126 亿，打九折约 113 亿。基准 105 亿约低 7%（绝对偏差 <15%）。**未因一致预期上调 NI3。**
- 现价 184.09 元对应市值约 2,231 亿元；按 2026E 核心归母 82 亿，股权盈利收益率约 **3.7%**，仅作筛选提示。
- 滚动市盈率：前三季度归母 71.84 + 2025 年四季度 5.66 ≈ 滚动净利 77.5 亿 → 约 **28.8 倍**。2026E 若 82 亿则约 27 倍。国际三巨头近窗前瞻约 15–18 倍，国内成熟 IVD 约 21–26 倍；联影 50 倍以上属高增设备叙事，**禁止**用来抬迈瑞退出倍数。
- 旧自由现金流并列（仅展示）：FV 196.9、B20 118.5。本轮禁止作定价轨或取低。
