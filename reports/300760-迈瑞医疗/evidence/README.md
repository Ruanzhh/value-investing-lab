## 真正可以改变结论的缺口

1. 医院端试剂单机产出、试剂实际净价、经销库存与终端回款：只有公司汇总，没有独立终端队列。不能从装机数推算确定复购现金。
2. 维持与增长资本开支：财报没有明确拆分，模型列区间和转化率；没有用折旧替代维持投入，也没有宣称85%由披露直接证明。
3. 少数股东及跨境现金：持股、合并利润和现金归属不同；初始115.28亿元超额现金含工作估计，缺精确逐家调拨表。按区间检验不代表已解决事实缺口。
4. H股条款、特别分红及新增收购：未核验最终方案，主预测附不发行条件，附录模拟融资和稀释。未来公告变化优先更新每股口径。
5. 新兴业务增量资本回报：收入增长不等于收购回报已经覆盖资本成本；尚无法拆出协同独立贡献。
6. 用户税务身份、实际佣金、资金期限及可承受损失：未提供，采用明确假设，不给个人仓位。

这些问题已落入情景、现金桥、敏感性和条件性结论；没有用“充分利用公开信息”冒充“全部事实均已知”。继续调研优先寻找上述披露或反证，而非堆叠同源转载。完整方法执行体现在主报告的商业机制、归母现金及资本配置分析，估值附录的联合概率、税费IRR、稀释与不利测试，以及明确更新条件；没有将形式合规当作经济假设正确的证明。
