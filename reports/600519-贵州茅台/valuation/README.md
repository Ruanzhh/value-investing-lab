# 从酒类营业收入到每股现金

[计算程序](calculate.py)采用Python标准库，无需行情接口。运行 `python calculate.py` 输出各路径、加权现金流、价格和压力测试。计价日2026-11-18，估值终点2029-11-18，实际天数/365，持续持有一股上交所普通股。到期日为研究周年，若需交易则用相邻交易日重估。

### 利润、资产与现金的边界

9月底滚动十二个月营业收入约1714亿元（1688.38＋1309.71－约1284.5），归母约821.61亿元（823.20＋644.67－646.27）。取1715和824作为研究日最近十二个月的正常收入与分红盈利基数，未用九个月年化。未来三个滚动年度依次对收入乘以销量和混合吨价两个增长因子；同路径每年使用表中归母经营利润率。历史会计净利率约48%–50%，其中含财务公司净息差及存款利息。2025单列金融利息收入32.16亿元，其税后归母贡献须扣利息、成本及少数份额，现金收益亦见财务费用。用47%作正常纯经营税后归母率（1715×47%=806亿元，与824相差18亿元），当中保留酒业税负、销售成本和少数损益。另按期初归母净金融资产的1%确认税后收益，反映低风险人民币资金的收益水平，仅对经营净利润乘PE。

期初可归属净金融资产约1278亿元，以9月底近似估值日。货币、拆出、一年内到期、债权及其他债权、贷款、其他非流动金融资产依次计499.27、1560.56、10、11.13、23.99、4.09、40.16亿元。扣合并全部负债378.83（含成员存款172.72）、全部少数权益92.17及400亿元运营和流动性储备。为避免把金融子公司的总资产直接分给股东，采用整体扣减法，少数权益按账面兑现，未来已用归母利润。对存量应付和税项作全额覆盖，预测营运资金仅计新增投入。400是估计，涵盖上半年受限法定准备金约84亿元及经营周转资金约316亿元（约半年现金采购和人工加上旺季部分税款）。定期同业存款可到期，按期末可变现、无本金减值计。保留款的收益和集团金融经营残值未另外资本化。估值日前最近七周净现金变化缺单列报表，未另推季节性收益。

年度归母可支配现金＝经营净利润＋净金融资产税后收益＋非现金摊折23－维持资本开支22－扩张开支－非现金营运资金增量。三项再投入按归母等效估计。2025合并固定资产折旧18.93、购建支出31.28，2024购建46.79，2025存货增加约71亿元。维持投入考虑既有车间、设备更新，扩张投入随增长提高，营运资金包括贮酒及经销预收减少。三季末存货约614亿元，持平于上年末，因此没有把2025的累库永久外推。正常路径第一年净投入73亿元，约占归母利润9%；约3.5%的收入复合增长需要已有熟酒储备、渠道提价以及高边际资本回报共同支撑。若全靠新增产能则不成立。未来不设净借款、重大并购、新一轮回购或发行。年内可支配现金减实际派付进入期末净金融资产，单独估值一次。

按9月底至估值日49天的时间差，以年化约750亿元的股东现金粗估，忽略季节性的期间增量可约达101亿元。它若全部形成新增可归母净现金，18%买价会提高约5元。预计收益对起点现金误差的敏感性低于终值PE。若2027年起的分红率由75%减至60%，同时将少发的分红全部留存、仍按1%赚税后收益，则合理买入价为963.79元，现价预期年化为2.32%。若留存资金投资失败，应另减期末资产。

正常路径共60%，对应核心酒2025年销量微增、2026年前九月酒业收入和收现仍增长。两条正常路径之中给估值压缩三分之一权重，因为渠道价差收窄后，资本市场可能更早按成熟消费品定价。系列酒以量补价、商务需求不足已发生，损伤权重高于强劲恢复；强势路径需要非标结构与飞天量价同时改善。以上是可修订的主观联合概率，尾部极端治理风险另作暂停配置条件。

PE的经济含义可用稳态可分配现金率×(1＋增长)/(股权要求回报－增长)检查，使用税后归母经营口径。13倍近似95%可分配、1%增长、8.4%要求回报；15倍约93%、2%、8.3%；20倍约91%、3%、7.7%；24倍约89%、4%、7.9%。高端需在每年留存11%经营利润的条件下实现4%长期增长，隐含新增资本回报约36%，竞争或税负侵蚀足以打破它。上述收益要求为资本化长期酒业利润的估计；投资者18%买入规则另算。正常/压缩两条路径前三年经营相同，第三年以后持续性及市场要求回报不同。经营严重受损时13倍亦可下穿。

### 同一股东的三年分配

五月已注销218.8614万股，股数统一为12.50081601亿。六月年度股息已支付。预测每一持有年度发放前一滚动年度归母的75%，约46%于12月、54%于次年6月发放，日期见程序。分期参照过去两次分配的相对规模，跨期沿用75%是研究假设，2024–2026年回报规划到期后需重新检验。首年约618亿元分配源自起点利润824亿元，包含尚未实施的2026中期。期末资产按实际发放额同步减少；未分出现金仍属届时股东。

人民币境内个人现金账户、同一批股份持有超过一年至退出，按该持有期股息差别化税率为零，资本利得暂免个税；买入费0.026%，卖出费0.076%（含0.05%印花税），不计最低佣金，手续费是测算值。不同账户、税制或提前退出应重算。加权税后每股分配依次约22.74、26.70、22.88、26.85、23.47、27.56元，期末扣卖费后1390.41元。价格为全部现金流现值，买入分母1.00026，继续持有的当下机会成本按卖出净额计算，卖出门槛分母0.99924。买卖价均再乘当前亿股数得到亿元市值。
