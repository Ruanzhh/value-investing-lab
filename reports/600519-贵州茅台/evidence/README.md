**现金质量复算。** 合并经营净现金中，先减去流入栏“客户存款和同业存放款项净增加额”，再加回流出栏“客户贷款及垫款净增加额、存放中央银行和同业款项净增加额、拆出资金净增加额”，四项均带原表正负号。这一口径可跨期复用，仍含金融经营利息及少数股东现金。再扣全部购建长期资产支出，2024、2025全年约720、746亿元，2025、2026前九月约553、597亿元。2025按净利润比例粗分归属，746×823.20/853.10≈720亿元，相当于归母利润的87%，构成现金模型的交叉检查；收款节奏和子公司实际分红会使单年比例偏离。

**尚不可观测。** 厂内陈年基酒与渠道成品库存要分开。全渠道不重叠的终端开瓶、消费者复购和进销存、按法人可随时上划的三季末现金、维持性工程独立预算均缺连续公开数据。由此限制销量、净现金和长期倍数的精度。[独立复核意见](review.md)
