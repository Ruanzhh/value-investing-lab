## 股东能抽走多少现金

**期初**。9月底可用现金等价物266.23亿（货币资金273.38亿），加交易性金融资产45.28亿。季度没有11月24日的完整资产负债表，假设两日期间除已披露事项外净增减为零。按前三季经营现金支出551.94亿的3.5个月预留214.64亿应对发货、保证金和垫资，相当于起点年收入的28.81%。这项可挑战的经营现金要求在收入上升时同比例增加。另留8.94亿元作为具有回购权的子公司引资义务代理（六月明细，九月部分重分类），以及0.79亿元交易性金融负债。其他非流动金融资产24.23亿暂按七折可回收，未上市权益的退出、税费与折价均有不确定性。8.57亿长期股权投资内含产业投资，未另计退出款，归母经营利润也未加权益法收益。以三季末归母权益/合并权益94.26%代理上述资产归属，再扣期后母公司新增回购支出1.75亿，得到可独立计价的**96.37亿元**。认缴基金假设用现金换取等值份额，未创造额外资产。期后收益与缴款时间未知。若独立资产估高40亿，买价降约1.17元。

**逐年现金**。运营债务保持可续借，假设净举债为零。普通银行借款服务的融资成本已进利润，未从期末再扣整笔债。净利加回相当于收入1.3%的固定资产折旧及摊销，再减全部资本开支与增量非现金营运资金，另扣经营现金储备的增量。这几项合并调整乘94.26%代理归母部分。折旧加回剔除使用权资产折旧，以利润中的租赁成本近似现金租金，只留租赁应计与付现的差异风险。以实绩检查，2025年固定资产折旧及无形、长摊摊销合计约11.21亿（1.26%收入），使用权资产折旧0.91亿，筹资项租赁支付0.85亿。另有非金融机构及融资租赁还款38.74亿，属融资本金等项目，若以后净还款，应直接削减股东现金，不能把上年经营现金减资本开支全分掉。[年报合并现金流与附注](../evidence/raw/2025.pdf)

取60%部分恢复，因为已有发运、预收及渠道续约，又有一个半年度左右的验收错位。25%押在长期受压，是因为原材料退税、准入和电站亏损可以跨周期延续，当前有限的确收不足以区分一次性延迟和以价换量。只有15%赋予高毛利且高放量，需要新产品、订单验收和供应链同时达标。恢复的60%中四分之一、高放量的15%中三分之一配较低倍数，容纳经营兑现而投资者要求更高回报的情况。均为主观联合概率。不同中间状态由相应代表点近似，重大事故、贸易禁令升级及股权融资困境可突破承压值。

末期PE覆盖10–19倍。用成熟后的股东可用现金收益率检查代价。假设末期之后经营增长趋于稳定，一个近似为 PE=(1+g)×(1−g/增量股权回报率)/(股权资本成本−g)。承压时名义增长约2%、增量回报约10%、资本成本约10%，得到约10.2倍。恢复时增长约4%、增量回报约14%、资本成本约9%，得14.9倍。优质放量后若仍能保持5%增长、增量回报约18%、成本约9%，得约19倍。盈利正常而风险溢价上行或增长较快消退可取10–12倍。这些是判断期末经营价值的经济前提。历史加权ROE从2023年40.96%降到2025年31.26%，受供应链信用及周期放大，不能当作永久增量回报。高倍数尤其依赖成熟后营运资金随增速降低而减少新增需求。若到期仍需持续大额投入，适用下档倍数。

末期归母经营盈利 × 本路径PE ＋ 分红后独立净资产，再除以预计期末股数。期望经营价值1,616.63亿元，另有独立净资产112.63亿元。盈余已在现金或再投资中记账一次，末期倍数只反映到期日以后的经营。未另行估算今天的公允价值。
