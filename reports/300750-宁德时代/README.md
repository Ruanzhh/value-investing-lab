# 宁德时代：需求仍强，增长与估值溢价应分开判断

**本次重估的主预测是：2029年11月正常化归母经营净利润746.73亿元，整体股权价值15847.68亿元；合理买入价229.85元，卖出价332.52元。** 宁德时代的客户、规模制造和交付优势仍支持增长，但税费分担、现金转化与扩产回报尚不足以保证增长和高倍数同时兑现。按2026年11月16日A股收盘240.50元测算，预期年化16.17%，低于18%的默认买入要求。

## 增长的依据仍在，定价权没有获得同等证明

公司向车企与储能客户销售电芯、电池及系统。2025年动力和储能合计约89.4%的收入，客户选择同时考虑安全、一致性、寿命、工程适配和交付。联合开发认证、制造良率、规模采购和研发投入构成优势；2025年研发费用221.47亿元也是维持优势的持续成本，不能全部加回利润。[业务与竞争证据](evidence/README.md#business)

原研究核对的SNE前三季动力装车份额从37.5%升至39.1%；公司三季度说明会披露电池销量超过260GWh，储能约占四分之一。2026半年报产能利用率94.86%、在建产能764GWh，支持产能陆续释放的可能。装车、出货和收入确认是不同口径，在建规模也不等于下一年可销售产量。

本轮将正常路径电池销量由1100/1300/1500GWh修订为1200/1400/1600GWh：2027年取机构对2026年约1000GWh估计及2027年20%—30%增长判断的较低端，随后增速降至16.7%和14.3%。这与客户和储能需求证据更相符；机构预测仍不等于订单保证，零增长及低效扩张继续进入受损路径。上行销量同步提高，并增加资金投入，未把产能当作免费增长。[量价推导与机构分歧](evidence/review-20261117.md)

客户能够通过双供、自制和新车型采购制衡报价，2025年前五客户占38.96%。2026H1动力、储能毛利率降至20.63%、23.96%。海外较高毛利与本地建设、合规和爬坡成本并存；比亚迪等技术竞争、LG北美本地产能及政策优势仍是反证。不能将储能需求、AIDC合作或换电站数量直接换算成新增高倍数利润。

最近十二个月＝2025全年＋2026前三季−2025前三季，最后一行不是精确归母自由现金流。[原件与口径](evidence/README.md#cash)

剥离现金利息、投资收益等，2026前三季核心经营息税前利润614.63亿元，按18%正常税率与93%归属、扣除融资利息后，经营归母约449.43亿元；它不等于报表归母或扣非。再用半年报相减，三季度核心经营税后利润率仅约**9.15%**，而上半年约12.74%。原首年9.5%其实已包含恢复，不能只因低于券商报表净利率就认为过度悲观。

[东吴三季报研报](https://pdf.dfcfw.com/pdf/H3_AP202610211830744550_1.pdf)的2027年报表归母998.04亿元，统一到本报告经营范围、融资、税率和归属假设后约695.17亿元。新正常路径为583.55亿元，差距缩小但保留：收入6960亿元低于其7407.55亿元，经营税后利润率约9.51%低于其同口径约10.56%。没有把券商报表利润整体乘经营PE，再额外加现金和投资。

利润率现由毛利率、销售/管理/研发、减值和税金附加逐项推导。正常路径毛利率21.5%→22.3%→22.7%，经营税后利润率约9.51%→10.00%→10.50%，仍低于H1水平。[官方消费税政策](https://szs.mof.gov.cn/zhengcefabu/202607/t20260717_3993743.htm)与[出口退税政策](https://szs.mof.gov.cn/zhengcefabu/202601/t20260109_3981637.htm)显示压力会延续；客户具体分担比例尚未披露。模型允许产品结构、效率和分担逐步改善，不假设政策撤回，也不在利润率之外重复扣一次总税单。

## 更高销量需要更多资本，现金恢复仍然偏慢

三季度经营现金流14.09亿元，同期长期资产现金支出170.95亿元。公司说明主动缩短供应商账期、增加预付款和研发支持，可能持续一段时间；系统产品验收也拉长收入确认周期。半年报披露供应商融资577.64亿元，其付款义务无条件且不可撤销。支持供应链可能长期正确，但短期资金需求是真实成本。[现金及供应链证据](evidence/README.md#cash)

新正常路径总资本开支660/710/760亿元，新增营运资金250/170/140亿元，均高于原路径；折旧随已转固资产增加到350/400/450亿元。维持与增长投入分开，维持投入没有机械设为折旧。资本承诺和基金认缴由对应预算覆盖，不重复扣除。机构关于现金迅速恢复的预测、个人关于现金流永久崩坏的判断，均未被直接采纳。

## 盈利正常也可能没有高估值

经营状态总权重仍为正常60%、受损25%、强增长15%。新模型把正常状态拆为20倍和15倍，将强增长也拆为20倍和25倍。税费、资本效率及机会成本存在不确定性，不能让正常或强增长自动获得区间上沿。具体35/25/25/7.5/7.5的联合权重是可挑战的主观估计，不是从研报票数或语言模型置信度得到的统计概率。[联合情景与倍数依据](valuation/README.md#weighted)

各路径分别估算第三年经营归母×对应PE，再加未重复计价的现金与投资。概率加权后，经营股权价值13579.38亿元、剩余非经营资产2268.30亿元，整体15847.68亿元；期间已分红不再加入。债务保留并承担利息，假设等额续借，不机械从扣息盈利的股权PE结果再减全部本金。

这仍是条件性预测：归母现金93%、投资80%为近似，旧质保返利足额预留1041.11亿元；投资以归母账面代理、没有将全部权益法收益当现金，也没有逐项证明可变现净值。相关递延税资产的兑现时点不明，未作为即刻可用现金。上述限制及敏感性在附录保留。

## 最强反证与失效条件

看多方面：需求、份额和在建产能可能让销量与资本效率超过本预测，税费传导也可能快于预期。看空方面：依靠降价、系统交付融资和更多资本才能保住份额，可能使盈利增长长期不能转换为每股现金。个人文章指出的后一个问题有效；无法核实的337.9亿元“总税单”、未公开渠道样本和混合单位盈利不能直接输入模型。[逐项核验](evidence/review-20261117.md)

在新买入价买入，经营受损路径仍可能累计亏损约49.88%；按240.50元买入，该路径约亏52.10%。第三年价值延迟两年、额外两年不增分红的压力下，参考价预期年化降至9.58%。所有经营税后利润率低1个百分点，买入价降至208.38元。18%门槛不保证本金安全，用户未给损失容忍，报告不代为宣称风险可接受。

后续证伪优先看：季度经营税后利润率与分产品/地区变化；应收、发出商品、供应商账期和回款是否一致；海外利用率、资本开支与新增利润回报；质量索赔、员工稀释和并购配置。正常路径要求费用与税费能够吸收、末期经营利润约833亿元且现金转化改善，任何一环持续不成立都应修订，不能仅因股价下跌增加乐观概率。

管理层持续研发、现金分红和供应链支持提供长期取向证据；这些不等于每项投资都创造价值，也不能排除治理、质量或海外准入尾部风险。本轮完成上述原始证据、市场分歧、模型与报告修订及反向自查，未经独立审阅。古井贡酒估值未改。
