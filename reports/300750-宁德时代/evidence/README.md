## 利润增长成立，现金回报仍需解释

来源F1—F3。不同期间不能直接做同比。2026前三季收入同比+56.19%、归母净利润+31.60%、经营现金流−23.60%。单三季度现金流由累计相减得到14.09亿元，同比下降93.59%；单季长期资产支出170.95亿元，两者之差−156.86亿元。这不是全部股权自由现金流，尚未处理投资、融资、利息和少数股东。

也不能只挑最差季度：滚动十二个月归母净利润876.97亿元，经营现金流1141.85亿元，长期资产支出544.24亿元，两者之差597.61亿元。现状不是“已经没有现金盈利能力”，而是高速增长后的资金占用出现变化，旧现金转化率不能不加检验地外推。滚动口径统一为2025全年＋2026前三季−2025前三季，公式已进入计算文件。

2025现金流补充资料中，存货增加消耗398.38亿元、经营性应收增加消耗169.12亿元，经营性应付增加贡献899.66亿元，三项净贡献332.16亿元。2026上半年同三项净贡献仅8.04亿元。F2第158页还披露供应商融资安排577.64亿元，较年初372.23亿元增加；列在应付账款中，本研究通过营运资金情景处理，不再无解释地当成有息债务扣一次。

公司在M1中将三季度变化归因于缩短付款账期、预付款和供应商支持，储能从电芯向系统延伸使验收确认周期变长；称存货增加主要是发出商品。**解释有经济合理性，但没有披露可逐项对账的季度现金流间接法、发出商品回款时间表和订单取消率。** 基准假设未来三年继续新增营运资金200/130/100亿元，不假定原有占用立刻释放；不利情景用350/220/120亿元，同时压低售价和利润率。若后续证据表明这是持续恶化，应下调估值，而非继续称作“暂时性”。

## 正常化盈利与现金、投资收益分开

F3利润表：收入4421.37424，减成本3416.95013、税金附加35.39029、销售33.71025、管理93.15309、研发185.16986、信用减值6.42154、资产减值35.95279，得到前三季核心经营息税前利润614.62629亿元。这里不计其他收益63.88亿元、投资收益90.66亿元、公允价值变动24.90亿元及资产处置收益；整体剔除财务费用，避免把利息、汇兑与主营利润混在一起。

采用18%的正常经营税率假设，得到未扣融资成本的集团经营税后利润503.99亿元、收入利润率11.40%。用于PE时必须另扣利息：F3披露前三季利息支出25.28779亿元，按税后成本并乘93%归母比例，得到正常化归母经营净利润449.43亿元。现金利息收入74.12521亿元和联营合营投资收益84.35673亿元不计入该经营盈利，相关资产另估。18%不是公司税率指引，93%也不是逐个子公司穿透后的精确比例。季度资产减值未逐项分离正常库存损耗与偶发固定资产减值，全部留在经营成本，可能偏保守；利润率敏感性覆盖其影响，但不等于已证实其可持续水平。扣非净利润仍可能含权益法投资收益，不能与本口径视为同一指标。

F2税收附注包括境内高新技术优惠与不同地区税率，不能把某个主体15%税率直接套到合并集团。F3非经常性损益表显示其他收益大部分被列入非经常性项目，支持与核心经营分开，但不证明未来一律为零。F2上半年利息费用13.92亿元，F3前三季25.29亿元；模型对期初债务用2.2%/3.5%年成本，是续借情景假设，不是已核定的平均合同利率。

财务附注披露2025折旧与摊销合计约269.37亿元，2026上半年约158.39亿元。模型未来维持性支出330/370/410亿元，另列增长资本开支280/310/320亿元；并未把全部折旧直接当作维持开支，也未将股份支付普遍加回。三季报未披露季度维持/增长资本开支拆分，预测是研究假设而非隐藏底稿。

## 优势的证据与客户制衡

2025动力电池收入3165.06亿元、储能624.40亿元，两者合计约89.4%；材料回收、矿产等不能简单套电池龙头的利润率。动力和储能毛利率分别23.84%、26.71%，2026上半年分别降至20.63%、23.96%。半年报境外毛利率29.97%、境内21.16%，境外收入占31.46%；地区毛利率存在产品组合差异，不能全部解释为地域定价权。

2025电池销量661GWh、产量748GWh、产能772GWh、利用率96.9%，年末电池库存186GWh，2024为106GWh。2026半年报期间产能525GWh、产量498GWh、利用率94.86%，在建764GWh。**半年期间产能与全年产能不可直接比较，更不能把在建产能全部当作下一年销量。** M1称三季度电池销量超过260GWh，其中储能约四分之一，匈牙利一期试生产；不等于整个匈牙利厂已达产。

SNE前三季动力装车：全球994.5GWh，CATL389.2GWh、同比+24.9%、份额39.1%，去年同期37.5%；比亚迪15.2%、LG8.2%。储能统计中，CATL198.3GWh、份额25.4%，海辰75.7GWh、亿纬71.6GWh，二线增长不能忽略。SNE储能三季度73.3GWh与公司260GWh约四分之一不完全相同，定义与确认时点不同，模型不拼接成伪精确总销量。

研究判断：竞争优势来自联合开发认证、规模制造与良率、交付可靠性、持续研发和客户对安全事故的规避，而非永远领先的一项配方。2025研发费用221.47亿元，说明维护技术优势本身需要持续支出。客户更换供应商有工程和认证成本，但可通过新车型导入竞争供应商、双供和自制制衡报价。年报前五客户占38.96%，最大客户13.73%，不能把未披露名称猜成某一家车企。

R2展示比亚迪追赶快充；R1显示LG凭北美本地合规供应链争取储能需求，并规划2027年底超过70GWh北美储能产能。韩国厂商的补贴会计与CATL口径不同，不能直接拿双方公布利润率作成本优劣排序。R3、R4显示合作关系和海外机会，但客户框架与规划产能没有给出可用于锁定未来利润的完整价格、最低采购量、违约条款。

<a id="policy"></a>
## 不能把政策损失机械乘在全部收入上

P1规定电池增值税出口退税自2026年4月由9%降至6%，2027年1月取消。P2规定相关锂电池消费税2026年9月起2%、2027年9月起4%；同时存在出口退免、已税原料抵扣及符合条件的新技术豁免。电池簇与完整储能系统税目也有区别。M1只说正与客户分担，**没有披露已转嫁比例**。本模型将税费影响放在售价与核心利润率中，不再对其结果重复减“全部收入×4%＋全部海外收入×6%”。

美国风险有两层：P3影响税收抵免资格，技术许可仍可能触及实质控制；P4另涉及特定电网设备交易的国家安全审查，范围包含储能系统。两者不是同一机制，也不等于所有出口归零。国内便宜并不能自动跨越海外合规门槛。美国收入和合同的完整拆分不足，故未承诺美国市场增长或单独给予许可收入高倍数；下行情景包含出货、毛利和产能回报同时受挫的可能。

2026年10—11月的储能合作备忘录和欧洲家储MOU是上行证据，但尚不足以证明其收现、毛利及新增资本回报。矿山环评报道同样不证明许可全部齐备或低成本达产。矿价上涨可能利好资源端而提高电池成本，不能两边都只计好处。

## 账上资产不全部属于普通股股东

三季度现金及等价物3333.98亿元小于货币资金3698.14亿元；本模型从前者出发，未把差额一律视作可分红现金。交易性金融资产627.80亿元另计一次，相关收益从核心利润剥离。债务及类债务合计1915.58亿元，净衍生负债10.17亿元，旧预计负债1041.11亿元另作足额储备。F2显示预计负债主要为售后综合服务费与销售返利；新销售的正常质保、返利已反映在未来经营利润中，旧义务储备不再放入未来营运资金重复扣除。

当前模型保留上述债务，假设到期等额续借、不新增净债务，在经营净利润中扣除融资利息。期末PE已是股权口径，不再重复扣同一债务本金；起点偿债并停止后续利息的替代情景单独计算。债务续借条件、资金限制和集团内部可调度性均非已确认事实。

经营和现金使用93%归母比例是有意标明的近似，不能据此推断每个资产均归母93%。四川时代在F2第160页的持股为79.20%；其持股链下的洛阳时代持有洛阳钼业53.297804亿股。按A2的13.29元，集团持股报价708.33亿元，按79.2%穿透后为561.00亿元，尚未扣处置税费、流动性和控制链约束。它已包含在投资组合内，**不得加在长期股权投资账面额之上再算一次**。

因最新逐项账面与净处置价值没有完整展开，本次对全部投资账面978.14亿元仅采用80%归母系数作账面代理，约782.51亿元；撤去原额外15%折价，也不把账面代理值当作逐项NAV结论。另直接测试归母组合为0、1500亿元，避免把估计系数伪装成已确认事实。它对总价值有影响，但不能取代经营现金流判断。

C1与C2合并：A股44.08949386亿、H股2.183003亿；扣除员工库存0.28319044亿及另列待注销回购0.19605919亿，当前经济权益股数45.79324723亿。10月累计回购53.6013亿元、1960.5919万股；9月已计入现金报表的33.03亿元不再扣第二次。研究日较股份快照晚一周，未声称逐日更新所有期间股份变动。

<a id="management"></a>
## 对管理层的判断必须落在资本配置上

年报无非标准审计意见提示；研发投入、海外合作、供应链支持能解释长期经营取向。它们不能证明管理层的所有决策都创造价值，也不能代替对诚信与文化的直接了解。本研究没有公司访谈、未披露客户合同和内部质量数据，不作“治理风险已排除”的结论。

F1披露2025年度按归母净利润50%安排现金分红，提供了实际回报股东的证据；它不是未来所有年份的无条件承诺。200—400亿元注销回购可减少股数，但是否增厚价值取决于回购价；员工持股受让价与公司回购价不同，会重新增加参与分配的股份。模型分别处理现金、注销和员工转让，不把所有回购当成持续股东收到的分红。C4的基金认缴4亿元说明资本配置在向更多领域扩展，放入未来其他增长投资预算，不凭“人工智能”字样增加估值。F2还披露长期资产承诺98.80亿元、对外担保46.87亿元、对子公司担保471.35亿元：资本承诺在未来资本开支中覆盖，内部担保不与合并债务重复相加；外部担保违约是额外压力风险。

<a id="pe"></a>
## 外部倍数只是参照

E1在三季报后采用15倍2027年盈利；E2在三季报前采用29倍2026年盈利。两者所用年度、经营判断与本报告剥离金融资产收益后的盈利口径不同，不能直接比较高低、求平均，也不能把券商目标价当作真实价值证据。本次实际读取的是研报文本镜像，未声称取得并审阅其完整底稿。

本报告基准15—20倍是研究判断：要求优势持续、现金转化改善，上沿还需更好的后续增长和投入回报。证据能够支持这些条件的讨论，不能唯一证明某个倍数正确；利润率、倍数和兑现延迟的敏感性因此必须保留。

## 哪些缺口会改变结论

| 未知 | 已如何处理 | 需要的新证据 |
| --- | --- | --- |
| 税费转嫁、单Wh毛利的产品/地区拆分 | 基准先压低利润率，上下行情景拉开；未给予全部转嫁信用 | 持续毛利、税负、客户结算变化与产品组合解释 |
| 付款条件缩短是否永久、系统验收多久收款 | 三年仍扣新增营运资金；不用2025供应商融资增量永续 | 存货类别、应收账龄、经营现金流间接法、回款与退货 |
| 海外项目、新业务及扩产的增量回报 | 增长投入独立扣除；PE上沿要求后续增长及资本回报支持 | 实际投产、利用率、折旧、项目利润与投资额 |
| 子公司资金可调度性、全部投资的真实归母与可实现值 | 归属系数明确列为假设；资产价值敏感性 | 各子公司现金、限制、少数股东安排、逐项投资估值 |
| 未来股份转让、进一步回购及融资 | 纳入最低回购余量和已批准员工计划的执行假设 | 每月股份报表、过户与注销公告、融资条款 |
| 质保赔付尾部、技术路线变化和海外准入 | 旧预计负债足额预留；保留比低增长更严重的永久损失可能 | 召回/索赔、良率与客户定点、项目合规认定 |

本次以三年盈利与PE联合路径的概率加权期望值形成主预测，不再使用DCF终值折现率或默认五折门槛；未指定当前点估值；目标年化18%由用户明确设定，属于买入要求而非外部披露事实。60%正常、25%不利、15%有利为研究者主观权重，事实来源支持其经济判断但不能证明这些精确概率，依据与敏感性见估值附录。基准投资组合采用归母账面代理，移除原15%折价；不利情景60%已经反映资产损失，不再叠加10%出售折价。F2第140页列示售后综合服务费及返利相关递延所得税资产合计149.17亿元，但其支付、抵扣与季度变化未逐项建模，旧义务全额储备因此可能偏保守。

这些缺口使结果属于**可复算的条件性评估**，不是唯一正确价格或价值下限。财报、业绩说明会、竞争者、需求、政策、资本配置与截止日新公告均已进入判断；未声称穷尽所有公开材料。新增资料若不改变上述经营变量，仅增加链接数量没有研究价值。
