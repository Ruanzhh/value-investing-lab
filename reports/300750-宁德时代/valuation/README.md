## 联合主预测

经营正常60%、受损25%、强增长15%的总判断不变，拆分正常与强增长的估值状态。下表为互斥代表路径，对连续分布作主观离散近似，非统计频率或公司指引。正常状态内约四成保留15倍，反映资本压力、风险偏好及机会成本；强增长也不必获得25倍。精确权重没有公开数据能够唯一校准，须接受敏感性挑战。

主预测：经营归母746.73亿元，经营价值13579.38亿元，非经营资产2268.30亿元，合计15847.68亿元。逐路径算价值及每股现金流，再加权；不以平均利润乘平均PE。

**倍数的经济条件。** 10倍对应经营优势受损和较低增长；15倍保留现金效率不佳或资本机会成本上升，20倍要求优势和再投资回报延续；25倍仅在高增长及现金回报同时兑现且获得溢价时成立。第三年正常FCFE/经营利润约46.4%，15/20倍分别只提供约3.1%/2.3%的当期经营现金收益率，绝非6.7%/5%的可分红现金收益率。

反推合理性而非另做主估值：若成熟阶段股权要求回报10%、新增股东资本回报20%，持续增长g所需再投入比例为g/20%，稳态PE=(1−g/20%)×(1+g)/(10%−g)。15/20/25倍分别隐含约4.64%/6.38%/7.27%长期增长及相应再投入。这是条件算例，10%并非本报告18%买入门槛，也非已证实资本成本；较高倍数需要扩张后现金分配比例恢复，不能只凭龙头标签。

### 毛利到经营税后利润率

经营税后率＝(毛利率−税金附加−销售−管理−研发−减值)×82%。新销售质保、返利及正常研发已在经营成本中，不再单独重复扣。基准毛利逐步回到22.7%，仍低于2026H1的23.93%；税金率2028升至2.1%体现完整年度消费税压力，2029小幅回落依赖组合和抵扣，并非税率下降。

正常所得税18%保留：H1所得税87.36亿元除以利润总额557.67亿元，表观约15.67%；仅剔除权益法收益57.83亿元后约17.48%，说明不能直接把合并低税率套入剥离投资后的经营利润。税种、研发优惠及地区差异仍未逐项预测。经营及现金归属93%为近似，投资80%为另一近似，非同一口径。

## 回报、税费及风险

先逐情景生成每股现金流，再概率加权。买入价＝未来现金流按18%折现的现值/(1+买入费率)。卖出价＝未来净现金流按4%折现的现值/(1−当前卖出费率)。同一组预测，不为卖出价另换更乐观参数；目标门槛不等于独立公允价值折现率。

买卖费各0.1%，分红税0为示例而非已确认免税；20%税率压力见下表。折现时间按实际天数/365.25。按240.50元参考价预期年化16.17%；按旧价254.22元为13.97%。18%买入上限229.85元，4%卖出价332.52元；对应10524.43和15225.62亿元等价市值。

期末价值延迟两年且额外期间不增分红，参考价IRR9.58%，在本次买入价入场也仅10.64%。受损路径在参考价累计亏52.10%，在买入价累计亏49.88%，年化分别约−22.52%/−21.30%；该路径不是最大损失下限。用户未给出损失容忍，不据18%门槛断言安全。

固定路径并将正常状态10个百分点按原内部比例转到受损/上行，参考价加权现金流IRR分别12.95%/18.78%；权重有实质影响，不能称精确概率。压力一次只改一个因素，联合冲击可能更差。

反推检验：若正常路径的经营利润、现金和分红全部实现，240.50元入场要达到18%年化，期末仍需约16.90倍经营PE；若只有15倍，该正常路径也达不到目标。这说明盈利增长本身不足以保证目标回报，必须把倍数分歧纳入主预测。此处是单路径反推，不替代概率加权结论。
