## 联合主预测

经营正常60%、受损25%、强增长15%的总判断不变，拆分正常与强增长的估值状态。下表为互斥代表路径，对连续分布作主观离散近似，非统计频率或公司指引。正常状态内约四成保留15倍，反映资本压力、风险偏好及机会成本；强增长也不必获得25倍。精确权重没有公开数据能够唯一校准，须接受敏感性挑战。

**倍数的经济条件。** 10倍对应经营优势受损和较低增长；15倍保留现金效率不佳或资本机会成本上升，20倍要求优势和再投资回报延续；25倍仅在高增长及现金回报同时兑现且获得溢价时成立。第三年正常FCFE/经营利润约35.7%，15/20倍分别只提供约2.4%/1.8%的当期经营现金收益率，绝非6.7%/5%的可分红现金收益率。

反推合理性而非另做主估值：若成熟阶段股权要求回报10%、新增股东资本回报20%，持续增长g所需再投入比例为g/20%，稳态PE=(1−g/20%)×(1+g)/(10%−g)。15/20/25倍分别隐含约4.64%/6.38%/7.27%长期增长及相应再投入。这是条件算例，10%并非本报告18%买入门槛，也非已证实资本成本；较高倍数需要扩张后现金分配比例恢复，不能只凭龙头标签。

### 毛利到经营税后利润率

以下全部是研究假设，以三季度核心经营税后利润率9.15%和H1约12.74%为锚；税费转嫁率未披露。出口退税影响留在毛利/售价内，消费税及其他税金在税金附加内，禁止再在模型底部减一张全收入税单。消费税法定税率不是集团税金附加率，国内应税收入比例、系统税目、出口及抵扣均影响税基。

经营税后率＝(毛利率−税金附加−销售−管理−研发−减值)×82%。新销售质保、返利及正常研发已在经营成本中，不再单独重复扣。基准毛利逐步回到22.7%，仍低于2026H1的23.93%；税金率2028升至2.1%体现完整年度消费税压力，2029小幅回落依赖组合和抵扣，并非税率下降。

正常所得税18%保留：H1所得税87.36亿元除以利润总额557.67亿元，表观约15.67%；仅剔除权益法收益57.83亿元后约17.48%，说明不能直接把合并低税率套入剥离投资后的经营利润。税种、研发优惠及地区差异仍未逐项预测。经营及现金归属93%为近似，投资80%为另一近似，非同一口径。

## 现金、投资、债务与股份

起点归母可调度现金代理＝(3333.97571现金等价物＋627.79978交易资产−600经营现金−1041.10971旧预计负债−10.17009净衍生负债)×93%−(59.80529261累计母公司注销回购−33.03已含在三季报现金中)＝2121.99亿元。三季末到研究日未披露的经营现金变动暂设为零，起点归母现金上下200亿元另测。

**为何让经营现金随产销增长。** F1和F3合并利润表对应的滚动十二个月收入为4237.01834＋4421.37424−2830.71987＝5827.67271亿元。同期合并经营现金流出小计为3786.48372＋3671.41142−2823.96214＝4633.933亿元。保留上一轮起点600亿元，相当于收入的10.30%，或约47天历史现金支出。公司未给出最低余额，450/600/750亿元约对应35/47/59个付款日，作为可挑战的储备尺度。实际支出取决于组合、季节与付款货币，预测用年收入近似经营规模，并非逐日拟合。正常路径各期集团储备716.58、816.45、912.20亿元，每期仅扣相对上期的归母变化108.42、92.88、89.05亿元。受损首期收入小于滚动收入，模型准许释放21.80亿元归母储备，若付款日反而拉长则会高估其可用现金。储备无独立金融收益，经营资产价值已含其服务能力。非现金营运资金只包含应收、存货、应付等，二者独立。起点600亿元扣一次，期末不再重复减总额。

旧质保/返利足额储备，不与新营运资金重复。相关H1递延税资产149.17亿元，未明确兑现时序，未当立即可用现金；现金+200压力已覆盖其数量级。供应商融资在经营应付中处理，不重复加有息债务。到期续借是条件，偿债替代同步减少现金和利息，结果见results的sensitivities。

归母投资代理＝(728.40531＋131.48849＋118.24729)×80%＝782.51亿元，受损状态×60%＝469.51亿元。洛钼持股等已在其中，不能再加一次；没有取得最新逐项NAV。H1权益法收益57.83亿元、宣告股利17.51亿元，二者不能等同现金；维持2%组合现金收益假设，另测0和4%。其差异对买入价约±0.62元，不足以抵销经营与PE分歧；退出仍按账面代理，不另把未分配权益收益乘经营PE。没有完整预测资源价格及留存收益形成的NAV增长，属于资产估值限制。

当前经济权益45.76691226亿股＝44.08949386亿A＋2.183003亿H−0.28319044亿员工库存−0.22239416亿待注销。最低200亿元回购余量140.19470739亿元，示例按250元执行；未来若实施400亿元上限、或成交价不同，期末现金与股数都要改。808.1586万股员工计划暂按158.42元转让，增加持股数量且回收约12.80亿元，170万股预留已含在内。期末股数45.28694929亿股（当前经济权益＋0.08081586−140.19470739/250）。[公告逐笔对账](../evidence/README.md#update)
