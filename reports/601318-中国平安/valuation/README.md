## 撤回记录

早期材料曾将 P/EV 约 61.8 元列为合理价，并列出 39.5 元合理买入点。最终结论撤回该定价：61.8 元仅留作观察背景，39.5 元不能继续作为合理买入点使用。旧公式与敏感性表已从现行附录删除，可通过 Git 历史追溯，不构成新的定价路径。

## 重新讨论的前提

需要验证可分配现金相对营运利润持续提升、偿付能力缓冲改善，以及新增资本投入的回报。筛选规则的行业适配性可以被挑战，但不能用方法争论直接恢复已撤回的数字。
