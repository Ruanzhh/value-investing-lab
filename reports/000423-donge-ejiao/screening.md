# 筛选三性含现金转化 · 东阿阿胶 · 2026-11-06

书面结论只能是 **过 / 打折 / 不过**（INVESTMENT-LENS / BUSINESS-DEPTH）。

| 前提 | 判定 | 一句话理由 |
|---|---|---|
| 利润为真 | **过** | 2023–25 OCF/NI≥1（2025≈1.32），未见变卖/重估出利；9M26 利润快于现金记入买点阻断与最大风险，未达「长期利润主要来自应收」而不过 |
| 利润可持续 | **过** | 处修复后期放缓；基准用 g=4%、净利率 25.5% 正常年，不用 2017–18 高峰与卖方双位数 |
| 维持盈利不需大量资本（**现金转化**） | **过** | ①近 3 年正常年 OCF/NI≥1；②维持性 capex 低、派息近 100%，轻资产；③营运资本非常态长期吸血（2025Q3 应收 5.25→年末 1.32 曾回落）。9M26 OCF≈4.0 vs NI≈13.3、应收 8.93：属授信季节性/渠道信号，**不在本关对 NI3 打折**——渠道风险已用基准低增速扣一次（风险只扣一次） |
