本次仅整理仓内已有材料，没有重新访问外部来源或补采财报。“原研究已核”的文字不是本次新增验证。研究摘录和评审意见属于二级材料，不能当作原始公告。没有原件、没有直达链接的事实，应当被审阅者视为尚需核验。
