## ① 现金转化是否真过 / 应打折

| 字段 | 内容 |
|---|---|
| **问题** | 主卡判「过、不打折」。2026 前三季 OCF/扣非仅 0.57、存货 +129 亿、购建固资常年约 2×折旧，是否应改为打折甚至退回筛选。 |
| **严重度** | 中（硬关；误判会整卡重开） |
| **证据** | intake：2022–25 OCF/扣非 0.82/1.22/1.12/1.85，均值 **1.25**，仅 2022＜1；2025 OCF 253≫扣非 137。business_understanding：维持 capex 代理≈1.0×D&A（约 17–20 亿），2025 购建 36.2 亿含扩张/海外本地化；维持/增长拆分**公开已尽**。2026 弱 OCF 归因存货备货且应收下降，非应收堆利润。规则（INVESTMENT-LENS）：正常年净利可近似业主盈余 → 过 → 只走 PE 轨。 |
| **判定** | **通过（维持「过」）**，但标**边缘**：① 若 2027 存货未消化且连续四季 OCF/扣非＜0.8 且应收抬头 → **退回打折或不过**；② Capex≫D&A 在「公开已尽」下不得假装已证维持资本很轻——只挡正式启用，不单独改判不过。 |
| **建议** | 维持过、不打折；买点仍不启用。不因现金转化退回筛选。 |
| **回流节点** | `drill_tree` 筛选三性·现金转化；跟踪清单·存货/OCF |

## ② NI3=175 是否中位过热

| 字段 | 内容 |
|---|---|
| **问题** | 路径 2026E174 → 2027消化160 → 2029**175**，等于约三年后回到热年附近；净利率 15.4% 高于 2025 的 ~14.8%，是否仍称「中位」。 |
| **严重度** | **高**（对 FV3 敏感度 ±10%≈±9%） |
| **证据** | scenarios：禁止外推 +41.5% 斜率；毛利中枢回 **46%**（相对 2026 前三季 ~49.6%）。营收 2029=1140（相对 2025 CAGR≈5%）。校验：1140×14%=160；×14.5%=165；×15%=171；×15.4%=175。主卡选 15.4%「贴近并略高于 2025」。但 2026E 本身用 `9M+priorQ4` 嵌了偏热毛利；消化年仅下到 160（相对热年 −8%），再爬回 175，**中位情景更像「弱消化后重回近高峰」**，不是周期中轴。偏悲观自检 130–140 与基准 175 落差大，说明基准已偏乐观一侧。 |
| **判定** | **可修** |
| **建议** | **下调 NI3 至 165**（净利率约 14.5%，贴近 2025 质量年、明显低于热年隐含 ~17%）。若坚持量增完全对冲毛利回落，至多 **170**，不得用 175 当「中位」标题数。 |
| **回流节点** | `1.1 FY2029 扣非`；`1.1.2 2027E 消化`；`1.1.3 毛利率中枢`；`scenarios` 分年路径 |

## ③ 退出 PE=18 依据是否够

| 字段 | 内容 |
|---|---|
| **问题** | 18× 介于谷底 ~16 与均值 ~21–22；缺年末快照表；与 NI 上修、净现金新加同时抬升，是否过松。 |
| **严重度** | **高** |
| **证据** | drill_tree：亿牛历史低约 15.8；2022–25 均值约 20.6–24.4；取「低于均值一档、高于谷底」的 18。**完整年末不复权×股本×同年扣非快照表缺**（V§3 强制项）→ 仅研究档（主卡已承认）。生意质量：难替代**仅部分成立**、定价权中等偏弱、硬件+方案非软件溢价（software ~1.3%–8%）——护城河强度不支撑贴近均值的退出倍数。旧卡 16× 确有「中位利润×谷底倍数」双重从严问题，但纠正双重从严≠一次跳到 18 且叠加利润上修。 |
| **判定** | **可修** |
| **建议** | 研究用退出倍数 **17×**（仍高于谷底、低于均值一档更稳）。在 NI3 已上修的前提下，**禁止**用 18–21。缺快照表 → 买点继续不启用（与主卡一致）。 |
| **回流节点** | `1.2 退出 PE` |

## ④ 净现金 3.23 是否可加、有无双计

| 字段 | 内容 |
|---|---|
| **问题** | 保守净现金 296 亿/股 3.23 加入 FV3；是否与 n×DPS 双计；存货大增下是否把营运现金当过剩现金。 |
| **严重度** | 中 |
| **证据** | 规则 V§5 D15：最近报告日净现金**保持不变**加到 FV3；不累加 FCF、不扣回购/分红，**避免与 n×DPS 双计**——公式层面**无双计**。科目：货币 370.84 − 有息 50.67 − 租赁 3.14 − 萤石少数约 20.6 ≈ 296（intake/gaps）。受限货币资金年报约 3.0 亿，影响每股 ~0.03，可忽略。一年内到期非流 10.91「含少量租赁」与租赁负债 3.14 或有小幅重叠 → 净现金略保守（可接受）。**口径偏宽点**：存货较年初 +128.6 至 333，OCF 偏弱，账面货币相当部分服务营运周转；主卡未扣「营运现金缓冲」，把近全额净现金当过剩权益加项。 |
| **判定** | **可修（非否决）** |
| **建议** | **允许按 D15 加净现金**；保留 3.23 作主建议分子的一部分（已扣租赁与萤石少数）。若主助手接受更严：再扣约 0.7/股营运缓冲 → **2.5**。不因净现金否定整卡；**禁止**再加全额 3.49。 |
| **回流节点** | `1.3 每股净现金` |

## ⑤ 合理买入点公式与 n / DPS

| 字段 | 内容 |
|---|---|
| **问题** | B20_TR=(37.6+3.15×0.70)/1.20^3.15 是否算对；n、DPS_min3 是否合规。 |
| **严重度** | 低（算术）/ 公式合规性高优先 |
| **证据** | V§3/§5：B20_TR=(FV3+n×DPS_min3)/(1+h)^n；DPS_min3=min(0.90,0.70,1.15)=**0.70**；fy3=FY2029；估值日 2026-11-06→2029-12-31，n≈3.15∈[2.5,3.5]；h=20% B 档。复算：1.20^3.151≈1.776，(37.60+2.21)/1.776≈**22.41**，与 calc 一致。合理买入点/合理价 0.596 ∈ 0.55–0.62，无需额外解释带。 |
| **判定** | **通过** |
| **建议** | 公式、n、DPS、h **维持**。数字修订只改 FV3 输入，不改公式。 |

## ⑥ 驱动树敏感节点是否漏挖

| 字段 | 内容 |
|---|---|
| **问题** | 前三大敏感已列 NI3 / PE / 净现金；是否漏掉对 FV3≥5% 的分支。 |
| **严重度** | 中 |
| **证据** | 已停：分部净利（公开已尽）、PE 快照（缺表）。**挖得不够**：① `1.1.2 2027 消化` 仅给点估计 160，未做「消化到 140」对路径终点的传导（若 2027=140 且修复斜率不变，2029 可能落在 155–165 而非 175）；② 毛利率未作独立 L1 ±10%（并入 NI3，但毛利 46%→42% 对 NI 冲击可单独 ≥5%）；③ 公司存货 vs **渠道库存**未区分；④ 存货跌价/减值情景未量化进树；⑤ 制裁扩大停在定性尾部。同一「毛利退潮」在利润路径与退出倍数两侧都出现——树未标明**只在一处扣**（DRILL-TREE「同一风险只扣一次」）。 |

| **建议** | 不必整树重写；补三个节点备注即可：`1.1.2` 消化深度敏感性；毛利单独扰动；「毛利退潮」风险锚在 NI3、退出 PE 不再以同一理由加码折价（或反过来）。公开已尽项保持已尽，不空挖。 |
| **回流节点** | `1.1.2`；`1.1.3`；前三大敏感附注 |

## ⑦ 相对旧闸 +40% 是否解释充分

| 字段 | 内容 |
|---|---|
| **问题** | 16.0→22.4（+40%，>15%）因子分解与「非重复放松」是否说清。 |
| **严重度** | **高**（DRILL-TREE：合理买入点变动>15% 须独立挑刺；规则倾向重估上调须严审） |
| **证据** | 分解（同公式）：仅 NI150→175、PE16、无现金 → 合理买入点≈**18.4（+15%）**；再 PE→18 →≈**20.6（+29%）**；再加现金 3.23 →**22.4（+40%）**。NI 上修有硬证据（2026E≈174 证伪 150）→ **必要**。PE16→18、新加净现金是**判断项**，与 NI 上修同向，构成叠松。主卡写「中位利润不用谷底倍数」「D15 允许加净现金」——理由单看成立，但未回答：在 NI 已从 150 提到 175 后，是否仍需把倍数从谷底附近再抬两档。毛利/制裁折价若已通过「不用热斜率、毛利回 46%」进入 NI，再用「制裁/硬件同质」把倍数压在均值下是对的，但同时相对旧卡**抬**倍数，等于旧卡双重从严的纠正幅度可能过大。 |
| **判定** | **需拍板（挑刺侧建议不维持 22.4）** |
| **建议** | 接受 NI 纠错带来的合理买入点升至约 18–19 区；**不接受**在无快照表、无独立复核采纳前一次到位 22.4。修订后合理买入点约 **20.3** 相对旧 16.0 仍约 **+27%**（仍>15%，本报告即满足换人挑刺要件）；正式启用仍否。 |
| **回流节点** | 版本对照表；根节点·相对旧闸 |
