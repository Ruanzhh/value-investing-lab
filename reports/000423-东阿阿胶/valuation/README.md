## 6. 核心假设与驱动

### 6.1 一句话基准假设

修复后期放缓；收入自基年 68.74 亿起年增约 **4%**；扣非净利率维持正常年中枢约 **25.5%**；原料储备已尽 → 不假设毛利率继续大幅上行；第二曲线不作翻倍引擎。现金转化判**过** → **不对 NI3 再打折**（渠道/授信已体现在低增速）。

### 6.2 基准路径（对外只报此线）

| 项 | 值 | 出处/置信 |
|---|---|---|
| rev0 / ni0 | 68.74 / 17.42 亿 | 基年拼表；与旧材料一致 |
| g / 净利率 | 4% / 25.5% | 贴近 9M26 +3.65%；正常年中枢；**中** |
| rev3 | **77.32** 亿 | rev0×(1.04)^3 |

分年直觉：约 2026E NI≈18.2 → 2027E≈19.0 → 2028–29≈19.7。不因其他卖方更高而抬 NI3。

## 7. 估值与敏感度（只走 PE 轨）

### 7.1 定价规则（现行）

- **只走**同年口径 PE：约三年基准净利 → EPS3 × 退出 PE → FV3 → 闸价。
- **禁止**：reverse_DCF、DDM、现金流定价轨、两轨取低。
- 退出 PE：约 **20–30** 内按生意质量与周期位置**判断取值**；历史中位**仅参照**，不得直接主报。
- 闸价公式：\( B20 = (FV3 + n \times DPS_{min3}) / 1.2^{n} \)；h=20%/22%（门槛常数未改）。
- ERP=5%、g_perp=1.44% 本轮 PE 轨**不用**。

### 7.2 退出 PE = 22×（主报 = 生意判断）

详见 本附录。

**理由摘要**：
1. 有定价权（M1），但不稳——2019 提价→压货→去库存崩过一次；护城河够「有」不够「硬」。
2. 周期是修复后期，不是扩张——9M26 +3.65%、应收抬升、品类存量 → 弱护城河/强周期应偏带下沿（约 20–25）。
3. 轻资产与高派息可给一小步溢价 → 相对纯弱周期下沿 20 可上移一档，但不足以到 25。

**边界（为何不取相邻档）**：

| 候选 | 不取原因 |
|---|---|
| 20 / 20.11 | 会像把窗口全中位「直接主报」——本轮废止写法；且忽略品牌/独家浆/轻资本一点质量溢价 |
| 23–25 | 应收抬升 + 2019 渠道史 + 品类存量，稳定性不够 |
| 25–30 上沿 | 强定价权/稳定轻资本才偏上沿；质量弱于同路由茅台/古井类 |
| 28–29 | 修复–扩张期高成交倍数，**不得抬主报** |
| 13.51 | 2018 压力期低倍，不得机械当稳态锚 |

历史参照（**非主报**）：窗口 [2017,2018,2023,2024,2025] PE = 20.11 / 13.51 / 29.34 / 28.02 / 19.29；全中位曾 **20.11**。\
`independent_signoff=false`（等用户本人原话；本轮不替用户决定）。

### 7.3 主路径计算

| 步骤 | 公式 / 输入 | 结果 |
|---|---|---:|
| NI3 | 68.74×(1.04)^3×0.255 | **19.7174** 亿 |
| EPS3 | 19.7174×100 / 639.826824 | **3.081678** |
| **FV3** | 3.081678 × **22** | **67.80** |
| n | (2029-12-31 − 2026-11-06)/365.25 | **3.151266** |
| **B20（研究用）** | (67.80 + 3.151266×1.78) / 1.20^3.151266 | **41.32** |
| B22 | 同分子 / 1.22^n | 39.23 |

现价 50.53 / 闸价 41.32 − 1 ≈ **+22.3%**。

### 7.5 敏感度与交叉（不改闸价公式）

| 情景 | FV3 | B20 |
|---|---:|---:|
| 基准（退出 22，无打折） | **67.80** | **41.32** |
| 若现金转化打折×0.90 | 61.02 | 37.51 |
| 示意：退出 15 / 20 / 25×（同 EPS3） | ≈46.2 / 61.6 / 77.0 | — |

交叉提醒：
1. 自现价 50.53，约三年按 15–25× 达不到约翻倍。
2. TTM≈18× → 粗收益率约 **5.5%**，高于国债 ~1.6%，相对 **20%** 门槛不算明显更优加仓。
3. 卖方目标价**不抬**闸价。
