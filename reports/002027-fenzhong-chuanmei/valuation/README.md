## 6. 退出 PE 判断

规则：主报约 **20～30** 内按生意质量、周期位置、定价权/难替代**判断取值**；历史同年 PE 中位数等**只作参照，不得直接主报**；增长扩张期高倍数不得抬主报。

| 项 | 值 |
|----|----|
| **主报退出 PE** | **20**（带内下沿） |
| 带 | 约 20～30 |
| 历史剔谷中位（参照，不进定价） | **21.8**（基窗 21.85 / 20.87 / 21.75 / 21.85） |

**取 20 的理由：**

1. **价格不受管制不过**（反垄断限价 + 独家位结束）→ 不宜给带内中上（约 25–30）。\
2. **周期中位偏弱、增速近平台**（基准收入 CAGR +1.5%）→ 非增长扩张期，不得用扩张期高成交倍数抬主报。\
3. **历史中位 21.8 仅参照**：窗口含可提价/独家结构年代；限价后结构已变，**禁止**再把 21.8 当主报。\
4. 带内下沿 20 与独立挑刺「可把退出压到约 20」方向一致；弱护城河 + 强周期偏区域龙头 → 偏带下沿。

**未取更高（如 22）：** 当前公开信息下价格三性仍不过、新潮未交割、消费品收入连续下滑，**无**支撑抬离下沿的证据。

## 7. 合理价与闸价（只走 PE 轨）

估值参数：FY3=2029-12-31；**n≈3.151**；h=**20%**（B 档）；DPS_min3=**0.33**。\
禁止：股息率定价、FCF 定价、两轨取低。

### 7.1 约三年基准合理价

\[
FV_3 = \frac{42.75 \times 20}{159.78} = \mathbf{5.35}\ \text{元}
\]

| 项 | 数值 |
|----|------|
| NI3 毛坯 | 46.47 亿 |
| × 现金转化 | ×0.92 → **42.75 亿** |
| × 退出 PE | **20** |
| ÷ 股本 | 159.78 亿股 |
| **FV3** | **5.35 元** |

对外只报这一条基准线。

### 7.2 研究用买入闸价（并列）

| 口径 | 公式 | 研究用数字 |
|------|------|-----------|
| **含息** | \((FV + n\times 0.33)/(1.2)^n\) | **3.60 元** |
| **不含息** | \(FV/(1.2)^n\) | **3.01 元** |
| 主线 | — | **主口径未选定** |

**硬提示：** 走弱年扣租现金常盖不住 0.33 分红底线（靠理财缓冲）→ **含息研究闸偏松**；拍板前研究对照**优先看不含息 3.01**。主口径仍未选定。
