# 宁德时代：增长之外，更要看多少利润能留给股东

## 核心判断

宁德时代的规模、制造能力与客户关系仍有价值，但电池业务需要持续投入。原报告没有把全部账面利润视为股东可以拿走的收益，而是先按八折调整，再进行估值。核心问题是扩张能否最终带来稳定现金回报。

合理价对应约三年后的基准情景；闸价是计入回报要求后的研究参考，不是交易指令。

## 生意逻辑与竞争优势

动力与储能电池需求支撑出货，规模制造和客户定点关系提供一定竞争壁垒。但公司仍处于扩张阶段，海外工厂、产品迭代和新增产能都需要资本。规模优势与强定价权并不是同一件事。

因此，评价公司不能只问出货增长多少，还要问每单位电量赚多少钱、维持竞争力要投入多少钱。税负转嫁、产能利用率和动力／储能的净利润拆分尚不充分，是原报告保留判断余地的原因。

## 关键证据：经营发生了什么

金额单位为亿元；前三季度数据不与全年直接作同比比较。

| 指标 | 2025 年 | 2026 年前三季度 |
|---|---:|---:|
| 营业收入 | 4237 | 4421 |
| 归母净利润 | 722.0 | 645.3 |
| 经营现金流 | 1332.2 | 616.3 |
| 购建长期资产支出 | 423.5 | 422 |

增长仍强，但现金回收与资本投入呈现另一面：2026 年前三季经营现金流与净利润之比约为 0.95，购建支出已接近上一年全年。过去较高的现金覆盖不能保证扩张后仍能维持。

原报告据此将现金转化判为 **0.80 折算**，并未否定利润真实性。维持性与扩张性开支缺少官方拆分，八折是研究判断，不是公司披露的精确比例。上述历史序列部分来源标为未发布内部文稿，本页仅转述仓内报告，不将其视为本次已核验的一手数据。

## 估值依据：哪些假设必须成立

基准假设 2029 年出货 **1300 GWh**，单位净利润 **0.066 元/Wh**，对应调整前利润 **858 亿元**。先乘以 **0.80**，得到 **686.4 亿元**的估值利润，再乘以 **22 倍**退出市盈率、除以 **46.2725 亿股**，得到约 **326 元**的三年后合理价。

原报告按约 20% 年回报要求并计入股息假设，研究闸价约 **193 元**。现金转化折扣、单位利润和出货量是关键变量；八折若仍然偏松，估值也会偏高。税负转嫁和资本开支等验证不足，买点未启用。

## 风险与后续跟踪

- **单位盈利恶化：** 单位归母利润连续两年低于 0.06 元/Wh，且不能用一次性税负解释。
- **份额与现金回收走弱：** 国内月度装车份额连续三个月低于 42%，或现金流长期低于净利润且应收、存货继续恶化。
- **资本负担改善：** 购建支出连续两年接近折旧、单位利润保持稳定，才有依据重新讨论现金转化折扣。

下一步应把出货、单位利润和购建支出一起跟踪。仅有收入增长，无法证明股东回报同步提高。
