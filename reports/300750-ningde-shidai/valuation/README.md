## 7. 估值与敏感度（仅 PE 轨）

公式（[calc_pe_only.py](calc_pe_only.py) / 本附录 / 本附录）：

```
NI3_gross = 1300 × 0.066 × 10 = 858
NI3_adj   = 858 × 0.80 = 686.4
FV3       = 686.4 × 22 / 46.27249686 = 326.35 → 展示约 326
B20_TR    = (326.35 + 3.151 × 5.028) / 1.20^3.151
          = 342.19 / 1.776 ≈ 192.64 → 展示约 193
```

本轮复核（2026-11-06 Asia/Shanghai 重跑 `python3 calc_pe_only.py`）：与上式一致；**相对定稿 326 / 193 无变化**。

| 项 | 主报 |
|---|---|
| 约三年基准合理价 | **约 326 元** |
| 买入闸价 | **约 193 元** |
| 现价 / 闸价 | 264.06 / 193 ≈ **+37%**（未到价） |
| 买点 | **未正式启用** |

**退出 PE=22 理由（非历史中位照抄）**：价格权偏弱、周期制造龙头、现金转化打折、难替代仅部分成立 → 落在弱护城河/强周期带下沿（约 20–25）；取 22——不贴地板 20（仍承认规模成本 + 定点转换成本部分成立），不抬至带中上 23–25。历史中位 23.15、扩张期高成交倍数 **不得抬主报**。
