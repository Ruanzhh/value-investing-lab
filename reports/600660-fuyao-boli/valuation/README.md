## 第7章 估值与敏感度（只走 PE 轨）

### 7.1 主路径计算（已复核）

```
估值日 2026-11-05 → FY2029-12-31：n = 3.154
收入₃ = 466.08 × 1.06³ = 555.11 亿
净利₃ = 555.11 × 16.5% = 91.593 亿
打折后净利 = 91.593 × 0.88 = 80.602 亿
合理价 = 80.602 × 22 ÷ 26.0974 = 67.947 ≈ 67.9 元
闸价 = (67.947 + 3.154×1.3) / 1.20^3.154 = 40.54 ≈ 40.5 元
闸价/合理价 = 0.597
现价 55.82 / 闸价 40.5 ≈ 1.38 倍
```

**复核结论**：与 [calc_pe_only_out.json](calc_pe_only_out.json) / [README.md](../README.md) 一致；**闸价无变化**（仍为 40.5）。

### 7.2 退出 PE=22 的理由

按现行硬规则，主报须在约 **20～30** 内视生意取值：

- 福耀属**成本护城河、无特许定价权、重资本且扩张未结束、OEM 买方强** → 落在弱护城河下沿带约 **20–25**。
- 取 **22**（非地板 20：全球份额与相对 AGC 的利润率差仍在；非 25+：无特许定价、扩张吸金）。
- 历史四年年末 PE 中位约 **19.03** 只作参照，且低于 20 带，**不得直接主报**。
- 2024 成交 21.87 属增长扩张期高倍数，**不得抬主报**。
