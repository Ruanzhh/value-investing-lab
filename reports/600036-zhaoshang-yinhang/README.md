# 招商银行：低成本存款仍是优势，信用成本决定利润底色

600036 · 研究日期：2026-11-06 · [返回公司目录](../../README.md)

## 核心判断

招商银行的核心优势是负债端低成本资金与零售客户基础。当前利润并不意味着零售信用周期已经恢复；原报告对信用成本作正常化处理，用银行适用的 PB–ROE 方法估值，结论仍为观察。

## 生意逻辑与竞争优势

银行先获得存款等资金，再通过贷款、投资与服务收费获利。招行的优势在于零售活期存款、结算关系和财富客户带来的相对低成本，而不是不受约束的贷款提价能力。

当贷款收益率下降时，负债降本可以缓冲息差；但低成本存款也可能向理财、货币基金或其他银行迁移。因此，需要验证的是相对同业的资金成本优势能否持续，而不是简单把过去的高净资产收益率延续下去。

## 关键证据：经营发生了什么

金额单位为亿元；2026 年前三季净资产收益率和信用成本为年化口径。

| 指标 | 2025 年 | 2026 年前三季度／三季度末 |
|---|---:|---:|
| 净息差 | 1.87% | 1.82% |
| 存款成本率 | 1.17% | 0.95% |
| 加权净资产收益率 | 13.44% | 13.49% |
| 信用成本 | 0.60% | 0.72% |
| 拨备覆盖率 | 391.79% | 389.39% |

负债成本下降部分抵消贷款收益率下行，但不代表资产端定价权恢复。原报告同时提示：报表信用成本低于风险生成水平，部分差额由拨备缓冲吸收，不能把低信用成本直接当作长期常态。

银行经营现金流受贷款、存款和金融投资投放影响，不能照搬制造业的自由现金流判断。这里的筛选重点是利润可信度、资本质量与内生资本积累。

## 估值依据：哪些假设必须成立

本报告采用 **PB–ROE**：先根据盈利和分红推演每股净资产，再乘以退出市净率。基准假设净息差在 **1.82%** 附近，不预设回升；信用成本正常化至 **0.90%**，第三年净资产收益率约 **11.4%**。

约三年后普通股每股净资产 **58.51 元**，乘以退出市净率 **0.953 倍**，对应合理价 **55.8 元**。原报告的总回报口径研究闸价为 **35.61 元**，不是按工业企业 PE 方法另造的价格。

信用成本正常化后，仍有约 **13–17 个基点**的拨备缓冲缺口未关闭，不能将估值理解为已经完全覆盖信用风险。买点仍未启用。

## 风险与后续跟踪

- **息差优势消失：** 净息差低于 1.60% 且连续两季环比下降。
- **信用压力超出假设：** 年化信用成本超过 1.2%，或拨贷比低于 3.4% 且信用成本仍低于风险生成水平。
- **负债与资本变弱：** 活期存款日均占比低于 45%，相对同业存款成本差小于 25 个基点，或核心一级资本充足率跌破原报告警戒线。

下一步应联看存款结构、信用生成、拨备与资本，判断利润是在经营中赚出来，还是依赖缓冲释放维持。
