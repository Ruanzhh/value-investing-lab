# 中际旭创：增长可见，远期利润归属与持续性仍决定价值

**中际旭创具备高速光模块的研发、客户认证和规模交付优势，近期需求有支撑；但不能把订单增长直接等同于可分配现金，更不能假定新技术与海外增长全部归原股东。** 本研究的概率加权主预测为：2029年11月17日正常化归母经营利润494.04亿元、期末股权价值7256.65亿元。以11月17日A股收盘393元测算，预期年化17.39%，低于18%的回报门槛。买入上限由418.29元下修至386.98元。下修来自原报告遗漏的后期新品准入风险，正常经营毛利预测仍为45% / 43% / 41%。

## 优势来自交付能力，客户并未交出议价权

公司把电信号与光信号相互转换的模块卖给云计算、网络设备等客户；光模块在2025年收入中占97.95%。高速率下的功耗、散热、良率、可靠性和大批量交付需要共同达标，客户验证与联合开发构成进入门槛。带宽升级可以提高单只产品价值，规模及工艺学习有助于成本改善。这解释了收入增长与2026前三季约46.39%毛利率，不能证明高毛利永久持续。[年报、招股书与竞争证据](evidence/README.md)

2025年前五客户占75.98%、第一客户24.06%，第一供应商占采购35.76%。客户集中既能带来大批量效率，也意味着少数客户的预算、双供和设计变更具有很大影响。新易盛前三季毛利约47.69%，至少说明同业也能取得高利润，不能把中际的利润全部解释为不可替代的垄断。未披露的客户名称和订单份额不作猜测。

管理层11月3日表示2027主要客户确定性采购订单基本覆盖全年，2028至少一家客户给出明确指引。招股书显示取消通常须书面通知并经公司同意、可能承担费用，故不能把订单说成毫无约束；但金额、赔偿及实际回款条件未全面公开，2028指引也不是全体已下单，2029更无利润保证。Alphabet、Meta的投入指引及11月18日已可取得的英伟达季报支持近期需求；它们的总投资和销售不是中际的保量合同。[下游与订单核验](evidence/README.md)

## 光连接增长，不保证旧模块保持全部价值量

可插拔模块、近封装光学（NPO）和共封装光学（CPO）将光连接放在不同位置，带来不同的器件、封装及维护分工。公司披露目前CPO主要参与光纤阵列单元（FAU）和外置光源（ELS）；新产品可以带来机会，也可能把原模块利润转移给交换芯片、光引擎或其他供应商。

[Lambda于11月16日公布的大规模CPO部署](https://lambda.com/blog/worlds-first-large-scale-deployment-of-nvidia-photonics-switches-with-cpo)表明交换机侧应用已有落地，不能用“scale-in还早”推导所有CPO替代都很远；这同样不证明可插拔会立即消失。LightCounting公开更新仍显示可插拔占销售主体。Marvell与Lumentum签署的纵向整合交易尚未完成，但它对供应链议价和技术分工构成反证，不能把所有技术路线都作为无成本新增利润。[原始材料与限制](evidence/README.md)

正常路径三期合并毛利率取45%、43%、41%。2024、2025年实际分别为33.80%、42.04%，2026年三季度单季约46.6%。群益给出的2027、2028年收入和成本隐含45.31%、43.45%，开源对应预测为45.9%、44.9%。前两期有同口径交叉参照。2029年41%主要取决于新品放量能否抵消同代降价，公开资料没有分型号的实际售价和成本。[研报原表、公司说明与反方解释](evidence/README.md)

## 海外利润、IPO现金和少数权益不能用一个比例处理

TeraHop的集团持股在后续融资完成后约66.35%，另有相当于融资后股数4.9%的管理层权证。本研究按权证摊薄后约63.25%计该层归属。H1该子公司净利润约31.70亿元、约占集团21.5%，经营现金却为−53.07亿元；它包含集团内部交易，不能用海外收入占比直接代替利润占比。

模型正常路径假设TeraHop利润占比升至30%/35%/40%，使归母比例由88.62%降至84.99%；没有将现有约92.29%归母比例永久固定。资本投入的归属暂以利润比例代理，母公司承担全部净再投入另作压力。对子公司具体资金调度、利润转移和少数股东义务缺少逐项披露，不能宣称已完全穿透。[权益原件与模型边界](evidence/README.md)

50.63亿元长期应付款涉及融资回购义务，但完整持有人、触发与结算映射不足。模型把所付现金与取得的少数权益同时计入，不能扣钱后还永久扣同一少数利润；另测按公平价换H股时的稀释。若新H股按模型每股价值的70%发行，买入上限约375.76元。合约压力是条件计算，不是法律义务精算。

现有库存股从分母剔除，已知未归属奖励1474.70万股计入摊薄，终点11.87003548亿股。期初现金扣已实施10月分红、必要经营现金、旧工程应付及质保储备；IPO现金与投资收益不再乘经营PE。回购已花约49.97亿元、均价约884元，不能仅因拟注销就证明增厚价值，也不能只用后来的股价倒推当时决策必错。人才激励、TeraHop管理平台权益与投资配置都需要从原股东每股价值审视，研发和持续薪酬不作为免费收益加回。

## 准入风险与正常经营的低倍数都影响结论

招股书显示2025美国客户收入占57.3%，2026Q1为61.7%。[1260H列名](https://public-inspection.federalregister.gov/2026-11571.pdf)本身不是全部商业销售禁令；[FCC已生效规则](https://www.govinfo.gov/content/pkg/FR-2026-09-11/html/2026-18535.htm)涉及Covered List主体和新授权，不能与光模块专项提案混为一谈。最新完整名单访问受限，所以也不能反向保证公司未来商业准入。海外工厂不自动规避按企业身份设置的限制。[政策原文与未解问题](evidence/README.md)

主观经营权重为正常35%、上行15%、周期/技术受损20%、后期新品部分受限15%、首期起严重准入受限15%，并进一步拆开正常×10/15倍、上行×12/18倍，避免高盈利必然高估值。近期需求支持增长状态占较大权重；客户集中、技术变化和实际政策动向要求给予不利状态实质权重。**精确概率未经历史样本校准**，不能用资料篇数证明15%就是正确值。

逐路径经营利润乘对应PE，加未重复计价的资产，再加权得到经营价值6517.68亿元、非经营资产738.97亿元。这要求未来再投资回报及盈利寿命兑现；即便正常路径10倍，在393元入场也仅约18.76%年化。倍数区间及其长期增长要求在[估值附录](valuation/README.md)明确，未用“龙头”标签代替经济依据。

## 结论取决于误判后还能剩多少

原模型给后期新品部分受限的独立权重为零。11月17日路透报道，即使美国云厂商反对，政府仍准备推进对新型号的限制。新版从正常经营拨出15个百分点给这一结果，保留首期起广泛受损的15%。这两项都是对三年经营结果的主观赋权，政策出台、传导至采购、最终造成多大损失是三个不同问题。[路透11月17日报道](https://www.marketscreener.com/news/trump-s-china-data-center-curb-advances-despite-amazon-google-meta-lobbying-ce785edcd98bf423) · [政策与毛利证据](evidence/README.md)

部分受限路径前两期仍按正常交付，到第三期才因新品份额和组合变差，收入从正常路径2784亿元降至2324亿元，归母经营利润从653亿元降至461亿元。先沿用正常状态平均13倍，买入上限从418.29降至397.61元。再按增长寿命缩短取10倍，上限降至386.98元。经营与现金差异贡献20.69元，倍数贡献10.63元（分项四舍五入）。因此，393元是否合格也取决于限制发生后，客户流失是否持续到终点以后。

393元比修订上限高6.02元。固定部分受限15%，严重受限低于约13.73%时，393元才达到或超过18%回报门槛。反过来，严重受限固定15%，部分受限的临界权重为12.12%。若正常和部分受限路径三期毛利各低2个百分点，上限进一步降至372.42元。反之，两条路径的三期毛利同时比设定高约0.83个百分点，393元也能达标。[联合压力表与复算](valuation/README.md)

在386.98元入场，周期情景累计亏损约48%，严重准入受限约89%。若价值兑现晚两年且没有额外分红，393元对应的预期年化降至10.22%。按本次主预测，393元尚未达到研究买点。

后续最有信息量的变化是：2027订单交付与回款能否同步；营运资金是否持续超过收入的模型比例；1.6T之后新品的价值量、良率和CPO份额；TeraHop利润占比、现金义务与H股发行条件；政策从讨论到适用公司及产品的正式限制。毛利、归母比例或客户准入持续偏离时，应更新经营与权重，不能仅因股价下跌继续抬高乐观情景。

十月股份月报原件、子公司资金分布及完整退出条款仍有缺口，其影响已进入稀释、资金归属、现金与结算压力；未据此虚构精确数据。公开资料支持理解近期盈利机制和构造有边界的条件预测，尚不能证明远期技术与政策结果已在能力圈内被充分掌握。本轮为研究自查，未经独立审阅。
