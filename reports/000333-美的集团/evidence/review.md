# 既有审阅异议摘录

[返回主报告](../README.md) · [来源与材料边界](../evidence/README.md)

本附录由既有研究摘录整理，保留数据口径、推理及来源线索。“已核”等标记沿用原研究，未在本次结构整理中重新验证。事实、计算和假设不能混为一类；现行结论见主报告。

既有评审分别讨论了盈利假设偏松与退出倍数偏高，现行口径采用 420 亿元、21 倍。本次仅整理这些意见，没有新增独立复核。

以下保留历史异议的论证；其中的旧参数、建议价与旧复核状态均不代表现行结论，也不是本次新开展的独立审阅。

## 问题清单

### P1 · NI3=430 相对「中性偏冷」略偏乐观

- **严重度**：中\
- **证据**（仅驱动树/挑刺包）：\
  - A1：2025A 扣非 412.7 亿；A2：2026E 谷底约 350（前三季 −22.5%）；根目标 NI3=430。\
  - 自 350→430 隐含约 **+7.1%/年**（3 年）；相对 2025A 四年 CAGR 仅约 +1%，但终点 **反超 2025A 约 4%**。\
  - A4：正常年毛利假设 28–28.5%，而 H1'26 已见 27.95（相对 2025 的 29.9 已压）；路径同时要收入 CAGR 仅 2.5–3% 却把扣非/营收抬回约 8.3–8.5%。\
  - A5：理想结构 450→430 仅 −4.4%，同时覆盖「分品类出厂未知 + 未分配残差约 16 亿」——残差本身约相当于 2025A 扣非的 ~4%，轻冲击偏松。\
- **判定**：**可修**\
- **回流节点**：`A`（NI3）、`A2`（谷底）、`A4`（毛利正常年）、`A5`（缺口轻冲击）\
- **修改建议（给生产者，不代改卡）**：\
  - 优先：把基准 NI3 收到 **410–420 亿**（建议锚 **420**，仍高于谷底复苏、接近/略高于 2025A 中性，更贴「偏冷」）。\
  - 或：保留 430，但把路径标签改为「中性（非偏冷）」并写明终点反超 2025A 的理由；同时把 A5 缺口扣幅至少提到 **约 6–8%**（450→约 415–420）二选一，勿两头都宽。\
  - **不要**因此再把 exit PE 从 15.3 砍到 14（与 A5 重复从严，驱动树已自禁，本报告维持该禁令）。

### P2 · 退出 PE=15.3 窗内含 2021 高点，但非正式快照

- **严重度**：低–中\
- **证据**：B1 窗含 2021:19.89；中位 15.25→15.3；剔 2020 低谷符合 RC1；修剪 ±5.6% 过关。同时标注「非正式 snapshots[]」「买点不启用」。\
- **判定**：**通过**（研究用倍数可保留）\
- **回流节点**：`B` / `B1`（若生产者补正式 snapshots 再核）\
- **说明**：正式启用买点前必须补 `multiple_anchor.snapshots[]`；在此之前 15.3 作研究用退出倍可接受。不建议为「显得保守」单边改 14×。

### P3 · 现金转化「过」vs 营运资本结构黄灯

- **严重度**：低–中\
- **证据**：挑刺包写 OCF/扣非 1.29–1.69、购建≪利润；同时 WC「应收↑预收↓票据↑」黄灯。按 INVESTMENT-LENS：利润长期显著高于经营现金且占款膨胀 → 不过关。此处 **OCF>扣非**，不像假钱；黄灯是结构预警，尚未构成「长期吸血」铁证。\
- **判定**：**通过**（「过」站得住）\
- **回流节点**：筛选结论 / 驱动树 `H`（维持性 capex/OCF，筛选用）\
- **修改建议（表述级，可选）**：结论卡或跟踪条件显式写「WC 黄灯若连续两年恶化且 OCF/扣非跌破约 1.0 → 现金转化改打折（建议先打九折再估）」；**不必**本轮因黄灯把筛选改成打折。

### P4 · EY≈6% 粗对照是否应退回筛选

- **严重度**：低\
- **证据**：现价市值≈6724 亿 ÷2025 扣非≈413 → PE≈16.3、EY≈6.1%，远低于 20% 门槛。SIMPLE-FLOW 要求粗对照差很大时退回步骤 2 重判现金转化。\
- **判定**：**通过**（处理方式正确）\
- **回流节点**：交叉检查表（非定价节点）\
- **说明**：EY 低主要反映 **现价已贵**（现价相对闸价约高 64%），不是现金转化失败。生产者未把它写成第二合理价，且动作已是「观察」——符合「只作筛选提示、不形成第二轨」。无需因 EY 再打折 NI3。

### P5 · 是否重复从严 / 过松

- **严重度**：低\
- **证据**：同一风险只在 A5 扣 NI3，明确禁止再砍 PE；净现金未另加（避免与含息扣非双计）——方向正确。综合 P1，当前更接近 **略松** 而非重复从严。\
- **判定**：**可修**（并入 P1 的 NI3 收口；倍数与净现金处理保持）\
- **回流节点**：`A5`（唯一扣险点）

### P6 · 买点未启用 / 研究用闸价

- **严重度**：低\
- **证据**：PE 快照非正式；分品类量价与残差公开已尽；卡写「买点未启用」「研究用闸价」。符合材料薄仍可出合理买入点、不得写成可执行到价的规则。\
- **判定**：**通过**\
- **回流节点**：结论卡启用状态（非驱动树数值节点）

### P7 · 护城河 / 五力独立性核验受限

- **严重度**：低（流程缺口，非直接改价）\
- **证据**：挑刺包未附五力与护城河机制摘录；最大风险句提到「成本/品牌河」证伪条件，但挑刺人按禁令未读 [business.md](business.md)，无法独立核验「难替代」是否经得起五力。\
- **判定**：**可修**（补摘录，不强制改价）\
- **回流节点**：下轮 `review_packet` 应附竞争/护城河 10～20 行摘录；若摘录显示河主要靠规模成本且国内量价已破位，再回流 `A4`/`A5` 加重扣幅。

### P8 · 旧闸约 54 与本轮约 54

- **严重度**：信息\
- **证据**：本轮 B20≈53.86≈约 54，与旧闸约 54 基本持平（现价已修正为 88.12）。闸价变动 ≪15%，无需因「变动过大」退回再挑。\
- **判定**：**通过**\
- **回流节点**：无

## 问题清单

### P1 · 退出 PE=22 落带正确，但相对「下半」叙事略靠上

- **严重度**：中（本轮焦点）\
- **证据**（仅挑刺包 / 驱动树 / 卡）：\
  - SIMPLE-FLOW §4：主报须在约 **20～30**；弱护城河/强周期/区域龙头偏 **20–25**；强定价权/稳定轻资本偏 25–30；历史中位不得直接主报。\
  - 包内画像：定价权**弱**、周期**中性偏冷**、成本护城河、现金转化**过**、全国规模、ROE 约 20%。\
  - 生产者理由：弱定价权+偏冷 → 偏 20–25 **下半**；取 **22**（>20：全国规模/现金/ROE；不上 25：定价弱/偏冷）。\
  - 算术：20–25 中位 **22.5**；「下半」大致 **20–22.5**。**22 落在下半上沿**，距中位仅 0.5，对「下半」用词偏满。\
  - 对照：若取地板 20 → FV≈110 / 闸≈67；取 21 → FV≈116 / 闸≈70；取 22 → 121/73；取 25 → 138/83。\
- **判定**：**可修**\
- **回流节点**：`B` / `B0` / `B2`（退出 PE 主报与带内分档）\
- **修改建议（给生产者，不代改卡）**：\
  - **首选**：主报改为 **21×**（更贴自述「下半」+ 弱定价权；仍高于地板：全国龙头/成本河/现金转化/ROE）。对应研究用 **合理价约 116、闸价约 70**（NI3=420 不变）。\
  - **次选**：维持 **22×**，但在 B2/B4 补一句显式理由——「取下半上沿 / 近中位，因全国非区域 + 成本河（美芝/威灵）+ 现金转化过，弱定价权只用来挡住 23–25 而非压到 20」；无此句则「下半→22」略跳步。\
  - **不建议**上到 23–25（与弱定价权、偏冷冲突）；**不建议**因历史 15.3 压回带外（违反新硬规则，且包已正确废止）。

### P2 · 是否与 NI3 路径「重复扣险 / 过松叠加」

- **严重度**：低–中\
- **证据**：\
  - NI3 路径已含偏冷：A2 谷底约 350、A3 收入 CAGR 约 2.5–3%、A5 450→420（−6.7%）。驱动树写明「同一风险只在 A5 扣一次；不叠砍 exit PE」。\
  - 退出 PE 用「弱定价权 + 偏冷」做**带内分档**——这是 §4 要求的判断取值，**不等于**对 A5 缺口再砍一刀；性质上是「倍数档位」而非「利润再打折」。\
  - 风险在于反方向：**过松叠加**——NI3 取可研区间上沿 420，同时 PE 取「下半」上沿 22，两边都偏宽一侧。\
- **判定**：**可修**（并入 P1；不强制重开 NI3）\
- **回流节点**：`B0`（优先）；`A`/`A5` 仅作观察、本轮不强制\
- **修改建议**：\
  - 优先用 P1 把 PE 收到 **21**，即可拆开「两边上沿」；**不要**再把 PE 收到 20 的同时又把 NI3 收到 410（易变重复从严）。\
  - NI3=**420 维持**（除非另有新公开事实）；可研下限 410 留作跟踪证伪，不本轮改点估计。

### P3 · NI3=420 是否仍偏松（本轮是否强制回流）

- **严重度**：低（本轮非焦点）\
- **证据**：A1 2025A 扣非 412.7；目标 420 相对 2025A 四年仅约 +0.4%/年，但相对谷底 350 三年约 +6–7%/年；区间标注 410–420。上一轮挑刺已自 430 收至 420。包要求「除非挑刺强制，勿重开 NI3」。\
- **判定**：**通过**（本轮维持；不强制回流）\
- **回流节点**：无（观察 `A`）\
- **说明**：420 仍是偏冷叙事下的上沿点估计，可接受；与 P1 联立时用 PE 微调即可，勿两头同轮猛砍。

### P4 · 闸价 +39% 是否混入公式/参数误改

- **严重度**：高（若成立）→ 核后为**无问题**\
- **证据**：旧 FV84.22/B20≈52.73 @15.3× → 新 121.10/73.50 @22×；n、DPS_min3=3.0、h=20%、股本 76.30 与上一稿一致；变动幅度与 22/15.3 比例匹配。\
- **判定**：**通过**\
- **回流节点**：无\
- **说明**：+39% 是规则强制换锚的预期结果（>15% 已正确触发换人挑刺），不是暗改 hurdle/叠息。

### P5 · 有无违规第二轨 / 两轨取低

- **严重度**：高（若成立）→ 核后为**无问题**\
- **证据**：卡与树仅报 PE 轨合理价；H 节点写明维持性 capex/OCF「筛选用，不进定价」；交叉表 EY 与闸价/FV 比均非第二合理价。\
- **判定**：**通过**\
- **回流节点**：无\

### P6 · 买点未启用 + 研究用草稿表述

- **严重度**：低\
- **证据**：卡抬头写明买点未启用、须换人挑刺后再正式定稿、不执行自动下单；现价 88.12 相对新闸约高 20%。\
- **判定**：**通过**\
- **回流节点**：无\
- **说明**：规则换锚后仍可给研究用闸价；**不必**因 +39% 暂停报价，但定稿前必须消化本报告 P1。
