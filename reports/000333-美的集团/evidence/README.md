## 独立复核意见

2026年11月19日独立复核通过。复核提出两项实质修订：经营利润按净债务法改列为归母份额的无杠杆税后经营利润，附录补列扣融资成本的归母交叉核算；商誉分别列示半年末、三季度末余额和半年计提额。独立按五条路径重算了分红时点、转股、期权和到期权益，买入上限67.98元、卖出参考97.30元，定价日年化4.80%。影响上限最大的已测因素是经营利润率和到期倍数，分红权属的单项影响约0.50元。
