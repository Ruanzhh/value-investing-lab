# 美的集团估值｜怎样把制造利润和资金池分开

金额为人民币亿元，股数为亿股。模型以2026-11-19为起点，显式三期止于2029-11-19。用年度经营规模近似每个滚动持有年度，缺乏分月利润。仅计算持续持有A股的回报。[主报告](../README.md) · [来源](../evidence/README.md) · [参数](inputs.json) · [计算器](calculate.py) · [逐期结果](results.json)

## 经营口径与证据锚

三季表以千元列报，换亿元除以十万。2026年前三季营业收入3673.65，营业总收入3690.87，后者还含金融业务利息和手续费。为避免将单估存款收益、公允价值、套保和股权投资收益乘制造业PE，先取营业收入，减营业成本、税金、销售、管理、研发。2025全年为4564.52−3359.90−22.17−428.91−160.92−177.88＝414.73；2026年九个月为3673.65−2738.17−16.87−302.81−114.29−125.13＝376.39，上年同期354.58。2024全年359.53。滚动十二个月经营小计436.54、收入4607.60，利润率9.47%。同期前三季小计率从9.77%到10.25%。下半年季节性和第四季费用较高，不能用9个月乘4/3。[年报及季报原件](../evidence/README.md)

再从小计走到可持续的经营盈利。预留正常信用/库存损失、汇兑和套保净摩擦，同时保留持续的产业相关补助和金融子公司放贷业务净贡献。历史示范将以上净项合计取收入的−0.2%，2026年前三季集团调整经营利润约369.04、按18%税和98.5%归属得298.07亿元；2025全年约327.61亿元。示范对应实报归母413.93及439.45亿元。归属假设参考2025年少数损益5.75亿元、2026前三季1.05亿元、上年同期7.54亿元，并为海外及控股子公司利润恢复留有份额。半年报金融子公司放贷息5.63亿元，存放同业央行息4.47亿元。放贷本金约133亿元保留在营运体系，放贷贡献计入经营；自有现金利息、联营分红、证券浮盈、资产处置和非持续补助剔出，单估的超额资金仅计1.5%税后回报。母公司的普通融资和债券本金已用资产作偿债拨备，经营利润以拨备偿还后的资本结构估计，剔除相关利息；不会既按带息利润乘PE又扣同一全部债务。实际报表仍有借款和可转债。美的同时持有大额带息存款和债务，因此采用先从金融资产拨备偿债、再给无杠杆经营利润定价的方法。文中经营利润均为归母份额的无杠杆税后经营利润，经营倍数按相应的再投资后现金收益率校准。若沿用实际融资结构，2025年与2026年前三季的财务项目利息费用分别为22.11、13.18亿元，利息收入为84.44、53.82亿元。按同一税率和归属比例，从327.61、298.07先扣税后融资成本，得309.75、287.42亿元的带融资成本经营归母代理；再加税后存款等利息，得377.95、330.89亿元。实报归母剩余差额还包含投资公允价值、汇兑、税率与损失等。该交叉核查只用于解释真实融资，与含净资金的主估值分开。[半年报附注四(36)(47)(52)](../evidence/raw/2026半年报.pdf)

## 股数、分配日和终点

11月18日已披露A股扣库67.66336227亿股、H股扣库6.50204亿股。A股11月19日公告注销123,958股，交易所变动表已含该批次，避免重复减股；11月19日实际行权若有新变化则有时点差。十月底约1198万股已授未行权A股期权按三年等额归属、45元行权款代理；可能有失效或新增。现金流和分红均用变动后的权益分母，库存股注销不会额外减少一次经济股数。本模型不假设每年新增免费回购。若后续库存股转作激励，则应同步计入股份和相关对价。[港交所股份文件](../evidence/README.md)

两笔可转债分别可换约0.9392亿及0.7856亿H股。正常路径假设短券于首期转股、长券在终点仍以本金留存；上行两笔均转（长券按第三期夏季分红前转股近似），下行两笔均按本金。转股解除原先的本金拨备并增加股数。2033长券的剩余期权时间价值、实际汇率和后续每次分红调价难以还原，边界测试两券均还本/均转股。没有将65.20亿元应付债券与长券面值相加。

2025—2027年规划在满足条件时，以近三年年均可分配利润的30%为现金分配底线，单次利润分配中的现金占比至少60%，合规回购可计入。模型65%是正常路径对实际派现的假设，规划到期后也有变化空间。2025每股合计4.30元是已发生的历史分配。首期夏季派息按2026归母代理465亿元×状态分配率，扣除已预留的2026中期0.50元/股。后续各期总分配以之前一年模拟清偿债务后的归母份额经营利润加资金税后收益，乘正常65% / 上行68% / 下行52%；先扣对应中期款再算夏季末期款。按7月15日及11月27日代理具体支付日，2029年11月末尚未支付的金额仍在期末权益内，按终点含该权利处理，不能再加未来股息。首笔A股中期每股0.50元按11月27日估计；在核查时点尚未取得A股实施日，不能把H股登记日用作A股登记日。若新买A股无权领取，买入价低约0.50元。用净资金池1.5%收益近似经营期间资金利息；对增资、转股、自有现金和分红按期间计息，已派现金从留存扣减。模型不含投资者个人通胀调整或杠杆。
