## 问题清单

### P1 · 退出 PE=22 落带正确，但相对「下半」叙事略靠上

- **严重度**：中（本轮焦点）  
- **证据**（仅挑刺包 / 驱动树 / 卡）：  
  - SIMPLE-FLOW §4：主报须在约 **20～30**；弱护城河/强周期/区域龙头偏 **20–25**；强定价权/稳定轻资本偏 25–30；历史中位不得直接主报。  
  - 包内画像：定价权**弱**、周期**中性偏冷**、成本护城河、现金转化**过**、全国规模、ROE 约 20%。  
  - 生产者理由：弱定价权+偏冷 → 偏 20–25 **下半**；取 **22**（>20：全国规模/现金/ROE；不上 25：定价弱/偏冷）。  
  - 算术：20–25 中位 **22.5**；「下半」大致 **20–22.5**。**22 落在下半上沿**，距中位仅 0.5，对「下半」用词偏满。  
  - 对照：若取地板 20 → FV≈110 / 闸≈67；取 21 → FV≈116 / 闸≈70；取 22 → 121/73；取 25 → 138/83。  
- **判定**：**可修**  
- **回流节点**：`B` / `B0` / `B2`（退出 PE 主报与带内分档）  
- **修改建议（给生产者，不代改卡）**：  
  - **首选**：主报改为 **21×**（更贴自述「下半」+ 弱定价权；仍高于地板：全国龙头/成本河/现金转化/ROE）。对应研究用 **合理价约 116、闸价约 70**（NI3=420 不变）。  
  - **次选**：维持 **22×**，但在 B2/B4 补一句显式理由——「取下半上沿 / 近中位，因全国非区域 + 成本河（美芝/威灵）+ 现金转化过，弱定价权只用来挡住 23–25 而非压到 20」；无此句则「下半→22」略跳步。  
  - **不建议**上到 23–25（与弱定价权、偏冷冲突）；**不建议**因历史 15.3 压回带外（违反新硬规则，且包已正确废止）。

### P2 · 是否与 NI3 路径「重复扣险 / 过松叠加」

- **严重度**：低–中  
- **证据**：  
  - NI3 路径已含偏冷：A2 谷底约 350、A3 收入 CAGR 约 2.5–3%、A5 450→420（−6.7%）。驱动树写明「同一风险只在 A5 扣一次；不叠砍 exit PE」。  
  - 退出 PE 用「弱定价权 + 偏冷」做**带内分档**——这是 §4 要求的判断取值，**不等于**对 A5 缺口再砍一刀；性质上是「倍数档位」而非「利润再打折」。  
  - 风险在于反方向：**过松叠加**——NI3 取可研区间上沿 420，同时 PE 取「下半」上沿 22，两边都偏宽一侧。  
- **判定**：**可修**（并入 P1；不强制重开 NI3）  
- **回流节点**：`B0`（优先）；`A`/`A5` 仅作观察、本轮不强制  
- **修改建议**：  
  - 优先用 P1 把 PE 收到 **21**，即可拆开「两边上沿」；**不要**再把 PE 收到 20 的同时又把 NI3 收到 410（易变重复从严）。  
  - NI3=**420 维持**（除非另有新公开事实）；可研下限 410 留作跟踪证伪，不本轮改点估计。

### P3 · NI3=420 是否仍偏松（本轮是否强制回流）

- **严重度**：低（本轮非焦点）  
- **证据**：A1 2025A 扣非 412.7；目标 420 相对 2025A 四年仅约 +0.4%/年，但相对谷底 350 三年约 +6–7%/年；区间标注 410–420。上一轮挑刺已自 430 收至 420。包要求「除非挑刺强制，勿重开 NI3」。  
- **判定**：**通过**（本轮维持；不强制回流）  
- **回流节点**：无（观察 `A`）  
- **说明**：420 仍是偏冷叙事下的上沿点估计，可接受；与 P1 联立时用 PE 微调即可，勿两头同轮猛砍。

### P4 · 闸价 +39% 是否混入公式/参数误改

- **严重度**：高（若成立）→ 核后为**无问题**  
- **证据**：旧 FV84.22/B20≈52.73 @15.3× → 新 121.10/73.50 @22×；n、DPS_min3=3.0、h=20%、股本 76.30 与上一稿一致；变动幅度与 22/15.3 比例匹配。  
- **判定**：**通过**  
- **回流节点**：无  
- **说明**：+39% 是规则强制换锚的预期结果（>15% 已正确触发换人挑刺），不是暗改 hurdle/叠息。

### P5 · 有无违规第二轨 / 两轨取低

- **严重度**：高（若成立）→ 核后为**无问题**  
- **证据**：卡与树仅报 PE 轨合理价；H 节点写明维持性 capex/OCF「筛选用，不进定价」；交叉表 EY 与闸价/FV 比均非第二合理价。  
- **判定**：**通过**  
- **回流节点**：无  

### P6 · 买点未启用 + 研究用草稿表述

- **严重度**：低  
- **证据**：卡抬头写明买点未启用、须换人挑刺后再正式定稿、不执行自动下单；现价 88.12 相对新闸约高 20%。
