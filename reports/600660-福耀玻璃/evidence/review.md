## 逐条挑刺

### 1. 现金转化判「过」是否过松？

| 项 | 内容 |
|---|---|
| **严重度** | 高 |
| **证据** | 0B：OCF/NI 均值 1.26、弱扩张年 Capex/D&A 0.79–1.03 作维持代理、(OCF−D&A)/NI 均值 **0.883** → 书面「过」。同文件承认扩张购建 45–62、预算 77、交流常态 60–70。[fin5y_out.json](../valuation/fin5y_out.json)（本目录）近年 Capex/D&A：2023 **1.77**、2024 **2.01**、2025 **2.00**——维持/增长拆分公司未披露。BUSINESS-DEPTH §6 要求把「维持竞争力」再投入与扩张分开写；当前专表用「维持当前产能≈1.0×D&A」过关，对模具/认证/产品升级/海外本地化是否算维持未量化。 |
| **判定** | **需用户拍板**（小修路径二选一，均不恢复双轨） |
| **回流节点** | **0B / 筛选三性** |

**小修选项（须择一写进 0B）：**

- **A. 维持「过」**：补一句——维持竞争力增量 Capex 公开侧无法拆分，已用证伪清单（Capex 连续两年 >80 亿且收入增速 <5% 等）跟踪；买点启用须明示该不确定性。合理价/闸价可暂留 **66.8 / 39.9**。\
- **B. 改判「打折」**：因 (OCF−D&A)/NI≈0.883 且扩张期未结束，利润按 **约九成（建议 0.88–0.90）** 再进 PE。示意（非代算定稿）：合理价约 **59–60**、闸价约 **35–36**（接近旧两轨取低，但是筛选打折，不是 FCF 轨）。

独立意见倾向：**若「维持」含竞争力而非仅产能，B 更贴证据；若严格按透镜「维持当前盈利」字面，A 可接受但必须把未量化风险写死。** 当前文案从「旧透镜误并扩张 → 不过」直接跳到「过」，中间缺少对「维持竞争力」的显式取舍 → 偏松。

### 2. 净利率 16.5% 相对 2025 的 20% 是否仍偏乐观？

| 项 | 内容 |
|---|---|
| **严重度** | 高（清单建议）→ 审后实质 **中** |
| **证据** | 扣非净利率 2022–2025：16.6 / 16.7 / 19.0 / 20.0%；基准取 **16.5%**，相对 2025 高峰已下修 3.5pct，贴近 2022–23 低位。drill：返利约解释 0.4pct，其余中枢回归。2026 前三季利润下滑主因汇兑 −10.67 亿，剔汇兑利润总额 +1.18%（0B / fin5y）。每 1pct≈4.05 元（[calc_pe_only_out.json](../valuation/calc_pe_only_out.json)）。 |
| **判定** | **通过**（相对历史中位不算乐观；相对高峰已留回归） |
| **回流节点** | 1.2（仅跟踪，不强制改数） |

残余风险：年降+海外+汇兑若叠加，可能落到 15–16%。属敏感度叙事，不构成单独退回；不必在净利率上再砍一刀（见条 7）。

### 3. 退出 PE 19.03 是否应剔 2024 的 21.87？

| 项 | 内容 |
|---|---|
| **严重度** | 中 |
| **证据** | 四年年末 PE：19.62 / 17.65 / **21.87** / 18.44 → 中位 19.03（已核）。剔 2024 后三年中位约 **18.44**，对合理价约 −3% 量级（示意 66.8→~64.7），非定性翻转。2024 为样本高点，但四年样本剔一年偏激进；透镜要求同业/更高倍数不抬升，未要求剔本公司历史高点年。 |
| **判定** | **小修**（披露敏感度即可，不强制改主路径） |
| **回流节点** | 1.3 |

建议在 drill / 卡旁注：若用 18.44，合理价/闸价约同步下移 ~3%；主路径维持 19.03 可接受。

### 4. 收入锚 466 + 其后 6% 与前三季 +2.46% 是否打架？

| 项 | 内容 |
|---|---|
| **严重度** | 中 |
| **证据** | 前三季收入 341.23、同比 +2.46%；全年锚 466.08 隐含 Q4≈124.9，高于前三季季均≈113.7（约 +10% 季节性/赶工假设，drill 标「推断」）。其后 6%/年对合理价敏感度仅 ±1.7%（增速 ±10%）；收入锚 ±10% → 合理价 ±10%。情景与「量从高增回落平台偏弱」（生意理解 §4）略紧。 |
| **判定** | **小修** |
| **回流节点** | 1.1 / 1.4 |

须补：Q4 如何从 341.23 接到 466 的假设一句。若年报/展望显示全年更近 450–455，应下调锚后再乘 PE；仅增速 6% 本身因敏感度低可不单改。

### 6. 闸价 +11.9% 是否掩盖扩张期应更严的安全边际？

| 项 | 内容 |
|---|---|
| **严重度** | 中 |
| **证据** | 新闸价 39.9 vs 旧两轨 35.6，**+11.9%**（<15%，未触「须解释或退回」的变动门槛，且已解释为取消取低）。旧取低实质用 FCF 轨表达扩张吸金；新规则要求该判断前移筛选。若 0B 维持「过」且不打折，闸价上修是规则后果；若应「打折」0.88–0.90，则 +11.9% **确实**部分掩盖了扩张期保守性（打折后闸价示意回落到约 35–36）。 |
| **判定** | **需用户拍板**（与条 1 绑定，不单开第二轨） |
| **回流节点** | 根·闸价 ← 先回流 **0B** |

独立意见：**不得**为压闸价而恢复 FCF×P/F 取低；应在筛选选 A/B。选 A 则接受 39.9 并写明扩张期现金薄于账面净利只作跟踪；选 B 则下调后再定稿。
