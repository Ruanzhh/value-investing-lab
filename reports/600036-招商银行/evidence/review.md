## 问题清单

### R1 · 利润为真打折只扣一次（无重复扣险）

- **问题**：筛选「利润为真」是否已只扣一次、有无在 ROE/PB 上重复从严。\
- **严重度**：低（本条为确认项，未发现违规）\
- **证据**：\
  - [README.md](../valuation/README.md)：Y1 净利 1,445 亿低于当前年化约 1,537 亿，原因写明为信用成本从报表 0.60–0.72% **一次**正常化到 0.90%。\
  - [README.md](../valuation/README.md)：明示「信用正常化已进利润路径，PB 窗口不再为信用二次打折」；退出 PB 用窗 P50=0.953（≤优质回退 1.00，禁止上修），符合 `bank-valuation-rules.md`（原材料未收录） 中值规则，并非额外信用折扣。\
  - 未见「下调 ROE + 过低回退 PB」双杀；牛档只降信用成本、不叠拨备释放（[README.md](../valuation/README.md)）。\
- **判定**：**通过**\
- **回流节点**：L1-2 信用成本；衍生 BPS₃/ROE 路径\

### R2 · 基准信用成本相对生成率仍偏低，「贴近生成率」表述偏满

- **问题**：基准信用成本 **0.90%** 相对本公司生成率 **约 1.03%–1.07%** 仍低约 13–17bp；相对报表 0.60–0.72% 已上修，但称「贴近生成率」易让人以为利润为真缺口已基本闭合，实际基准路径仍隐含一定拨备垫消耗。\
- **严重度**：**中**\
- **证据**：\
  - [README.md](../valuation/README.md) L1-2：数值 0.90%；出处含生成率 1.03%–1.07% 与报表 0.60%/0.72%。\
  - [README.md](../valuation/README.md) 驱动表与勾稽条：一边写「贴近生成率」，一边数字仍明显低于生成率区间下沿。\
  - 敏感度（`drill_tree` / `valuation_calc`）：信用成本 ±10% → ΔFV3 约 ±1.6%。粗线性外推：若抬至约 1.00% / 1.05%，FV3 约降至 ~54.8 / ~54.3，B20 约 ~35.0 / ~34.7（**仅建议量级，非本助手改数**）。\
- **判定**：**可修**\
- **回流节点**：**L1-2 信用成本**\
- **建议改法（二选一，由生产者改树后重算，挑刺助手不改定稿）**：\
  1. **改数**：基准信用成本抬至生成率下沿附近（约 **1.00%–1.05%**），重滚 BPS₃→FV3→B20；或\
  2. **改表述+钉边界**：维持 0.90%，但删「贴近生成率」类满表述，改为「介于报表与生成率之间的正常化中值」，并在筛选勾稽写明剩余拨备垫消耗未完全关闭、证伪线仍用 1.2%。\

### R3 · 基准 NIM / 退出 PB 是否偏松

- **问题**：NIM=1.82%、退出 PB=0.953 是否对合理价偏乐观。\
- **严重度**：低\
- **证据**：\
  - NIM：取 2026Q1–9 披露且 Q3 环比持平（`intake` / `drill_tree` L1-3），明确「不假设息差大幅回升」——相对现况不松。\
  - 退出 PB：窗 P50 0.953 ≤ 优质回退 1.00 → 直接用 P50、禁止上修（[README.md](../valuation/README.md) + `bank-valuation-rules.md`（原材料未收录））——规则方向正确，不构成上修偏松。\
  - 贷款增速 3.5% 略高于 YTD +2.69%（零售仍负），属轻度乐观，但对 FV3 敏感度仅 ±0.3%（`drill_tree`），不单独升格。\
- **判定**：**通过**（贷款增速作备注，不强制改数）\
- **回流节点**：L1-3 NIM；L1-1 退出 PB；L1-6 贷款增速（备注）\

### R4 · 无 Ke-then-hurdle、无制造业 FCF 双轨残留

- **问题**：是否残留 Ke 折现后再叠 hurdle，或 FCF×倍数旧双轨。\
- **严重度**：低（确认项）\
- **证据**：\
  - [README.md](../valuation/README.md) 开篇与交叉节：主路径 = BPS₃×退出 PB；Ke 理论 PB 仅交叉；明示禁止 Ke-then-hurdle；闸价公式为 `FV3/(1+(h−y))^n`。\
  - 附录 PE 粗对照标明非主路径；明示禁止制造业 FCF×倍数旧双轨。\
  - 决策卡：银行走 PB–ROE/总回报，未并列 FCF 轨买点。\
- **判定**：**通过**\
- **回流节点**：根节点 FV3；闸价（总回报）\

### R5 · BPS₃、FV3=55.8、B20=35.61 与 y、n 算术自洽

- **问题**：关键输出是否算对、口径是否一致。\
- **严重度**：低（确认项）\
- **证据（独立复算）**：\
  - BPS₀ 46.87，按 Y1–Y3 ROE 12.2%/11.8%/11.4%、payout 35% 滚存 → BPS₃≈**58.50–58.51**；与净利留存路径（1445/1505/1567 亿）一致。\
  - FV3 = 58.51 × 0.953 = **55.76** → 对外四舍五入 **55.8**（与 [README.md](../valuation/README.md)「55.75 四舍五入」一致）。\
  - y：Y1 净利×35%/股本 → DPS_fwd≈2.006；2.006/42.54≈**4.71%**；trail 2.016/42.54≈4.74%；取较低者，符合银行规则「不用 trailing 抬买点」。\
  - B20：55.76 / (1+(0.20−0.0471))^**3.151** ≈ **35.61**；纯价格（y=0）≈31.39；B22≈33.73——与卡一致。\
  - 现价 42.54 相对 B20 贵约 19.5%——与卡一致。\
- **判定**：**通过**\
- **回流节点**：衍生 BPS₃/ROE 路径；根节点 FV3\

### R6 · 闸价相对旧 35.62 实质不变的解释是否站得住

- **问题**：Δ≈−0.01 元是否真由 n/y 微调解释，而非暗改驱动却声称为「不变」。\
- **严重度**：低\
- **证据**：\
  - [README.md](../valuation/README.md) / `drill_tree`：相对 11-05，NIM/贷增/信用/非息 **写明不变**；BPS₃、退出 PB 不变 → FV3 不变。\
  - [README.md](../valuation/README.md)：asof +1 日 → n 3.154→3.151；现价 42.38→42.54 → y 略降；两效应近似抵消。独立用 FV3=55.76、n≈3.154、y≈4.73% 反算旧闸约 **35.62**；新参约 **35.61**——解释算术成立。\
  - 闸价变动 ≪15% 数字核对关卡阈值，无需因变动幅度退回重挑。\
- **判定**：**通过**\
- **回流节点**：根节点 FV3；闸价（总回报）\
- **过程提醒（不升格）**：本轮若定位为「按最新深估标准重算」，仅声明驱动照搬 11-05 时，应在账本写清「标准升级后仍采纳原驱动的理由」；与 R2 信用成本缺口一并处理即可，不单独需拍板。\

### R7 · 公式年数 n：规则文本写 ³、底稿用 3.151

- **问题**：`bank-valuation-rules.md`（原材料未收录） 买点公式写作 `(1+(h−y))³`；本卡用至 FY3 的实际年数 **n=3.151**。用 n=3 则 B20≈36.39，与现报 35.61 差约 2%。\
- **严重度**：低\
- **证据**：规则字面为立方；[README.md](../valuation/README.md) / `valuation_calc` 明确 n=3.151 至 2029-12-31；约三年研究惯例可解释，但与规则字面不完全同一。方向是略压低闸价（更严），未见凑到价。\
- **判定**：**通过**（建议在 valuation 脚注一句「约三年按实际日历年数 n，非固定整数 3」；不强制改数）\
- **回流节点**：闸价（总回报）\

### R8 · PB 窗末笔收盘与 intake 现价轻微不一致

- **问题**：[pb_window_calc.txt](../valuation/pb_window_calc.txt) 记系列末笔 2026-11-05 收盘 **42.37**；[README.md](README.md) / 卡用行情现价 **42.54**。\

- **回流节点**：L1-1 退出 PB\

## 事前验尸（简表）

若三年后该研究仓亏约 30%，较可能路径：\
1. 零售信用生成率中枢上移且拨备垫耗尽（→ 回流 L1-2；熊档信用 1.2% 已部分覆盖）。\
2. 活期占比/存款成本优势失守，NIM 再下台阶（→ L1-3；熊 NIM 1.65%）。\
3. 银行股风险偏好压缩，退出 PB 跌向 P20 一带（→ L1-1；内部熊 FV3≈48.9 已覆盖部分）。\

未见「改口径让买点变近」：相对旧闸 35.62 几乎不动且略降；到价状态仍为未到价。
