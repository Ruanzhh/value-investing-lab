## 现金是真的，但不能都当作经营新增现金

F1审计的另一关键事项是货币资金存在性和完整性，披露了银行函证、流水与存单检查。F2无非经营性资金占用、违规担保及重大诉讼披露。它们支持继续使用财报研究，但本研究未接触银行流水或独立函证。

**现金流分类桥：**

| 亿元 | 2024全年 | 2025全年 | 2026H1 |
| --- | ---: | ---: | ---: |
| 报表经营现金流 | 47.28 | 19.47 | 15.43 |
| 减：受限资金净释放，负数为净占用 | 5.89 | -9.92 | 4.30 |
| 剔除该时点项后经营现金流 | 41.38 | 29.39 | 11.13 |
| 当期归母利润 | 55.17 | 35.49 | 21.64 |

这是研究重分类，不是改写法定现金流，也不是归母自由现金流。F1第146–147页的2025调节表包含存货增加15.01亿元、经营应收减少22.67亿元、经营应付减少26.48亿元；不能只选应收改善解释现金质量。M1第2问说明2023年的受限资金支付曾列在经营应收变化中，因此不直接拼接“其他”项目作跨年趋势。

H1利息收入2.41亿元也进入经营现金流；进一步简单扣除后约8.72亿元，但没有重分配相应所得税和少数股东现金，不能称为精确的归母经营现金。2026前三季21.21亿元经营现金流减长期资产购建支出5.81亿元，账面差额15.39亿元，同样不是可全部派出的归母现金。

Q3可作一项检查：货币资金117.33减现金及等价物112.35，差额4.98亿元；2025末受限资金16.93亿元，差额减少11.95亿元。**若**变化均对应经营性受限资金释放，则前三季剔除此项的经营现金流约9.26亿元，扣购建支出后约3.44亿元。季报缺少完整受限资金调节，故这只是桥接估计，未标为已披露精确数。它与季报“收回受限资金增加”的解释方向一致，提醒不能把现金流转好全归于动销。

现金预测把这些影响显式转入营运资金与资本开支，未把释放受限资金作为可持续利润。一般修复路径仍有每年4–5亿元新增营运资金，衰退路径允许在收入下降时库存及渠道回款继续占用现金。需要下一份年报验证这些假设。

## 治理与资本配置的证据边界

F1标准无保留审计；收入、资金是关键审计事项。F1及F2披露范围内未见重大诉讼、处罚、非经营性资金占用或违规担保。F1关联采购及接受劳务约0.247亿元、关联销售及提供劳务约0.086亿元，不是主要收入来源；“无重大关联交易”不等于完全没有关联往来。不能据此断言所有治理风险已经排除。

国资控股、管理层薪酬按规定及业绩考核，并不自动构成好坏判断。公开披露没有完整的长期资本回报考核权重，F2说明无股权激励实施。M1对库存两次给出总体合理的定性回答，没有逐单品数据；对扩产节约成本未给可核验结果；对B股转板明确暂无计划。信息边界需要保留，不能用“诚信”“优秀文化”等标签代替证据。

正面证据是现金分红：2025全年归属分红23.2584亿元，占归母利润65.53%；其中末期17.9724亿元在2026年7月付出。负面资本配置证据是黄鹤楼商誉减值和智能园投产后的低利用率。已有投入是沉没成本，不自动降低未来现金价值；但扩产收益未兑现也意味着不能给新增投入高回报假设。

2025末智能园工程进度表为99%，M1称2025全面建成投产；这是工程结算/进度口径与使用状态的区别。模型仍留后续建设、维护和改造支出，没有把“投产”解释为今后资本开支归零。F2披露无需要说明的重要承诺/或有事项，只能限定在披露标准内，不能证明没有未来付款需求。

## 外部观点用来挑战，而不是代替判断

E1较乐观，认为报表逐步向实际动销收敛；E2也支持去库，却提示经销商库存仍高。两份研究调整后2028年归母预测分别约29.6亿元和27.5亿元。与本模型第二段持有年度总归母28.33亿元数量级接近，但期间并不完全重合，不能称一致预期验证了本报告。它们也可能共同低估或高估恢复。

E3从线上价格挑战品牌定价权。其观察构成风险线索，线上券后价却未包含返利、促销补贴及所有渠道成本，不能据此精确量化经销商亏损。I1则为行业需求收缩提供更广样本，仍不能给出古井自身库存。管理层库存评价、券商走访与媒体价格观察在可验证程度上均弱于财报，模型因此保留较高的低位徘徊和衰退权重。

本次自查纠正/避免了四种容易改变结论的口径错误：将保证金释放全当新现金；将公司基酒库存等同经销商库存；将A股价乘总股数当作A+B实际市值；把包含现金收益的全部净利润乘PE后再加全部现金。本次没有独立外部审阅，不能称“已获独立确认”。
