## 7. 估值与敏感度（仅 PE 轨）

公式（[calc_pe_only_out.json](calc_pe_only_out.json) / 本附录）：

```
FV3 = (34.2 × 23 + 53.1123) / 5.286 = 158.856 → 约 159
B20 = (158.856 + 3.151 × 4.40) / 1.20^3.151 ≈ 97.236 → 约 97.2
合理买入点/合理价 ≈ 0.612（落在 0.55–0.62）
```

| 项 | 主报 |
|----|------|
| 基准合理价 | **约 159 元** |
| 合理买入点 B20 | **约 97.2 元** |
| 退出 PE | **23** |
| 买点 | **未正式启用** |

**退出 PE=23 理由（非历史中位照抄）**：区域白酒龙头 + 轻资本且现金转化（周期修正）过 → 不低于带下沿 20；难替代性同行第 3、省外退缩、去库修复、费用粘性 → 弱护城河/区域/周期带约 20–25；不得用增长扩张期高成交倍数（历史中位 28.1）抬主报，也难顶强定价权上沿 25–30；取该带中位附近 **23**。

**敏感性（不改主报）**：

| 扰动 | 合理买入点约 |
|------|--------|
| NI3 −10% / +10% | **88.9 / 105.6** |
| 退出 PE −10% / +10% | **88.9 / 105.6** |
| 富余现金 ±10% | 影响 <1 元量级 |

**交叉对照（附录，非第二条合理价）**：
- RI 正当 PE 20.8 → FV≈145，与主路径差 **1.097**（<1.25）\
- 无风险 25× → FV≈172，差 **1.083**（<1.25）\
- 历史中位 28.145 → FV≈192（**仅参照**）\
- 现价 TTM 盈利收益率≈3.3%；从现价三年后 15/20/25× 总回报约 1.15 / 1.46 / 1.77（含叠息）——达不到「大约翻倍」经验提醒

禁止现金流定价轨、禁止两轨取低。

**合理买入点相对 97.2**：**不变**。相对更早口径：相对纯 PE 闸 116.0 为 −16.2%（退出倍数回流）；相对两轨取低闸 89.3 为 +8.9%。
