## 先固定计价、股份和收益定义

总股数5.286亿股，其中A股4.086亿、B股1.2亿。持有期内假设无增发、回购、可转债及股数变化；若有新公告必须更新每股计算，不能只提高整体价值。归母经营净利润已经扣融资成本、所得税及少数股东利润，**不等于EBIT、NOPAT或企业自由现金流**。

正常化经营利润剔除另行计价的闲置现金收益，必要经营现金收益保留；经营债务保留、利息进入利润，不再从PE股权价值中机械扣第二遍。金融现金收益逐日入现金池，期末只将剩余可归母非经营现金加值一次。小额其他投资与房地产不单独加值，其投资收益也不塞进经营利润。

预期年化=概率加权每股现金流的IRR。先算每条联合路径的现金分配和期末价格，按权重汇总，再求IRR；不以各情景IRR的均值作主答案。默认18%源自用户要求，是买入上限的收益门槛，不是预测，也不是独立当前估值的资本成本。

### 三年窗口与分红时点

模型的三段经营年度分别截止2027、2028、2029年11月7日，每段代表一整年持有期间的经营规模；相邻自然年度财报提供锚，但表中第一段不冒称精确的2027自然年预测。第三段年化正常化利润用于到期日PE。

现金流按ACT/365.25计时。各段自由现金按实际天数均匀形成、闲置现金按日滚存；这是季节性简化，不是公司逐日预算。第一笔中期分红假设2026-12-31付每股1元，实际仅有董事会预案；若未获批准或延期，须改日期及现金留存。2027-07-17另付2026年估计归母利润24.5亿元的65%，减已假设派发的5.286亿元，共10.639亿元。若预案取消，这笔中期款不能仍从年度分红扣掉。

后两次年度分红假设2028、2029年7月17日支付，按前一完整持有年度归母利润乘对应分红率。这样比将全年预测利润全部在产生当年分出更接近历史习惯，但持有年度与法定自然年度存在约两个月错位，属于明确的日期及盈利近似，未来有实际方案即替换。所有分红都在支付时从现金池扣除，末段尚未分出的利润留在期末现金，不假设无偿多收一次分红。未假设分红再投资。

## 从量价和费用推导盈利

2026全年收入153、归母24.5是研究预测，分别隐含第四季度25.30、1.90。前三季财报与TTM收入151.77提供规模锚；Q4利润必须从2025亏损和2026Q3极弱状态恢复，不能视为已实现。模型不外推2024收入235.78、利润55.17的峰值。

35亿元不是额外安全边际扣款：经营中需要保留的资金由经营PE承载，不能同时当多余现金加值。现有应付账款、合同负债与预提费用放在经营营运资金基数中，未来变化进入现金桥；没有把所有负债一次付清后仍假设继续享受它们的免费融资。保证金保留额不是法定最低现金要求，增减需要重新判断，而非固定跨公司规则。部分质保款也可能与建设相关，本模型用保留资金覆盖而不另重复扣除。

Q3其他流动资产3.15亿元未披露完整构成，不把其中税项或可能重复的利息全部作多余现金；其他权益投资等金额小且归属复杂，也未额外加值。少数股东现金、必要现金及研究日前桥接的联合误差以起始可计价现金±10亿元检查，不再扣一笔“误差准备”。

Q3借款、租赁及一年内到期负债合计约5.53亿元，明显小于上述可计价现金余额。借款主要在子公司，模型保留经营债务、按收入0.1%计融资成本，假设到期续借后余额大体稳定；未假设新增债务资助分红。若实际需偿债，应同时减少现金和利息成本，不能只扣债务本金一次又永久保留原利息。

## 倍数和概率如何判断

先分经营状态，再分相同经营状态下的市场定价。业务温和修复合计40%，低位徘徊25%，竞争性衰退15%，较强修复20%。温和修复权重较高，依据是已有品牌、现金、足够产能与最新收入回款改善；低位及衰退合计40%，依据是连续利润收缩、量价压力、营销刚性、竞品分化，以及渠道缺少可核验数据。强修复20%承认去库后经营杠杆，不把全国化和新品成功当成事实。

**这些比例是研究者暂定主观判断，未经统计校准，不是历史发生频率，也不来自语言模型自报信心。** 证据支持状态排序，不能精确证明15%或20%的差异；必须看移权敏感性。估值没有通过调权让现价变便宜。

PE代表值按经济机制选择：

- 衰退10–14倍，取12：经营利润长期受损、需求缩量和资金占用，要求较高收益补偿；仍不是清算底价。
- 低位14–18倍，取16：收入大致稳定、低个位数增长、维持渠道仍耗费现金，利润可转现金但持续性一般。
- 普通修复18–22倍，取20：销量回升、少量结构改善、资本高峰过去；假设之后增长回落到中个位数，不能永久外推复苏利润弹性。以约85%–90%的可分配转化粗看，20倍对应4%多的现金收益，需增长支持；不是只靠低利率就应给25倍。
- 较强恢复22–26倍，取24：省内稳定、结构回升、低追加资本需求同时得到证明，才支持更长盈利持续性。代表值未取最高端，因为之后增速仍会降低。
- 普通恢复仍可能只给14–18倍、强恢复也可能只给16–20倍：分别取16、18，表示市场偏好、行业长期预期或实现时点导致的压缩，而非再次压低同一路径盈利。

这些区间是可挑战的估计，代表值虽落在区间中部，依据是上述现金回报与竞争条件，而非自动执行“取中点”。历史高PE和同行报价不作直接锚；E1、E2的前瞻PE处于约17–21倍只是当时价格下的参照，不构成终值依据。增长恢复同时发生PE压缩已单列，避免只把好利润配高PE。

```text
                   ＋ 期末每股价值 × (1－卖出费率) / (1＋18%)^实际持有年数
```

得到A股上限83.424569元，乘5.286亿股为440.98亿元A股等价买入市值。参考价105.01元使用同一组现金流，IRR为8.9507%；当前市值与未来价值不能直接用差额年化。第一个1元中期分红已经从终值现金扣除；起始现金、金融收益、经营利润、股利都可沿输出现金桥复核。

B股与A股在本模型采用同一单位经济权益，但实际市场分割。以54.81港元×0.85712=46.978747元、相对A股44.7374%的价格比为“退出相对折价持续”的单独假设，不把A股价格当B股可实现退出价。暂假设汇率不变、股息税10%、买入费0.20%、卖出费0.25%、资本利得税0%；这是比较参数，不是对B股具体投资者税制或经纪商费率的确认。由此得人民币模型IRR11.79%，18%买入上限40.43元、换算47.16港元。未计换汇价差、最低收费、市场冲击、资金跨境成本，实际回报可能更低；流动性差也可能令退出折价扩大。

A股等价市值555.08亿元=A价×全股数；A+B实际行情市值485.45亿元=A价×4.086+B价×汇率×1.2。二者不得混用。663.37亿元为企业全部普通股的经济价值，未对B股部分另扣市场折价；这不构成B股三年后一定平价的预测。B股条件测算独立使用折价退出。

## 更新与可复核边界

权重调整须由证据驱动：同季价量、渠道利润和销售费率持续改善可提高修复权重；在同行增长时古井连续失速、基酒继续积压或出现新增低回报投资，则提高低位与衰退权重。不能从某个目标股价反推概率。股票价格更新只改变回报及剩余日期，不能自动把旧的2029预测延期三年。

脚本验证权重总和、股份合计、各段现金桥、现金不透支以及买入上限IRR回代；资本利得税仅实现0税率假设，改为非零会报错，须先补充计税逻辑。已从其他工作目录运行并确认输出一致，另检验零现金收益下改变分红比例不创造总价值、行情变化不改变经营估值与A股买入上限。这些是算术一致性检查，不证明概率或盈利预测正确。另复核来源原表、季度差额、分红是否重复、受限资金与少数权益归属、同行反证及A/B币种。没有独立审阅者签字，也没有将规则符合性当成估值正确性。
