# 古井贡酒：恢复需要渠道利润，不能只看收入转正

研究日期：2026-11-07。金额默认人民币，财务金额单位为亿元；主要评价A股000596，另说明B股200596的差异。财报截至2026年9月30日，行情截至11月6日。

**古井仍有区域品牌和渠道基础，现金储备也给了它调整时间；但定价权、全国化效率和新增产能回报正在接受检验。我的判断是盈利可以逐步修复，暂不应按重回高峰或恢复高增长来定价。** 在下述暂定主观概率下，三年后预期股权价值为663.37亿元，按18%目标年化反推的A股合理买入价约83元；105.01元参考价对应的模型年化约8.95%。当前A股尚不满足这套收益要求，低于83元也不自动证明永久损失风险可接受。

这是新框架下重新研究的结果，不沿用已清空旧报告的数字。663.37亿元是**2029-11-07的期望价值**，不是今天的合理市值；83元是特定收益要求下的买入上限，不是独立估计的当前内在价值。概率未经统计校准，精确到分的结果只便于复算。

## 好生意的基础还在，但优势需要付出持续费用

古井主要向经销商销售白酒，通常先款后货。品牌在地方宴席和社交场景中的认可、产品梯度以及终端服务网络，使其不必与普通酒只比生产成本。2026年上半年，年份原浆贡献79.65亿元收入、毛利率85.03%；集团整体毛利率80.33%，前五名经销商期末无应收账款。这些支持产品有品牌溢价、回款模式有优势的判断。[半年报：业务与经销模式](evidence/raw/2026半年报.pdf#page=10)

但毛利率不等于股东回报。2025年销售费用54.58亿元，包含广告13.53亿元、综合促销18.61亿元；收入下降时，人员、广告和终端维护不能等比例收缩。2026年上半年广告费还增长1.99%，而收入下降27.01%。这是一门需要持续维护消费者与渠道关系的生意，不能把销售费用大幅删掉，再把增加的利润当成正常盈利。[年报费用明细](evidence/raw/2025年报.pdf#page=17)、[半年报费用明细](evidence/raw/2026半年报.pdf#page=14)

公司的全国化也没有完成：上半年华中收入占90.07%，华北收入下降50.71%。华中不等于安徽，公开报表不能精确计算安徽市场份额，但足以说明区域集中仍高。品牌和密集渠道构成进入壁垒，却不能阻止迎驾、口子窖以及全国名酒争夺同一消费者。原粮涨价相对容易被高毛利吸收，消费降档与促销竞争造成的实际售价下降更难转嫁；目前缺乏长期抵御通胀的强定价权证据。[区域收入](evidence/raw/2026半年报.pdf#page=13)

## 收入出现改善，利润与现金还没有给出同样强的信号

| 合并口径，亿元 | 2023全年 | 2024全年 | 2025全年 | 2026年前三季度 |
| --- | ---: | ---: | ---: | ---: |
| 营业收入 | 202.54 | 235.78 | 188.32 | 127.70 |
| 归母净利润 | 45.89 | 55.17 | 35.49 | 22.60 |
| 经营现金流净额 | 44.96 | 47.28 | 19.47 | 21.21 |

前三季度不与全年直接比较：2026年前三季度收入、归母净利润分别同比下降22.25%、42.94%。单三季度收入增长3.69%，但归母净利润下降68.04%至0.95亿元；销售费用率由报表相减计算为47.51%。期末合同负债9.58亿元，较半年末回升，但仍低于2025年末15.20亿元。改善是真实的边际信号，尚不足以说明费用恢复正常或渠道重新愿意积极备货。[年报历史数据](evidence/raw/2025年报.pdf#page=7)、[三季报](evidence/raw/2026三季报.pdf#page=2)

更直接的压力来自产品结构：上半年年份原浆收入下降27.32%，销量下降16.66%，据此计算的平均每吨收入下降约12.79%。它同时包含产品组合、折扣和渠道变化，不能说成每款酒都降价12.79%。因此，未来预测需要回答的是卖什么酒、以什么价格卖、渠道还有没有钱赚，而不仅是总销量能否反弹。[销量与收入原表](evidence/raw/2026半年报.pdf#page=10)

同业提供了重要反证：迎驾2026年前三季度收入、归母净利润分别增长6.93%、4.25%，口子窖则分别下降17.62%、48.23%。行业困难没有让所有企业同幅下滑，古井的产品组合和渠道效率也必须承担解释责任。[迎驾三季报](https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12674883&stockid=603198)、[口子窖三季报](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12676005&stockid=603589)

现金流不能只看21.21亿元这个数。2026年上半年15.43亿元经营现金流包含4.30亿元受限资金释放，去掉后为11.13亿元，约为归母利润的51%；这还包括存款利息，且现金流是合并口径。三季度报告也说明受限资金收回增加，但未给出完整调节明细。2025年则相反，保证金净占用压低了经营现金流：剔除这项时点影响后为29.39亿元，而非19.47亿元。调整改善了理解，不能消除营运资金占用与利润下滑的事实。[现金转换底稿](evidence/README.md#现金是真的但不能都当作经营新增现金)

库存也要区分。2026年6月末公司自有成品酒数量较年初下降，半成品酒却从37.06万吨增至41.09万吨；自制半成品及在产品账面金额99.80亿元，占存货约92%。基酒储存有工艺价值，但不等于立即可分红的现金，更不等于经销商库存已经出清。公司未公布可核对的分产品、分区域渠道库存及开瓶数据。[库存明细](evidence/raw/2026半年报.pdf#page=103)

## 扩产结束有利于现金释放，资本配置仍需打分

智能园2025年已全面建成投产；公司解释制造费用增长主要来自新增折旧。2025年成品酒产量约10.75万吨，对应18万吨设计年产能，粗略利用率约60%；不是没有能力供货，而是需求和产品结构决定产能是否值钱。2026年前三季度购建长期资产现金支出5.81亿元，低于上年同期13.64亿元，未来无需复制上一轮扩产才能恢复部分收入。[产能](evidence/raw/2025年报.pdf#page=12)、[管理层解释第10、14问](evidence/raw/2025年度业绩说明会.pdf#page=6)、[资本开支](evidence/raw/2026三季报.pdf#page=11)

这支持用正常化盈利乘PE，并以现金桥检查资本投入；不支持把所有折旧都当成可分配现金。本模型仍计入每年维护、改造及增长投入，以及基酒和渠道资金占用。2025年黄鹤楼商誉减值3.15亿元说明外延扩张发生过价值损失；它不应每年机械重复扣除，也不能加回后便宣称原收购成功。[商誉减值](evidence/raw/2025年报.pdf#page=133)

治理判断是“未发现足以否定研究的公开硬伤，但缺乏给予资本配置溢价的依据”。实控人为亳州市国资委，集团持股51.34%；2025年现金分红对应全年归母利润的65.53%，体现回馈股东的能力。另一面，管理层没有给出库存细项、扩产增量回报或持续提高分红的量化承诺；2026年半年报无股权激励计划，公开资料不足以证明考核以长期每股价值为核心。无保留审计意见支持财务报表可信度，不证明终端需求或管理层每项经营判断正确。[治理、关联交易与说明会核对](evidence/README.md#治理与资本配置的证据边界)

## 主预测：三年后恢复到约31亿元归母经营利润

以2026年全年收入153亿元、归母利润24.5亿元作为**研究估计**起点：前三季度已实现127.70亿元、22.60亿元，隐含第四季度收入25.30亿元、利润1.90亿元。它没有把第三季度的极低利润率全年化，也没有把2024年高点直接当作正常水平。2025年第四季度亏损含商誉等减值，恢复到小幅盈利仍要求费用和动销改善，并非低基数自然保证。

未来三段持有年度，概率加权收入由154.08亿元、160.87亿元增至170.18亿元；归母经营净利润由24.04亿元、27.28亿元增至**30.97亿元**，加上单独核算的剩余现金收益，第三段总归母利润约32.13亿元。温和修复是经营状态中权重最高的一类，但期望值同时考虑低位徘徊和竞争性衰退，不称作“最可能实现的精确数字”。

经营恢复的主要来源是去库后销量回升、产品组合止跌，以及销售费用率随收入和投放效率改善而下降。普通修复路径第三段销售费用率仍为30%，没有降到迎驾水平；第三段收入177.04亿元，仍低于2025年。更强恢复需要份额和结构同步改善，只给予较小权重。完整的量价、费用、现金投入、联合PE与概率依据见[估值附录](valuation/README.md)。

各条路径先分别计算经营价值，再加尚未分出的非经营净现金，最后加权，得到**期末经营股权价值564.45亿元，加期末归母可计价净现金98.92亿元，合计663.37亿元**。期间预计另有每股9.30元税前现金分配，已从期末现金扣除，不重复计价。

未统一给25倍PE，原因不是为了压出低买点。普通修复后的预期增长为中个位数、销售投入仍高、渠道定价尚需验证；相应主要区间14–22倍。只有结构和资本效率明显恢复的状态才支持更高倍数。若把所有状态都统一改为25倍，其余不变，买入上限会升至107.55元——可见对倍数的判断确实能改变结论，不能用“白酒好公司”一语带过。[倍数与敏感性](valuation/README.md#倍数和概率如何判断)

## 18%的要求对应83元，仍然需要承担经营失败风险

本报告的“预期年化”统一为：先把各路径的每股现金分配和期末价值按概率加权，再求IRR。按人民币、境内个人A股持续持有超过一年及附录税费假设：

| 项目 | 结果 |
| --- | ---: |
| 18%目标年化对应A股合理买入价 | 83.42元/股，实务理解为约83元 |
| 按全部5.286亿股换算的A股等价买入市值 | 440.98亿元 |
| 11月6日A股参考收盘价 | 105.01元/股 |
| 该价格对应期望现金流IRR | 8.95% |

行情来源为[历史收盘数据](https://cn.investing.com/equities/gujing-distill-a-historical-data)。用户税务身份未知，以上只是明确条件下的计算；不是确认用户免税。18%是收益要求，未再另打安全折扣。

按期望分红与期末现金不变反推，105.01元要取得18%年化，需要三年后经营利润约37.61亿元并获得20倍PE，或当前主预测经营利润得到约24.29倍PE。两者都不是不可能，但都比本报告的加权判断更乐观。若只是三年累计不亏，相同现金假设下20倍PE所需经营利润为20.38亿元；“大概率不亏”和“值得承担风险取得18%回报”是两回事。

即使83.42元买入，竞争性衰退路径仍可能累计亏损46.17%；普通恢复但PE为16倍的路径，年化约17.69%。若企业现金流和价值冻结、价值兑现拖延两年，83.42元对应年化降至10.66%。这些是压力测试，不是损失下限，也不代表已替用户认可亏损容忍度。[下行与延迟检验](valuation/README.md#容错能力和最有力的反对意见)

B股不能直接套用A股退出价格。11月6日B股54.81港元，按当日中间价折合46.98元，约为A股的44.74%；公司在5月说明会明确暂无B股转板计划。假设这个折价一直存在、汇率不变，按B股附录税费假设，模型年化约11.79%，18%对应约47.16港元。它是折价持续条件下的比较，不能因同一企业便假设三年后折价消失。[B股价格](https://cn.investing.com/equities/anhui-gujing-distillery-historical-data)、[汇率](https://www.chinamoney.com.cn/chinese/bkccpr/index.html?tab=2)、[公司回复第19问](evidence/raw/2025年度业绩说明会.pdf#page=10)

全公司实际A+B股行情市值约485.45亿元；常见的105.01元乘全部股数得到555.08亿元，是A股等价市值。不能用485.45亿元作为只买A股者的投入来计算回报。

## 哪些证据会让我改判断

最强的乐观解释是，收入下降主要来自主动去库，资本开支高峰已过，渠道恢复后利润会比本模型更快回升。最新券商研究确实提供了库存改善的线索；但同时下调盈利预测，且渠道调研没有公开可复查样本。本报告接受恢复的可能性，不把这些线索当成已确认的全面拐点。[外部观点及处理](evidence/README.md#外部观点用来挑战而不是代替判断)

最强的悲观解释是，过去高利润包含渠道提前备货和持续升级的共同红利；需求降档、线上价格透明和竞争者抢份额，会使“恢复高利润”成为错误锚点。现金只能争取时间，不能修复消费者选择；如果大额现金转向低回报项目，账面安全感也会消失。

后续主要看三组证据：

- **动销与价盘**：同季年份原浆量价、可核对的渠道库存和返利后经销商利润。单次电商补贴价、合同负债回升或股价上涨都不够。量价连续改善且费用率回落，才上调恢复权重；连续两个可比披露期继续恶化，则下调。
- **盈利能否变成股东现金**：剔除保证金释放后的滚动现金流、基酒增量、资本开支和实际分红。若正常化现金回流连续低于模型、存货与应付款占用加重，重算现金桥；若披露大额资金受限、占用或会计问题，先停止使用买入价。
- **投入是否有效**：扩产后的产销匹配、全国化收入与销售费用的关系、收购后回报及新项目资金需求。若再启动重大扩产或并购，必须先证明每股回报，不把增长计划直接加进估值。

目前研究能够解释主要商业机制、利润与现金差异，足以给出可挑战的条件性估值；不能从公开资料验证完整终端库存、单品盈利或各子公司可自由分配现金。完整缺口与影响留在[证据附录](evidence/README.md)，全部假设、算法和结果留在[估值附录](valuation/README.md)。这份研究经过来源及计算自查，未经独立第三方审阅。资金不能承受等待、需要杠杆或要求低回撤时，单凭18%的模型门槛不构成持有理由；在机会成本比较中，也无需为了完成研究而买入。
